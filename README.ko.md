## 1. Dayloom이란? 핵심 개념

### 어떤 플러그인인가요?

Dayloom은 옵시디언 노트에 적힌 **체크박스 할 일(`- [ ]`)**들을 자동으로 수집하여 보기 편한 타임라인 스케줄로 시각화해 주는 플러그인입니다.  
할 일에 날짜와 시간을 입력하면 타임라인 위에 시간 블록으로 나타나며, 타임라인에서 블록을 마우스로 드래그하면 **노트 본문의 텍스트가 실시간으로 함께 수정**됩니다.  
별도의 외부 데이터베이스 없이, 오직 사용자의 순수 마크다운(Markdown) 파일 안에서 모든 데이터가 관리됩니다.

### 주요 기능 한눈에 보기

| 기능 | 설명 |
| --- | --- |
| 6가지 뷰 | 일간 타임라인, N일 뷰(2~14일), 주간 뷰, 월간 뷰, 보드(칸반/우선순위) 뷰, 리스트 뷰 |
| 타임박싱 | 원하는 시간 슬롯으로 할 일 드래그 배치, 상·하단 핸들을 끌어 시간 길이 조절 |
| 사이드 드로어 | 미니 달력, 🎯 오늘의 집중(Today's Focus), 지난 할 일, 미지정 할 일, 일일 통계 패널 제공 (데스크톱 모든 뷰에서 열기 가능) |
| 확장형 검색 | `/` 키를 누르면 헤더 전체가 검색창으로 확장, 엔터 입력 시 리스트 뷰에서 일괄 검색 결과 표시 |
| 다중 선택 & 삭제 | 모든 뷰에서 Ctrl/Cmd+클릭 및 마우스 네모 드래그 다중 선택 지원, Delete 키로 일괄 삭제 (실행 취소 지원) |
| 구글 캘린더 연동 | 일정 읽기/수정/생성 및 특정 캘린더와의 양방향 태스크 동기화 |
| 시작 알림 | 시작 시간(또는 5~30분 전)에 앱 내 알림창 또는 시스템 알림 제공 (차임 사운드 포함) |
| 인라인 뷰 삽입 | ```` ```dayloom ```` 코드블록을 통해 일반 노트 본문에 원하는 조건으로 플래너 임베드 |
| Tasks 플러그인 호환 | 옵시디언 Tasks 플러그인의 표준 이모지 문법(📅 ⏳ 🛫 ✅ ❌ 🔁 🔺⏫🔼🔽⏬) 완벽 호환 |
| 다국어 지원 | 한국어, English, 日本語, 简体中文 지원 (옵시디언 언어 자동 감지 또는 설정에서 수동 선택) |

### 두 가지 창: Dayloom vs Dayloom Compact

| 이름 | 여는 방법 | 설명 |
| --- | --- | --- |
| **Dayloom** | 리본의 캘린더 아이콘 클릭 또는 커맨드 `Open Dayloom` | 메인 플래너 탭. 데스크톱 환경에서는 우측 사이드 드로어가 함께 제공됩니다. |
| **Dayloom Compact** | 리본의 시계-캘린더 아이콘 클릭 또는 커맨드 `Open Dayloom Compact` | 우측 사이드바에 도킹되는 컴팩트 뷰. 하단 5개 탭(일간 · 2일 · 월간 · 보드 · 리스트)으로 구성됩니다. |

> 💡 단축키 `Ctrl+P` (Mac은 `Cmd+P`)를 눌러 **커맨드 팔레트**를 연 뒤 "Dayloom"을 입력하면 관련된 모든 명령어를 확인할 수 있습니다.

### 기본 개념

- **할 일(Task)은 체크박스 한 줄입니다**: 본문에 `- [ ] 리포트 작성하기`라고 적기만 하면 Dayloom이 알아서 인식합니다.
- **날짜 기준**: `⏳ 2026-10-07`(예정일) $\rightarrow$ `📅 2026-10-07`(마감일) $\rightarrow$ **데일리 노트의 파일명** 순서로 인식합니다.  
  예를 들어 `2026-10-07.md` 데일리 노트 본문에 적힌 태스크는 별도 날짜 표기가 없어도 해당 날짜의 할 일로 처리됩니다.
- **시간 표기**: `⏰09:00-10:30` 형태로 기록됩니다. 시간이 지정된 태스크는 타임라인에 시간 블록으로 배치되고, 시간이 없는 태스크는 상단 "종일(All Day)" 영역에 들어갑니다.
- **상태 구분**: 체크박스 내부 문자로 구분합니다: `[ ]` 할 일, `[/]` 진행 중, `[x]` 완료, `[-]` 취소됨.

## 2. 구글 캘린더 OAuth 2.0 연동 가이드

> 📌 구글 캘린더 연동은 **선택 사항**입니다. 연동하지 않아도 Dayloom의 모든 로컬 플래너 기능은 100% 정상 작동합니다.

### Dayloom의 인증 방식

Dayloom은 **"구글 로그인 버튼"을 따로 제공하지 않습니다.** 대신 설정창에 다음 3가지 고유 키값을 직접 입력받아 동작합니다:

| 설정 항목 | 설명 | 예시 형태 |
| --- | --- | --- |
| `Google Client ID` | 직접 생성한 구글 클라우드 앱의 클라이언트 ID | `xxxx.apps.googleusercontent.com` |
| `Google Client Secret` | 해당 앱의 비밀 키(Secret Key) | `GOCSPX-xxxx` |
| `Google Refresh Token` | 새로운 액세스 토큰을 받아오기 위한 영구 토큰 | `1//0xxxx` |

Dayloom은 이 3가지 값을 이용해 구글 서버(`https://oauth2.googleapis.com/token`)에서 주기적으로 안전하게 단기 액세스 토큰을 자동 갱신합니다.  
따라서 최초 **① 구글 클라우드에서 OAuth 앱을 만들고 ② 리프레시 토큰(Refresh Token)을 딱 한 번만 발급받는 작업**이 필요합니다. (약 15~20분 소요)

> ⚠️ 구글 클라우드 콘솔의 화면 UI는 구글에 의해 수시로 변경될 수 있습니다. 메뉴 명칭이 조금 다르더라도 비슷한 의미의 메뉴를 찾아 진행하시면 됩니다.

---

### 1단계: 구글 클라우드 프로젝트 생성

1. [Google Cloud Console](https://console.cloud.google.com/)에 접속하여 본인의 구글 계정으로 로그인합니다.
2. 상단 헤더의 **프로젝트 선택 드롭다운**을 클릭한 뒤, 우측 상단의 **[새 프로젝트 (New Project)]**를 클릭합니다.
3. 프로젝트 이름에 알아보기 쉬운 이름(예: `Dayloom`)을 입력하고 **[만들기 (Create)]**를 클릭합니다.
4. 상단 드롭다운에서 방금 생성한 프로젝트가 활성화되어 있는지 확인합니다.

### 2단계: Google Calendar API 활성화

1. 좌측 햄버거 메뉴(☰)를 열고 **[API 및 서비스] $\rightarrow$ [라이브러리]**로 이동합니다.
2. 검색창에 `Google Calendar API`를 검색하고 클릭합니다.
3. **[사용 (Enable)]** 버튼을 클릭합니다.

### 3단계: OAuth 동의 화면 구성

*(최신 콘솔에서는 **Google Auth Platform**으로 명시되어 있을 수 있습니다.)*

1. 좌측 메뉴에서 **[API 및 서비스] $\rightarrow$ [OAuth 동의 화면]** (또는 *Google Auth Platform $\rightarrow$ 브랜딩*)으로 이동하여 **[시작하기]**를 클릭합니다.
2. 앱 정보 입력:
   - **앱 이름(App name)**: `Dayloom` (원하는 이름 아무거나 가능)
   - **사용자 지원 이메일**: 본인의 구글 이메일 선택
3. **사용자 유형(User type)**: 개인 계정 사용 시 **외부(External)**를 선택합니다.
4. 개발자 연락처 이메일을 입력하고 **[저장 후 계속]**을 누릅니다.
5. **테스트 사용자(Test users)** 단계에서 **[+ ADD USERS]**를 눌러 **본인의 구글 계정 이메일**을 반드시 등록합니다.

> ⚠️ **매우 중요: 7일 토큰 만료 문제 방지**  
> 앱이 **테스트(Testing)** 상태에 머물러 있으면, 구글 보안 정책상 캘린더 리프레시 토큰이 **7일 후 자동 만료**됩니다.  
> 매주 토큰을 재발급받는 번거로움을 피하려면, 토큰을 발급받기 전에 OAuth 동의 화면 페이지 상단의 **[앱 게시 (Publish app)]** 버튼을 눌러 상태를 **프로덕션(In production)**으로 전환하세요.  
> 나 혼자 쓰는 앱이므로 구글의 별도 승인 심사 없이 즉시 프로덕션 전환이 가능합니다. (로그인 시 "확인되지 않은 앱" 경고가 뜨면 **고급 $\rightarrow$ (앱 이름)(으)로 이동**을 누르시면 됩니다.)

### 4단계: OAuth 클라이언트 ID / Secret 발급

Dayloom 설정창에서는 이를 웹 클라이언트로 요구하므로, 클라이언트 유형을 **웹 애플리케이션(Web application)**으로 만듭니다.

1. 좌측 메뉴에서 **[API 및 서비스] $\rightarrow$ [사용자 인증 정보]**로 이동한 뒤, 상단의 **[+ 사용자 인증 정보 만들기] $\rightarrow$ [OAuth 클라이언트 ID]**를 클릭합니다.
2. **애플리케이션 유형**: **웹 애플리케이션 (Web application)** 선택
3. **이름**: `Dayloom Web Client` (자유롭게 입력)
4. **승인된 리디렉션 URI (Authorized redirect URIs)** 섹션에서 **[+ URI 추가]**를 누르고, 아래 구글 공식 토큰 발급기 주소를 **정확히 복사해 입력**합니다:
   ```text
   https://developers.google.com/oauthplayground
   ```
5. **[만들기]**를 클릭합니다. 화면에 나타나는 **클라이언트 ID(Client ID)**와 **클라이언트 보안 비밀번호(Client Secret)**를 메모장에 안전하게 복사해 둡니다.

### 5단계: 리프레시 토큰(Refresh Token) 발급 (OAuth 2.0 Playground)

1. [OAuth 2.0 Playground](https://developers.google.com/oauthplayground) 웹사이트를 엽니다.
2. 우측 상단의 **톱니바퀴 아이콘 (⚙️, OAuth 2.0 configuration)**을 클릭합니다.
   - **`Use your own OAuth credentials`** 체크박스를 켭니다.
   - 바로 아래에 4단계에서 복사해 둔 **OAuth Client ID**와 **OAuth Client Secret**을 각각 붙여넣습니다.
   - **Access type**이 `Offline`으로 설정되어 있는지 확인합니다. (오프라인이어야 리프레시 토큰이 나옵니다.)
3. 화면 좌측 **Step 1 (Select & authorize APIs)** 아래의 *Input your own scopes* 입력창에 다음 스코프를 붙여넣습니다:
   ```text
   https://www.googleapis.com/auth/calendar.events
   ```
   > Dayloom은 캘린더의 **일정 읽기, 생성, 수정, 삭제** 권한만 사용하므로 이 스코프 하나면 충분합니다.
4. **[Authorize APIs]** 파란색 버튼을 클릭하고, 방금 테스트 사용자로 등록했던 본인의 구글 계정으로 로그인한 뒤 권한을 허용합니다.  
   *(경고창이 뜨면 "고급" $\rightarrow$ "(안전하지 않음)으로 이동" 클릭)*
5. 계정 인증이 끝나면 자동으로 **Step 2** 화면으로 전환됩니다.  
   파란색 **[Exchange authorization code for tokens]** 버튼을 클릭합니다.
6. 화면 아래쪽에 생성된 내용 중 **`Refresh token`** 값을 복사합니다 (`1//0`으로 시작하는 긴 문자열입니다). 필요한 모든 키가 준비되었습니다! 🎉

> 🔒 클라이언트 시크릿과 리프레시 토큰은 **비밀번호와 같습니다.** 절대 외부에 공유하지 마세요.

### 6단계: Dayloom 설정창에 값 입력하기

1. 옵시디언 **설정 (⚙️) $\rightarrow$ 커뮤니티 플러그인 $\rightarrow$ Dayloom**으로 들어갑니다.
2. 상단 탭에서 **☁️ Google Calendar** 탭을 클릭합니다.
3. **Enable Google Calendar Integration** 스위치를 켭니다.
4. **Google Calendar OAuth 2.0 (sync & editing)** 항목 아래의 세 입력창에 복사해 둔 값을 차례대로 붙여넣습니다:
   - `Google Client ID`
   - `Google Client Secret`
   - `Google Refresh Token`

### 7단계: 표시할 캘린더 등록하기

1. 같은 탭 아래쪽 **Google Calendars 📅** 섹션에서 **[+ Add Calendar]** 버튼을 누릅니다.
2. 새 행이 생기면 정보를 채워 넣습니다:
   - **체크박스**: 체크 시 표시, 해제 시 숨김
   - **Name**: Dayloom 플래너에 표시될 별칭 (예: 직장, 개인, 학교)
   - **ID**: 기본 메인 캘린더는 `primary`를 적고, 다른 보조 캘린더는 해당 캘린더 고유 ID를 적습니다.
   - **Color**: 타임라인에 표시될 색상 지정
3. 보조 캘린더의 ID 확인 방법:  
   웹 브라우저의 구글 캘린더 $\rightarrow$ 원하는 캘린더 우측 **⋮ $\rightarrow$ 설정 및 공유 $\rightarrow$ 캘린더 통합 $\rightarrow$ 캘린더 ID** 복사  
   *(보통 `xxxx@group.calendar.google.com` 형태이며, 메인 캘린더 ID는 본인의 Gmail 주소입니다.)*
4. 불필요한 캘린더는 우측 **Delete** 버튼으로 삭제할 수 있습니다.

### 8단계: 태스크 동기화용 전용 캘린더 지정 (선택 사항)

**Task Sync Google Calendar** 드롭다운에서 특정 캘린더를 선택하면, 옵시디언의 날짜와 시간이 지정된 할 일들이 해당 구글 캘린더의 일정으로 자동 전송(동기화)됩니다.

> 💡 **강력 추천**: 구글 캘린더에서 **`Obsidian Tasks`라는 이름의 전용 캘린더를 하나 새로 만들어** 7단계에서 추가한 뒤, 여기에 지정하시는 것을 권장합니다.  
> Dayloom은 화면의 중복 표시를 방지하기 위해 **동기화용으로 지정된 캘린더의 일정은 타임라인에 일정으로 중복해서 그리지 않습니다** (어차피 동일한 옵시디언 태스크가 이미 떠 있기 때문입니다).  
> 만약 본인의 메인 캘린더(`primary`)를 동기화 캘린더로 지정해 버리면, 메인 캘린더에 원래 있던 약속이나 미팅 일정들이 타임라인에서 숨겨지므로 주의하세요.

### 9단계: 연동 테스트

1. Dayloom 메인 뷰를 엽니다.
2. 상단 헤더 툴바의 **동기화 버튼(↻)**을 클릭하거나 단축키 `F5`를 누릅니다.
3. 잠시 후 "✅ …" 완료 알림이 뜨고 타임라인에 구글 캘린더 일정들이 블록으로 나타나면 성공입니다!
4. 만약 오류가 발생한다면 [FAQ](#7-자주-묻는-질문faq--문제-해결) 섹션을 참고하세요.

### 동기화(Sync)의 상세 동작 방식

| 작업 | 결과 |
| --- | --- |
| **동기화 버튼 클릭 / `F5` / `Ctrl+R` (`Cmd+R`)** | 볼트 내 모든 노트를 재스캔하고, 현재 뷰 범위의 구글 일정을 다시 받아오며, 날짜/시간이 있는 태스크들을 동기화 캘린더로 일괄 전송합니다 (과거 60일 ~ 미래 365일 범위). |
| **동기화 버튼 우클릭** | *Synchronize Tasks with Google Calendar 📤* 모달창이 열려 대상 캘린더를 확인하고 수동 동기화를 실행할 수 있습니다. |
| **Dayloom 내부에서 태스크 편집** (드래그, 시간 리사이징, 모달 편집, 체크박스 체크 등) | 수정된 단일 태스크가 즉시 구글 캘린더의 해당 일정에 실시간으로 반영됩니다. |
| **노트 본문에서 직접 텍스트 수정** | 즉시 전송되지 않으며, 다음번 동기화(F5 등) 시점에 반영됩니다. |
| 태스크의 날짜/시간 제거 | Dayloom이 생성했던 일정인 경우, 구글 캘린더에서도 해당 일정이 안전하게 삭제됩니다. |
| Dayloom에서 동기화된 태스크 삭제 | 연동되어 있던 구글 캘린더 일정 역시 함께 삭제됩니다. |

- 동기화된 태스크 줄 끝에는 `[gcalId:: …]` 메타데이터가 붙습니다. 이는 구글 일정과의 연결 링크이므로 절대 지우지 마세요.
- 동기화 엔진은 **오직 Dayloom이 스스로 생성한 일정만 삭제**합니다. 사용자가 원래 구글 캘린더에 직접 등록해 둔 약속이나 회의 일정은 절대 삭제하지 않습니다.
- 타임라인에서 구글 캘린더 일정 블록을 마우스로 드래그하여 이동하거나 크기를 늘리면 구글 캘린더에 즉시 저장됩니다.

## 3. 설정(Settings) 탭별 가이드

Dayloom의 설정은 총 5개 탭으로 나뉘어 있습니다:

`⚙️ General (일반)` · `⏱️ Timeline (타임라인)` · `☁️ Google Calendar (구글 캘린더)` · `🔔 Notifications (알림)` · `📱 View/Display (뷰/표시)`

> 설정 메뉴 명칭은 선택하신 언어에 맞게 표시됩니다. (본 가이드에서는 영문/국문 기준 병기)

### ⚙️ General (일반)

| 설정 항목 | 설명 | 추천 기본값 |
| --- | --- | --- |
| **Language / 언어** | Dayloom의 UI 언어 설정: `Auto (옵시디언 기본값)`, `English`, `한국어`, `日本語`, `简体中文`. 변경 시 즉시 반영 | `Auto` |
| **Default Task File Path** | 새 태스크가 기본 저장될 노트 경로 (빠른 캡처, 타임라인 더블 클릭, `+` 버튼 사용 시). 파일이 없으면 자동 생성 | `Day Planner.md` 또는 `Inbox/Tasks.md` |
| **Excluded Files & Folders** | 태스크 수집에서 제외할 폴더 및 파일 필터 규칙 (아래 상세 설명 참조) | Templates, Archive |
| **Daily Notes Folder Path** | 데일리 노트가 보관되는 볼트 내 폴더 경로 | 예: `Daily` |
| **Daily Notes File Format** | 데일리 노트 파일명 날짜 포맷 | `YYYY-MM-DD` |
| **Daily Note Template** | 새 데일리 노트 생성 시 사용할 템플릿 파일 경로 | 예: `Templates/Daily.md` |
| **Weekly Notes Folder Path** | 주간 노트가 보관되는 볼트 내 폴더 경로 | 예: `Weekly` |
| **Weekly Notes File Format** | 주간 노트 파일명 포맷 | `gggg-[W]ww` (예: `2026-W41`) |
| **Weekly Note Template** | 새 주간 노트 생성 시 사용할 템플릿 파일 경로 | 예: `Templates/Weekly.md` |

#### 🔎 경로 자동완성 (Fuzzy Search)
경로 입력 필드는 볼트 내 실제 파일과 폴더를 퍼지 검색으로 자동 추천합니다. 예를 들어 `dly`만 타이핑해도 `Daily` 폴더를 즉시 찾아냅니다. (파일 필드는 마크다운 문서만, 폴더 필드는 디렉터리만 필터링되어 나타납니다.)

#### 🚫 Excluded Files & Folders (제외 규칙 설정)
옵시디언의 검색 필터처럼 **칩(Chip)** 형태로 간편하게 규칙을 추가하고 관리합니다.

1. 입력창 좌측에서 **Exclude(제외)** 또는 **Keep(포함/유지)** 모드를 선택합니다.
2. 폴더나 파일명을 타이핑하여 추천 목록에서 고르거나 `Enter`를 칩니다.
3. 규칙이 칩 형태로 추가됩니다:
   - 칩을 **클릭**하면 Exclude $\leftrightarrow$ Keep 상태가 즉시 토글됩니다.
   - 우측의 **×** 버튼을 누르면 규칙이 삭제됩니다.
   - 볼트에 실제로 존재하지 않는 경로는 취소선 및 흐린 색으로 표시됩니다.
4. 입력창 아래의 *"Leaving out N of M notes."* 안내를 통해 전체 노트 중 몇 개가 제외되었는지 실시간으로 확인할 수 있습니다.

| 규칙 예시 | 의미 |
| --- | --- |
| `Archive` | Archive 폴더 및 그 안의 모든 하위 문서를 태스크 검색에서 제외 |
| `Templates/Daily.md` | 해당 템플릿 파일 1개만 제외 |
| `**/Templates` | 깊이에 상관없이 볼트 내의 모든 `Templates` 폴더를 제외 |
| `Daily/*.md` | `Daily` 폴더 직속 마크다운 파일만 제외 (하위 서브폴더는 포함) |
| `Archive` + **Keep** `Archive/2026` | Archive 폴더 전체를 제외하되, 그 안의 `Archive/2026` 하위 폴더만은 포함 |

> `*`는 단일 폴더 레벨 매칭, `**`는 모든 하위 디렉터리 매칭을 뜻합니다 (대소문자 무시).

### ⏱️ Timeline (타임라인)

| 설정 항목 | 설명 | 추천 기본값 |

| **Timeline Hour Height (…)** | 타임라인 1시간의 세로 픽셀 높이 (30~180px) | `60` (기본값); 일정이 많다면 `90` 이상 추천 |
| **Timeline Start Hour / End Hour** | 타임라인이 표시할 시작 및 종료 시간. **'Fit It In(빈 시간 채우기)' 기능의 근무 가능 시간 기준**으로도 사용됨 | 예: `7` – `23` |
| **Default Task Duration (minutes)** | 시간 미지정 태스크를 타임라인으로 끌어놓을 때 부여되는 기본 시간 길이 (1~1440분). 여러 태스크를 연속 배치할 때도 사용됨 | `60` (기본값); 뽀모도로 사용자라면 `25` |

## 4. 사이드 드로어 & 타임박싱 워크플로우

**타임박싱(Timeboxing)**이란 각 할 일에 구체적인 시간 블록을 부여하여 *"언제 이 일을 할 것인가"*를 명확히 결정하는 기법입니다.  
Dayloom의 사이드 드로어는 아직 시간표에 올리지 않은 할 일들을 모아두고, 오늘의 집중 목표와 진척도를 한눈에 보며 손쉽게 일정표로 끌어다 배치할 수 있도록 돕습니다.

### 드로어 열고 닫기

- **데스크톱 Dayloom 메인 뷰**의 모든 탭(일간, N일, 주간, 월간, 보드, 리스트)에서 사용 가능합니다. (Dayloom Compact 및 모바일 화면에는 표시되지 않습니다.)
- 열기 / 닫기: 키보드 `s`를 누르거나, 헤더 툴바 끝의 **패널 아이콘(▣)**을 클릭하거나, 커맨드 `Toggle Side Drawer`를 실행합니다.
- 드로어 자체 우측 상단의 닫기(⨯) 버튼을 눌러도 됩니다.

### 레이아웃 구조

```text
┌ October 2026 ▾        ‹ Today ›    ⨯ ┐  ← 미니 달력 (보드 뷰에서는 자동 숨김)
│ Su  Mo  Tu  We  Th  Fr  Sa            │
│ ...  6주 캘린더 그리드, 점 표시 ...    │
│ [ ☑ Tasks 8 │ ◔ Stats 62% ]           │  ← 듀얼 모드 전환 스위처
├───────────────────────────────────────┤
│ [+ Add an undated task (🔺 ⏫ …)]      │  ← 1줄 빠른 캡처
│ ▾ 🎯 Today's Focus      (1)            │
│ ▾ 🚨 Overdue Tasks      (3) [Roll to today] │
│ ▾ 📂 Undated Tasks      (5)            │
└───────────────────────────────────────┘
```

### 미니 달력 (Mini Calendar)

- **날짜 클릭**: 메인 플래너 뷰가 해당 날짜로 즉시 이동합니다. 현재 메인 화면에 띄워진 날짜 범위는 은은한 밴드로 강조되며, 오늘은 꽉 찬 원으로 표시됩니다.
- **Ctrl/Cmd+클릭**: 해당 날짜의 데일리 노트 마크다운 파일을 새 탭으로 엽니다.
- **날짜 아래 색상 점(Dot)**:
  - 주황색: 미완료 할 일 존재
  - 붉게 빛나는 점: 🔺 최고(Highest) 우선순위 할 일 존재
  - 초록색: 해당 일의 모든 할 일 완료
  - 파란색: 구글 캘린더 일정 존재
- **‹ ›** 버튼 또는 **마우스 휠 스크롤**: 월 단위 이동 (**Today** 클릭 시 오늘로 복귀).
- **월 이름(예: October 2026) 클릭**: 미니 달력을 1줄짜리 주간 스트립으로 접습니다 (다시 누르면 펼침). Dayloom이 이 접힘 상태를 기억합니다.
- **날짜 위로 할 일 드롭**: 특정 날짜 위로 할 일 카드를 끌어다 놓으면 해당 날짜로 날짜가 변경됩니다 (지정된 시간은 유지).
- **보드(Board) 뷰**로 진입하면 미니 달력이 자동으로 숨겨져 태스크 목록이 세로 공간을 최대로 활용합니다.

### Tasks 모드

- **🎯 Today's Focus (오늘의 집중)**: 오늘 날짜로 지정된 미완료 **🔺 최고(Highest)** 우선순위 할 일 목록입니다. **어떤 할 일이든 여기로 끌어다 놓으면** 즉시 오늘 날짜가 부여되면서 🔺 최고 우선순위로 승격됩니다 (미지정 할 일의 경우 `📅` 오늘 날짜 자동 부여).
- **🚨 Overdue Tasks (지난 할 일)**: 오늘 이전 날짜인데 아직 완료되지 않은 미완료 할 일들입니다. (우선순위 $\rightarrow$ 오랜된 날짜 $\rightarrow$ 제목 순 정렬, 지난 날짜는 붉은색으로 강조 표시).
- **📂 Undated Tasks (미지정 할 일)**: 날짜가 없는 모든 할 일 풀(Pool)입니다 (보드 뷰의 *Undated* 열과 동일한 목록).
- 비어 있는 섹션은 **자동으로 접히며**, 새 태스크가 들어오면 자동으로 펼쳐집니다. 섹션 헤더를 클릭하여 직접 접고 펼칠 수도 있습니다.
- **🔺 최고(Highest)** 카드는 붉은 테두리와 은은한 글로우로 강조되며, **⏫ 높음(High)** 카드는 주황빛 테두리로 돋보이게 처리됩니다.

### Stats 모드

현재 플래너가 보여주고 있는 **해당 날짜의 생산성 통계**를 요약해 줍니다 (미니 달력에서 다른 날짜를 누르면 그 날의 통계로 전환):

- **프로그레스 링**: 계획된 시간 대비 완료한 시간의 비율 (시간이 지정된 태스크 기준, 취소된 일 제외). 시간 지정 태스크가 없는 경우 완료한 개수/전체 개수 비율로 표시됩니다.
- **계획됨(Planned) / 완료됨(Completed) / 남은 시간(Remaining)** 표시.
- **완료한 태스크 개수**, **완료한 집중 태스크 개수**, **구글 캘린더 일정 시간 합계**, **우선순위별 분포 그래프**.
- 하루의 성취를 복돋워 주는 짧은 응원 메시지.

검색 필터가 켜져 있어도 Stats 모드는 항상 해당 일 전체의 종합 통계를 유지합니다.

### ① 빠른 캡처 (Quick capture)

1. 사이드 드로어 상단의 1줄 입력창에 할 일을 적고 `Enter`를 칩니다.
2. 설정의 **Default Task File Path** 노트에 미지정 할 일 형태로 즉시 추가되며, "Task created in …" 알림이 뜹니다.
3. 타이핑할 때 우선순위 이모지를 함께 적으면 우선순위가 바로 적용됩니다 (예: `⏫ 제안서 초안 작성`).
4. 한국어, 일본어, 중국어 등 조합형 문자(IME)를 완벽 지원하므로 글자가 씹히지 않고 한 번의 `Enter`로 깔끔하게 저장됩니다.

### ② 우선순위 설정하기

카드의 우선순위 배지를 클릭하거나(우선순위가 없을 때 마우스를 올리면 흐린 깃발이 나타남), 카드를 키보드로 포커스한 뒤 `p`를 누릅니다.  
🔺 최고(Highest), ⏫ 높음(High), 🔼 보통(Medium), ○ 일반(Normal), 🔽 낮음(Low), ⏬ 최하(Lowest) 팝업에서 선택하면 노트 본문에 해당 이모지가 자동으로 반영됩니다.

### ③ 할 일을 시간표로 드래그 배치하기

| 드롭 위치 | 결과 |
| --- | --- |
| **타임라인 시간 슬롯** (일간 / N일 / 주간) | 해당 날짜 및 드롭한 시간으로 지정 (15분 단위 스냅). 시간 길이는 **Default Task Duration** 적용 |
| **월간 뷰 날짜 칸 또는 미니 달력의 특정 일** | 날짜만 변경 (기존 시간 유지; 시간 미지정 태스크는 종일 영역으로 유지) |
| **주간 / N일 뷰의 날짜 헤더** | **Fit It In**: 해당 날짜의 가장 빠른 빈 시간 슬롯을 찾아 자동 배치 |
| **보드(Board) 뷰의 열** | 칸반 모드: 해당 열의 날짜(또는 완료); 우선순위 모드: 해당 우선순위 부여 |
| **🎯 Today's Focus 섹션** | 오늘 날짜 부여 + 🔺 최고 우선순위 지정 |
| **드로어의 나머지 영역** | 일정 해제 (⑤번 항목 참조) |

- 드래그 중에는 떨어질 예상 시간(예: `14:30`)이 점선 프리뷰 박스로 나타납니다.
- 드래그 도중 `j` / `k` 키를 누르면 마우스를 놓지 않고도 다음 날짜/이전 날짜로 타임라인 페이지를 넘길 수 있습니다.
- 드래그 도중 `Esc`를 누르면 이동이 즉시 취소됩니다.
- 모든 이동 후에는 우측 상단 알림에 **Undo(실행 취소)** 버튼이 제공됩니다.

### ④ 여러 할 일을 한 번에 순차 자동 배치하기 (Sequential Schedule)

1. **Ctrl/Cmd+클릭** 또는 드로어 빈 공간에서 **마우스 네모 상자(Marquee)를 드래그**하여 여러 태스크를 선택합니다.
2. 선택된 카드 중 하나를 마우스로 잡고 타임라인의 원하는 시작 시간대로 끌어다 놓습니다.
3. 드롭한 시작 시간을 기점으로, 드로어에 나열되어 있던 순서대로 **빈틈없이 꼬리를 물며 연속 자동 배치**됩니다! (각 태스크의 원래 시간 길이를 유지하며, 시간 정보가 없던 태스크는 설정의 기본 시간 단위(예: 40분)씩 차례대로 채워집니다.)
4. 자정(24:00)을 넘어가는 태스크는 제자리에 유지되며, 한 번의 Undo 버튼으로 전체 다중 배치를 이전 상태로 되돌릴 수 있습니다.

`Esc`를 누르면 드로어의 다중 선택이 해제됩니다.

### ⑤ 일정 해제하기 (Unschedule)

타임라인의 블록, 종일 태스크, 월간 뷰의 태스크, 보드 뷰의 카드를 **마우스로 잡아서 사이드 드로어 안으로 끌어다 넣으면**, 날짜와 시간이 제거되어 다시 순수 [미지정 할 일]로 돌아갑니다.

- 시간 표기, `⏳` 예정일, `📅` 마감일이 본문에서 안전하게 지워집니다.
- **데일리 노트 파일 안에 적혀 있는 태스크**는 파일명 자체가 날짜이므로 날짜가 지워지지 않습니다 (안내 팝업 표시).
- 구글 캘린더 일정은 드로어로 끌어다 놓아도 캘린더에서 삭제되지 않습니다.
- 실수 방지를 위해 지난 할 일(Overdue)과 집중 할 일(Focus) 카드는 **오직 [Undated Tasks] 섹션 위로 드롭했을 때만** 일정이 해제됩니다.

### ⑥ 지난 할 일(Overdue) 정리하기

- Overdue 카드에 마우스를 올리면 빠른 처리 버튼이 나타납니다:  
  `Today (오늘로)` · `Tmrw (내일로)` · `+1 wk (1주일 뒤로)` · `Undate (날짜 지우기)`. 시간은 유지한 채 날짜만 빠르게 변경됩니다.
- 섹션 헤더의 **Roll to today**를 누르면 밀려 있던 모든 지난 할 일들이 클릭 한 번으로 오늘 날짜로 일괄 변경됩니다 (Undo 지원).

### ⑦ 드로어 키보드 조작법

`Tab` 키를 눌러 드로어 카드에 포커스를 맞춘 뒤:

| 키 | 동작 |
| --- | --- |
| `Enter` | 할 일 수정 모달 열기 |
| `f` | **Fit It In**: 향후 14일 이내에서 가장 빠른 빈 시간 슬롯을 찾아 자동 배치 |
| `p` | 우선순위 팝업 열기 |

*Fit It In* 기능은 설정된 근무 시간(Start / End Hour)을 준수하며, 오늘은 현재 시간 이후의 빈 슬롯만 탐색하고 기존의 옵시디언 태스크 및 구글 캘린더 일정을 피해 비어 있는 공간에 쏙 넣어줍니다. 들어갈 자리가 없으면 안내 알림이 뜹니다.

### 추천하는 아침 플래닝 루틴 ☀️

1. 아침에 옵시디언을 켜고 `s`를 눌러 사이드 드로어를 엽니다.
2. **Overdue** 섹션을 보고 `Roll to today`로 밀린 일들을 가져오거나 날짜를 미룹니다.
3. 오늘 가장 중요한 핵심 과업 1~2개를 골라 **🎯 Today's Focus**로 끌어다 놓습니다.
4. 생각나는 새로운 할 일들을 상단 **빠른 캡처**에 타이핑하여 털어놓습니다.
5. 오늘 처리할 **Undated** 태스크들을 다중 선택한 뒤 타임라인 빈 공간으로 드래그하여 하루 시간표를 연속 배치합니다.
6. 각 블록의 하단 핸들을 늘려 예상 소요 시간을 맞추고, 하루를 마칠 때 **Stats** 탭에서 링을 채운 성취감을 맛보세요!

## 5. 뷰, 검색, 다중 선택 & 단축키

### 6가지 뷰 (Views)

| 뷰 (탭) | 단축키 | 핵심 특징 |
| --- | --- | --- |
| **일간 타임라인 (Daily Timeline)** | `d` | 하루 상세 뷰. 현재 시간 표시선, 진행 중인 작업의 실시간 프로그레스 바, 상단 고정 종일(All Day) 영역 |
| **N일 뷰 (N-day View)** | `x` | 2~14일을 가로로 나란히 표시 (탭 상단에서 일수 즉시 변경 가능). 모바일에서는 2일 뷰로 동작 |
| **주간 뷰 (Weekly View)** | `w` | 한 주(7일) 전체 표시. **요일 날짜 헤더를 클릭**하면 해당 날의 일간(Daily) 뷰로 바로 이동 |
| **월간 캘린더 (Monthly Calendar)** | `m` | 한 달 달력 그리드. **날짜 셀을 클릭**하면 해당 날의 일간 뷰로 이동, **주차 번호를 클릭**하면 해당 주의 주간 뷰로 이동 |
| **보드 뷰 (Board)** | `b` | 칸반 보드. *칸반 모드*(Undated · Overdue · Today · Tomorrow · Future · Completed) 및 *우선순위 모드*(Highest 🔺 … Lowest ⏬) 지원 |
| **리스트 뷰 (List View)** | `l` | 한 달 간의 일정을 아젠다 목록으로 확인. 검색 시 전 기간의 모든 일치 결과를 보여주는 화면으로 활용 |

- 헤더 좌측의 **날짜 필(Date pill)** (예: 📅 2026-10-07 (Wk 41))을 클릭하면 해당 일이나 주의 데일리/위클리 마크다운 노트가 열립니다.
- **보드 뷰**에서 카드를 다른 열로 끌어다 놓으면 해당 상태에 맞게 노트 본문의 날짜나 우선순위가 즉시 수정됩니다. 카드를 다중 선택하여 여러 장을 한꺼번에 다른 열로 이동시킬 수도 있습니다.

### 데스크톱 헤더 구조

```text
[📅 날짜]                [‹ Today ›]  [🔍 ↻ 🔍+ ? ▣]  [+]
```

| 컨트롤 | 설명 |
| --- | --- |
| 📅 날짜 알약 | 해당 데일리 / 주간 노트 열기 |
| ‹ Today › | 이전 / 오늘 / 다음 날짜 탐색 |
| 🔍 검색 | 확장형 검색창 활성화 (`/`) |
| ↻ 동기화 | 구글 캘린더와 동기화 (우클릭: 수동 동기화 모달). 구글 연동 켰을 때만 표시 |
| 🔍+ 줌 | 타임라인 시간당 세로 높이 확대/축소 (일간 / N일 / 주간) |
| ? 단축키 | 단축키 안내 모달 (설정에서 숨기기 가능) |
| ▣ 패널 | 사이드 드로어 열기 / 닫기 |
| **+ 추가** | 새 로컬 태스크 추가 또는 새 구글 일정 등록 (*Add Local Task* / *Add Appointment*) |

보드 뷰에서는 헤더에 **Kanban / Priority** 모드 전환 토글이 추가됩니다.

### 🔍 확장형 검색 (Search)

1. 키보드에서 `/`를 누르거나 헤더의 돋보기 아이콘을 클릭합니다.
2. 상단 헤더의 복잡한 버튼들이 부드럽게 사라지고, **헤더 전체를 채우는 유려한 글래스모피즘 검색창**이 나타나며 자동으로 커서가 포커스됩니다.
3. 검색어를 입력하면 현재 뷰에서 타이핑과 동시에 실시간 필터링됩니다:
   - 태스크 본문, `#태그`, 노트 파일 경로, 구글 일정 제목, 장소, 캘린더 이름을 모두 검색합니다.
   - 띄어쓰기로 여러 단어를 입력하면 모든 단어가 포함된 항목(AND 조건)을 찾습니다.
4. **Enter 키를 누르면 즉시 [리스트 뷰(List View)]로 자동 전환**되며, 특정 날짜에 국한되지 않고 **볼트 전체에서 일치하는 모든 결과**를 일목요연하게 모아서 보여줍니다!
5. `Esc`를 누르거나 검색창 우측의 **×** 버튼을 누르면 검색 모드가 종료되고 원래의 헤더 버튼들이 복원됩니다.

*(리스트 뷰에 담기지 않는 미지정 태스크는 검색 중일 때 사이드 드로어의 Undated 목록에 필터링되어 나타납니다.)*

### ✅ 다중 선택 & 일괄 삭제

| 작업 | 방법 |
| --- | --- |
| 개별 항목 추가/제외 선택 | 원하는 블록/카드를 **Ctrl/Cmd + 클릭** (수정 창이 뜨지 않고 선택 상태만 토글됨) |
| 마우스 드래그로 영역 선택 | 빈 공간에서 **마우스를 네모 상자(Marquee)로 드래그** (타임라인, 종일 영역, 보드 뷰, 드로어 모두 지원) |
| 기존 선택에 영역 추가 | `Ctrl`, `Cmd`, `Shift` 중 하나를 누른 상태에서 마우스 네모 드래그 |
| 선택 전체 해제 | 빈 공간 클릭, 키보드 `Esc`, 또는 하단 선택 바의 × 클릭 |
| 여러 항목 동시 이동 | 선택된 항목 중 하나를 드래그 (타임라인 블록은 시간 간격을 유지하며 이동, 드로어 카드는 연속 자동 배치) |
| 일괄 삭제 | 키보드 `Delete` 또는 `Backspace`, 또는 하단 선택 바의 **Delete** 클릭 |

- 다중 선택은 한 영역(타임라인 그리드, 상단 종일 영역, 사이드 드로어 등) 안에서 독립적으로 작동합니다.
- **삭제 시** 실수 방지 확인 모달이 먼저 뜹니다 (`Enter` 확정, `Esc` 취소).  
  옵시디언 노트에서 해당 줄들이 깔끔하게 지워지며, 삭제 직후 우측 상단 알림의 **Undo** 버튼으로 한 번에 원상복구할 수 있습니다.
- 함께 선택된 구글 캘린더 일정이나 동기화 태스크의 캘린더 사본도 구글 캘린더에서 함께 삭제됩니다.
- ⚠️ **주의**: 구글 캘린더 자체 일정은 구글 정책상 Dayloom의 Undo 버튼으로 복구할 수 없습니다.
- 각 태스크 수정 모달 안에도 개별 **Delete** 버튼이 제공됩니다.

## 6. 태스크 문법 & 인라인 코드블록

### 기본 마크다운 문법

```markdown
- [ ] 태스크 제목 ⏰09:00-10:30 ⏫ 🔁 every week ⏳ 2026-10-07 📅 2026-10-10
```

| 요소 | 문법 | 의미 |
| --- | --- | --- |
| 체크박스 | `[ ]` `[/]` `[x]` `[-]` | 미완료 / 진행 중 / 완료 / 취소됨 |
| 시간 | `⏰09:00-10:30` | 시작–종료 시간. 종료 시간이 없으면(`⏰09:00`) 기본 30분 블록으로 표시 |
| 우선순위 | 🔺 ⏫ 🔼 🔽 ⏬ | 최고 / 높음 / 보통 / 낮음 / 최하 (없으면 일반) |
| 예정일 | `⏳ YYYY-MM-DD` | Dayloom 타임라인에 배치될 때 자동으로 찍히는 날짜 |
| 마감일 | `📅 YYYY-MM-DD` | 예정일이 없을 때 차순위로 인식되는 날짜 |
| 시작일 | `🛫 YYYY-MM-DD` | Tasks 플러그인 호환 시작일 |
| 완료/취소일 | `✅ YYYY-MM-DD` / `❌ YYYY-MM-DD` | 체크박스 체크 시 자동으로 기록되는 완료/취소 날짜 |
| 반복 규칙 | `🔁 every day` 등 | 완료 체크 시 다음 주기의 새로운 태스크 라인이 자동으로 생성됨 |
| 구글 연동 키 | `[gcalId:: …]` | 구글 캘린더와 연결된 고유 키 (수동으로 작성하거나 지우지 마세요) |

#### 다양한 시간 표기 지원
아래와 같이 작성된 시간 포맷도 유연하게 인식합니다:

```markdown
- [ ] 09:00 - 10:00 회의           ← 시간을 맨 앞에 작성
- [ ] 회의 [09:00-10:00]          ← 대괄호 표기
- [ ] 회의 [startTime:: 09:00 - 10:00]  ← Dataview 인라인 필드 표기
```

#### 날짜 우선순위 규칙
`⏳ 예정일` $\rightarrow$ `📅 마감일` $\rightarrow$ **노트의 파일명 날짜** (데일리 노트).  
예를 들어 `Daily/2026-10-07.md` 파일 본문에 작성된 `- [ ] 헬스장 ⏰07:00-08:00`은 본문에 날짜 표기가 없어도 10월 7일 아침 7시 일정으로 자동 배치됩니다.

#### 반복 규칙 (Recurrence) 지원 포맷
`every day` (`daily`), `every week` (`weekly`), `every month` (`monthly`), `every year` (`yearly`), `every weekday`, 그리고 `every N day/week/month/year` (예: `every 3 days`).

### 인라인 코드블록: ```` ```dayloom ````

일반 노트 본문 어디에나 Dayloom 플래너 뷰를 위젯 형태로 삽입할 수 있습니다. 커맨드 팔레트에서 **Insert Inline View (dayloom block)**를 실행하면 자동으로 템플릿이 삽입됩니다.

````markdown
```dayloom
type: daily
height: 500px
```
````

> 하위 호환성을 위해 이전 명칭인 ```` ```dayplanner ```` 및 ```` ```dayplanner-pro ````도 동일하게 인식합니다.

| 옵션 | 설정 가능 값 | 설명 |
| --- | --- | --- |
| `type` | `daily` · `multiDay` · `weekly` · `monthly` · `board` · `list` | 뷰 종류. 블록 내부 상단 탭을 클릭하여 즉시 변경 가능 |
| `date` | `YYYY-MM-DD` 또는 `today` | 표시할 기준 날짜 |
| `height` | `500px`, `80vh` 등 (단위 없는 숫자는 px) | 블록 높이. 블록 하단 테두리를 마우스로 드래그하면 새 높이가 자동 저장됨 |
| `hourHeight` | 숫자 (예: `80`) | 이 인라인 블록에만 적용할 시간당 세로 픽셀 높이 |
| `showFilters` | `true` | 필터 패널이 열린 상태로 시작 |
| `collapsedColumns` | `[undated, completed]` | 보드 뷰에서 기본으로 접어둘 컬럼 지정 |
| `filters` | (필터 UI 조작 시 자동 작성됨) | 아래 필터링 설명 참조 |

- **데일리 노트** 안에 옵션 없이 ```` ```dayloom ````만 넣으면 그 날짜의 뷰가 자동으로 뜹니다.
- **주간 노트** 안에 넣으면 그 주의 주간 뷰가 뜹니다.
- 인라인 블록에서는 날짜 헤더 클릭 시 탭 전환 대신 해당 데일리/주간 **노트**가 열립니다.

### 🔍 인라인 블록 필터링 패널

블록 헤더 우측의 **🔍 Filter** 버튼을 누르면 인라인 필터 설정 바가 열립니다 (버튼에 `🔍 Filter · 2`처럼 적용된 필터 수가 표시됨).

```text
[Match all ▾] [📁 Folder in Work ×] [# Tag contains #urgent ×] [+ Filter]
```

1. **+ Filter** $\rightarrow$ 원하는 필터 조건 선택: `Folder` · `File` · `Tag` · `Status` · `Priority` · `Date` · `Text` · `Item type`
2. 생성된 행에서 조건 연산자와 값을 선택한 뒤 **Done** (또는 `Enter`) 클릭.
3. 설정된 필터 칩을 클릭하여 조건을 다시 수정하거나, **×**를 눌러 제거.
4. 맨 앞의 **Match all(모두 일치 - AND) / any(하나라도 일치 - OR) / none(모두 제외 - NOR)** 드롭다운으로 결합 방식 지정.
5. 복잡한 다중 조건이 필요하다면 **+ Filter $\rightarrow$ Group**을 추가하여 괄호 묶음 그룹 조건 생성 가능.

| 필터 항목 | 지원 연산 조건 |
| --- | --- |
| Folder (폴더) | `in` / `not in` + 볼트 폴더명 (자동완성 추천) |
| File (파일명) | `matches` / `does not match` + 파일명 |
| Tag (태그) | `contains` / `is` … + `urgent` (`#` 유무 상관없음, 서브태그 포함) |
| Status (상태) | `is` / `is not` + To do · In progress · Completed · Cancelled |
| Priority (우선순위) | `is` / `above (이상)` / `below (이하)` + 우선순위 |
| Date (날짜) | `is` / `before` / `after` + Today · Tomorrow · This week · This month · 특정 날짜, 또는 `is empty` / `is set` |
| Text (텍스트) | `contains` / `starts with` … + 텍스트 |
| Item type (종류) | Task (순수 할 일) / Google Calendar appointment (구글 일정) |

필터 패널을 닫으면 코드블록 내부에 YAML 형태로 깔끔하게 저장되며, 텍스트로 직접 수정할 수도 있습니다:

```yaml
filters:
  kind: group
  mode: all
  children:
    - kind: rule
      type: folder
      operator: contains
      value: "Work"
    - kind: rule
      type: status
      operator: notEquals
      value: "completed"
```

> 💡 **활용 팁**: 특정 프로젝트 노트 본문에 `Folder in Projects/Alpha` 필터를 건 Board 블록을 넣어두면, 해당 프로젝트 전용 맞춤 칸반 보드가 완성됩니다.

## 7. 자주 묻는 질문(FAQ) & 문제 해결

### Q1. 노트에 할 일을 썼는데 플래너에 나타나지 않아요.
- 줄의 시작이 정확히 `- [ ] ` 형태인지 확인하세요 (`*` 글머리 기호나 `1.` 번호 매기기는 지원하지 않습니다).
- 타임라인 시간표에는 **날짜가 있는 태스크**만 표시됩니다. 날짜가 없는 태스크는 사이드 드로어의 **Undated** 섹션이나 보드 뷰의 **Undated** 열에서 확인하세요.
- 설정 $\rightarrow$ General $\rightarrow$ **Excluded Files & Folders**에 해당 노트가 제외되어 있지 않은지 확인하세요.
- 싱크 동기화 프로그램 충돌로 생긴 복사본(`.sync-conflict-`가 포함된 파일명)은 자동으로 무시됩니다.
- 검색창이 켜져 있지는 않나요? `Esc`를 눌러 검색을 꺼보세요.
- 키보드 `F5`를 눌러 볼트를 새로고침해 보세요.

### Q2. 구글 토큰 갱신 시 "invalid_grant" 오류가 발생합니다.
리프레시 토큰이 만료되었거나 취소된 경우입니다.
- OAuth 동의 화면이 **테스트(Testing)** 상태이면 토큰이 **7일 만에 만료**됩니다. 동의 화면을 **프로덕션(In production)**으로 게시한 후, [2단계의 5단계](#5단계-리프레시-토큰refresh-token-발급-oauth-20-playground) 과정을 통해 새 리프레시 토큰을 발급받아 입력하세요.
- 구글 계정의 비밀번호를 변경했거나 구글 계정 보안 설정에서 앱 권한을 해제한 경우에도 토큰이 만료됩니다.

### Q3. "unauthorized_client" 또는 "invalid_client" 오류가 발생합니다.
- 복사한 클라이언트 ID나 시크릿 앞뒤에 불필요한 공백(스페이스)이나 줄바꿈이 들어가지 않았는지 확인하세요.
- 리프레시 토큰은 **반드시 해당 Client ID와 Secret을 이용해 발급된 토큰이어야** 합니다. Playground에서 *Use your own OAuth credentials*를 체크하지 않고 기본값으로 받은 토큰은 인증되지 않습니다.

### Q4. 구글 캘린더 일정이 안 보이거나 일부만 나타납니다.
- 설정 $\rightarrow$ ☁️ Google Calendar $\rightarrow$ **Google Calendars 📅** 목록에 해당 캘린더가 등록되어 있고 **체크박스가 켜져 있는지** 확인하세요.
- **Task Sync Google Calendar**로 지정된 캘린더의 일정은 중복 방지를 위해 화면에서 숨겨집니다. 미팅이나 약속이 들어있는 개인 캘린더를 동기화 캘린더로 지정하지 마세요.
- 헤더의 동기화 버튼(↻)을 누르거나 `F5`를 눌러 새로고침하세요.

### Q5. 노트 본문에서 시간을 바꿨는데 구글 캘린더에 바로 반영되지 않아요.
노트 파일에서 직접 텍스트를 타이핑하여 수정한 내용은 구글 캘린더로 즉각 전송되지 않습니다. 헤더의 **동기화(↻)** 버튼이나 `F5`를 한 번 눌러주세요.  
(Dayloom 타임라인에서 블록을 마우스로 드래그하거나 편집 모달창에서 수정한 내용은 즉시 전송됩니다.)

### Q6. 태스크 줄 끝에 붙는 `[gcalId:: …]`가 지저분해 보여요.
구글 캘린더의 일정과 해당 태스크를 연결해 주는 고유 링크이므로 삭제하시면 안 됩니다.  
대신 설정 $\rightarrow$ 📱 View/Display $\rightarrow$ **Hide Inline Metadata Fields**를 켜시면 화면상에서는 깔끔하게 숨겨집니다 (파일 본문에는 안전하게 유지됨).

### Q7. 알림이 울리지 않아요.
- 설정 $\rightarrow$ 🔔 Notifications $\rightarrow$ **Reminder Type**이 `Off`로 꺼져 있지 않은지 확인하세요.
- 해당 태스크가 **오늘 날짜**이고 **시작 시간(`⏰HH:mm`)**이 지정되어 있어야 합니다.
- 시스템 알림을 받으려면 운영체제 설정에서 옵시디언의 알림 권한이 허용되어 있어야 합니다 (권한이 없으면 Dayloom이 앱 내 팝업 공지로 대체합니다).
- 소리가 안 난다면 설정의 🔊 테스트 버튼을 눌러보세요. 모바일 기기의 경우 브라우저 정책상 화면을 한 번 터치하기 전까지는 소리 재생이 제한될 수 있습니다.

### Q8. 단축키가 동작하지 않아요.
- Dayloom 플래너 영역을 마우스로 한 번 클릭하여 **활성화된 뷰(Active View)**로 만들어 주세요.
- 텍스트 입력 필드(빠른 캡처, 검색창, 본문 에디터 등)에 커서가 들어가 있을 때는 글자 입력을 위해 단축키가 작동하지 않는 것이 정상입니다.
- `?` 단축키 창이 열려 있을 때 다시 `?`를 누르면 창이 닫힙니다.

### Q9. 특정 블록이 마우스로 드래그되지 않아요.
- 이미 **완료(`[x]`)되었거나 취소(`[-]`)된 태스크는 잠금 처리**되어 이동되지 않습니다. 체크박스를 눌러 미완료 상태로 돌린 후 이동하세요.
- 모바일 환경에서는 블록을 **약 0.35초간 롱프레스(길게 누름)**해야 집어 올릴 수 있습니다.

### Q10. 사이드 드로어가 보이지 않아요.
사이드 드로어는 **데스크톱 환경의 Dayloom 메인 뷰**에서만 제공됩니다. 키보드 `s`를 누르거나 헤더의 패널 아이콘(▣)을 클릭해 보세요.  
(사이드바의 Dayloom Compact나 모바일 기기에서는 화면 공간상 표시되지 않습니다.)

### Q11. 빠른 캡처로 등록한 할 일이 Undated(미지정)에 안 떠요.
설정의 **Default Task File Path**에 지정된 노트 파일명에 날짜(예: `2026-10-07.md`)가 포함되어 있다면, 데일리 노트로 인식되어 해당 날짜가 자동으로 부여됩니다.  
순수 미지정 태스크로 모으고 싶다면 날짜가 없는 일반 파일명(예: `Inbox.md` 또는 `Day Planner.md`)을 지정하세요.

### Q12. 실수로 일정을 옮기거나 삭제했어요. 되돌릴 수 있나요?
네! 일정을 이동하거나 삭제할 때마다 우측 상단 알림 팝업에 몇 초간 **Undo(실행 취소)** 버튼이 나타납니다. 여러 태스크를 한꺼번에 옮기거나 삭제했더라도 클릭 한 번으로 이전 상태로 완벽하게 되돌릴 수 있습니다.  
(단, 구글 캘린더에서 삭제된 구글 자체 일정은 복구되지 않습니다.)

### Q13. 내 구글 인증 정보는 어디에 저장되나요? 안전한가요?
클라이언트 시크릿과 리프레시 토큰은 사용자의 볼트 내부 `.obsidian/plugins/obsidian-day-planner-pro/data.json` 파일에만 로컬로 저장되며, 개발자 서버나 외부로 일체 전송되지 않습니다.  
만약 본인의 볼트를 깃허브 등에 공개(Public) 저장소로 올리신다면 해당 `data.json` 파일이 커밋되지 않도록 `.gitignore`에 등록해 두세요. 원치 않을 때는 언제든 구글 계정 설정 $\rightarrow$ 보안 $\rightarrow$ **타사 앱 및 서비스**에서 Dayloom의 접근 권한을 즉시 취소할 수 있습니다.

### Q14. 플러그인 언어가 이상하게 나와요.
설정 $\rightarrow$ General $\rightarrow$ **Language / 언어** 메뉴에서 변경하세요. `Auto`는 옵시디언 자체의 언어 설정을 따라가며, 원하는 언어(한국어, English 등)로 수동 고정할 수도 있습니다.
