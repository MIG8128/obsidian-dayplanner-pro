## 1. Dayloom이란? 핵심 개념

### 어떤 플러그인인가요?

Dayloom은 옵시디언 노트에 적힌 **체크박스 할 일(`- [ ]`)**들을 수집하여 시간표 형태의 일정으로 시각화해 주는 플러그인입니다.
할 일에 날짜와 시간을 입력하면 타임라인 위에 시간 블록으로 나타나며, 타임라인에서 블록을 마우스로 드래그하면 **노트 본문의 텍스트가 실시간으로 함께 변경**됩니다.
별도의 외부 데이터베이스 없이, 오직 사용자의 순수 마크다운(Markdown) 파일 안에서 모든 데이터가 관리됩니다.

### 주요 기능 한눈에 보기

| 기능 | 설명 |
| --- | --- |
| 6가지 보기 | 일간 타임라인, N일 보기(2~14일), 주간, 월간, 보드(기본 칸반 / 우선순위 집중), 목록 |
| 타임박싱 | 원하는 시간 슬롯으로 할 일 드래그 배치, 상·하단 핸들을 끌어 블록 크기(시간) 조절 |
| 어디서든 드래그 | 할 일을 잡고 놓지 않은 채 날짜, 주, 심지어 다른 보기(일간 → 월간 또는 보드)로 넘나들며 이동 |
| 사이드 서랍 | 미니 달력, 🎯 오늘의 핵심, 기한 지난 할 일, 날짜 없는 할 일, 일일 통계 (데스크톱 및 태블릿) |
| 검색 | `/` 또는 `Ctrl/Cmd+F`를 누르면 헤더가 검색창으로 확장, `Enter`를 누르면 목록 보기에서 일치 항목 일괄 표시 |
| 다중 선택 & 삭제 | Ctrl/Cmd+클릭 또는 영역 드래그 선택, `Delete`로 할 일 및 일정 일괄 삭제 (되돌리기 1회 지원) |
| 구글 캘린더 | 일정 확인, 편집, 생성 및 삭제, 시간이 지정된 할 일을 캘린더와 동기화 |
| 알림 | 시작 시점(또는 5~30분 전)에 앱 내 알림 또는 시스템 알림, 차임 소리 제공 |
| 터치 | 스마트폰, 태블릿, 터치스크린 노트북에서 길게 눌러 드래그, 스마트폰에서 스와이프로 날짜 전환 |
| 인라인 보기 | ```` ```dayloom ```` 코드블록을 통해 일반 노트 본문에 원하는 필터 조건으로 플래너 삽입 |
| Tasks 호환 | 옵시디언 Tasks 플러그인의 이모지 문법(📅 ⏳ 🛫 ✅ ❌ 🔁 🔺⏫🔼🔽⏬) 지원 |
| 테마 & 언어 | 옵시디언 테마 색상 반영, English, 한국어, 日本語, 简体中文 지원 |

### 두 가지 창: Dayloom과 Dayloom Compact

| 이름 | 여는 방법 | 설명 |
| --- | --- | --- |
| **Dayloom** | 리본 캘린더 아이콘 *Open Dayloom*, 또는 커맨드 `Open Dayloom` | 메인 플래너 탭입니다. 모든 보기와 (데스크톱 및 태블릿 환경) 사이드 서랍이 함께 제공됩니다. |
| **Dayloom Compact** | 리본 시계-캘린더 아이콘 *Open Dayloom Compact*, 또는 커맨드 `Open Dayloom Compact` | 우측 사이드바에 도킹되는 컴팩트 플래너입니다. 스마트폰용 레이아웃을 사용하며, 하단 바에 **일간 · 목록 · 월간 · 보드**와 **더보기**가 있습니다. |

> 💡 단축키 `Ctrl+P` (Mac은 `Cmd+P`)를 눌러 **커맨드 팔레트**를 연 뒤 "Dayloom"을 입력하면 관련된 모든 명령어를 확인할 수 있습니다:
> `Open Dayloom`, `Open Dayloom Compact`, `Go to Today`, `Toggle Side Drawer`, `Insert Inline View (dayloom block)`, `Show Keyboard Shortcuts`, `What's New (Release Notes)`.

### 기본 개념

- **할 일은 체크박스 한 줄입니다.** 본문에 `- [ ] 보고서 작성하기`라고 적기만 하면 Dayloom이 인식합니다.
- **날짜 기준**은 `⏳ 2026-10-07`(예정일) → `📅 2026-10-07`(마감일) → **데일리 노트의 파일명** 순서로 인식합니다.
  예를 들어 `2026-10-07.md` 데일리 노트 본문에 적힌 할 일은 별도 날짜 표기가 없어도 해당 날짜의 할 일로 처리됩니다.
- **시간 표기**는 `⏰09:00-10:30` 형태로 기록됩니다. 시간이 지정된 할 일은 타임라인에 시간 블록으로 배치되고, 시간이 없는 할 일은 상단 "종일" 행에 들어갑니다.
- **상태 구분**은 체크박스 내부 문자로 구분합니다: `[ ]` 할 일, `[/]` 진행 중, `[x]` 완료, `[-]` 취소됨.

### 새로운 기능

업데이트 후 **새로운 기능** 창이 변경 사항을 한 번 안내합니다. 언제든 커맨드 `What's New (Release Notes)`를 실행하거나 설정 → 일반의 **릴리스 노트 보기** 버튼을 눌러 다시 열어볼 수 있습니다.

## 2. 구글 캘린더 OAuth 2.0 연동 가이드

구글 캘린더 연동은 **선택 사항**입니다. 연동하지 않아도 Dayloom의 모든 할 일 관리 기능을 그대로 사용할 수 있습니다.

### Dayloom의 로그인 방식

Dayloom에는 별도의 **"Google 계정으로 로그인" 버튼이 없습니다.** 대신 설정에 세 가지 값을 직접 입력합니다:

| 설정 항목 | 설명 | 예시 형태 |
| --- | --- | --- |
| `구글 클라이언트 ID` | 직접 생성한 OAuth 앱의 ID | `xxxx.apps.googleusercontent.com` |
| `구글 클라이언트 보안 비밀` | 해당 앱의 비밀 키 | `GOCSPX-xxxx` |
| `구글 갱신 토큰` | 새 액세스 토큰을 받아오기 위한 오프라인 갱신 토큰 | `1//0xxxx` |

이 값들이 설정되면 Dayloom이 자체적으로 구글 토큰 엔드포인트(`https://oauth2.googleapis.com/token`)에 요청하여 단기 액세스 토큰을 발급받아 메모리에만 보관합니다.
따라서 사용자가 할 일은 **① Google Cloud에서 OAuth 앱을 만들고, ② 갱신 토큰(Refresh Token)을 한 번 발급받아 등록하는 것**입니다.
차근차근 진행하면 약 20~30분 정도 소요됩니다.

> ⚠️ Google Cloud 콘솔은 UI가 자주 변경됩니다. 메뉴 명칭이 조금 다르더라도 같은 의미의 항목을 찾아 진행해 주세요.

### 1단계: Google Cloud 프로젝트 생성

1. [Google Cloud Console](https://console.cloud.google.com/)에 접속하여 구글 계정으로 로그인합니다.
2. 상단의 **프로젝트 선택 드롭다운**을 클릭한 뒤 **새 프로젝트**를 누릅니다.
3. 프로젝트 이름에 알아보기 쉬운 이름(예: `Dayloom`)을 입력하고 **만들기**를 클릭합니다.
4. 상단 드롭다운에서 방금 만든 프로젝트가 선택되어 있는지 확인합니다.

### 2단계: Google Calendar API 활성화

1. 왼쪽 메뉴에서 **API 및 서비스 → 라이브러리**를 엽니다.
2. `Google Calendar API`를 검색하여 선택합니다.
3. **사용** 버튼을 클릭하여 활성화합니다.

### 3단계: OAuth 동의 화면 구성

(최신 콘솔에서는 **Google Auth Platform**으로 표시될 수 있습니다.)

1. **API 및 서비스 → OAuth 동의 화면**(또는 *Google Auth Platform → 브랜딩*)으로 이동하여 **시작하기**를 클릭합니다.
2. 앱 정보 입력:
   - **앱 이름**: `Dayloom` (원하는 이름 아무거나 가능)
   - **사용자 지원 이메일**: 본인의 구글 이메일 선택
3. **대상 / 사용자 유형(Audience)**: 개인 계정의 경우 **외부(External)**를 선택합니다.
4. 개발자 연락처 이메일을 입력하고 약관에 동의한 뒤 **저장 후 계속**을 누릅니다.
5. **테스트 사용자(Test users)** 항목에서 **본인의 구글 계정 이메일**을 추가합니다.

> ⚠️ **중요: 7일 만료 방지 안내**
> 앱 상태가 **테스트(Testing)** 상태이면 구글 정책상 갱신 토큰이 **7일 후 자동 만료**됩니다.
> 매주 토큰을 다시 발급받는 번거로움을 피하려면, 토큰을 발급받기 *전에* 동의 화면(대상 페이지)에서 **앱 게시(Publish app) → 프로덕션 환경(In production)**으로 전환하세요.
> 본인 혼자 사용하는 개인 앱은 구글의 별도 앱 확인(검수) 없이도 바로 게시할 수 있습니다. 로그인 시 "확인되지 않은 앱" 경고가 뜨면 **고급 → (앱 이름)으로 이동**을 클릭하여 계속 진행하면 됩니다.

### 4단계: OAuth 클라이언트 ID 및 보안 비밀 만들기

Dayloom 설정에서는 이를 *OAuth 웹 클라이언트*로 지정하므로, **웹 애플리케이션(Web application)** 유형으로 만듭니다.

1. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   (또는 *Google Auth Platform → 클라이언트 → 클라이언트 만들기*)를 엽니다.
2. **애플리케이션 유형**: `웹 애플리케이션(Web application)`
3. **이름**: 원하는 이름(예: `Dayloom Web Client`)
4. **승인된 리디렉션 URI**에 아래 주소를 정확히 추가합니다 (다음 단계에서 토큰 발급 도구로 쓰이는 구글 공식 도구 주소입니다):
   ```
   https://developers.google.com/oauthplayground
   ```
5. **만들기**를 클릭합니다. 화면에 표시되는 **클라이언트 ID**와 **클라이언트 보안 비밀**을 안전한 곳에 복사해 둡니다.

### 5단계: 갱신 토큰(Refresh Token) 발급 (OAuth 2.0 Playground)

1. [OAuth 2.0 Playground](https://developers.google.com/oauthplayground)에 접속합니다.
2. 우측 상단의 **톱니바퀴 아이콘(⚙️, OAuth 2.0 configuration)**을 클릭합니다.
   - **Use your own OAuth credentials** 체크박스를 켭니다.
   - 4단계에서 복사한 **OAuth Client ID**와 **OAuth Client secret**을 붙여넣습니다.
   - **Access type**이 `Offline`으로 설정되어 있는지 확인합니다 (오프라인이어야 갱신 토큰이 발급됩니다).
3. 왼쪽 화면의 **Step 1** 입력창(*Input your own scopes*)에 아래 권한 스코프를 입력합니다:
   ```
   https://www.googleapis.com/auth/calendar.events
   ```
   > Dayloom은 **일정 읽기, 생성, 수정, 삭제** 권한만 사용하므로 이 스코프 하나면 충분합니다.
4. **Authorize APIs** 버튼을 클릭하고, 3단계에서 테스트 사용자로 등록한 구글 계정으로 로그인한 뒤 권한을 허용합니다.
   (확인되지 않은 앱 경고가 뜨면 *고급 → ...으로 이동*을 클릭합니다.)
5. **Step 2** 화면으로 넘어가면 **Exchange authorization code for tokens** 버튼을 클릭합니다.
6. 우측 결과 창에서 **Refresh token**(`1//0`으로 시작) 값을 복사합니다. 이것으로 모든 준비가 끝났습니다! 🎉

> 🔒 클라이언트 보안 비밀과 갱신 토큰은 **비밀번호와 동일하게 안전하게 보관**해야 합니다. 외부에 절대 공유하지 마세요.

### 6단계: Dayloom 설정에 값 입력

1. 옵시디언 **설정(⚙️) → 커뮤니티 플러그인 → Dayloom**을 엽니다.
2. 상단 탭에서 **☁️ 구글 캘린더**를 선택합니다.
3. **구글 캘린더 연동 사용** 스위치를 켭니다.
4. **구글 캘린더 OAuth 2.0 (동기화 및 편집)** 섹션 아래에 복사한 값들을 입력합니다:
   - `구글 클라이언트 ID`
   - `구글 클라이언트 보안 비밀`
   - `구글 갱신 토큰`

   복사 시 들어간 불필요한 앞뒤 공백이나 줄바꿈은 자동으로 제거됩니다.

### 7단계: 표시할 캘린더 추가

1. 같은 탭의 **구글 캘린더 📅** 항목 옆 **+ 캘린더 추가** 버튼을 누릅니다.
2. 추가된 행의 정보를 설정합니다:
   - **체크박스**: 켜면 표시, 끄면 숨김
   - **이름**: Dayloom 화면에 표시될 이름 (예: 업무, 개인)
   - **ID**: 기본 캘린더는 `primary`, 보조 캘린더는 해당 캘린더의 ID 입력
   - **색상**: 타임라인에 표시될 일정 색상
3. 다른 캘린더의 ID를 찾는 방법:
   웹 브라우저에서 Google 캘린더 접속 → 해당 캘린더의 **⋮ 버튼 → 설정 및 공유 → 캘린더 통합 → 캘린더 ID** 복사
   (보통 `xxxx@group.calendar.google.com` 형태이며, 기본 캘린더 ID는 본인의 Gmail 주소입니다).
4. 불필요한 캘린더는 **삭제** 버튼으로 제거할 수 있습니다.

### 8단계: 할 일 동기화 캘린더 선택 (선택 사항)

**할 일 동기화 캘린더** 항목에서 캘린더를 지정하면, 날짜와 시간이 있는 모든 할 일이 해당 캘린더에 일정으로 자동 등록됩니다.

> 💡 **권장 사항**: 구글 캘린더 웹에서 `Obsidian Tasks` 등 **동기화 전용 캘린더**를 새로 만든 뒤 7단계에서 추가하고, 여기서 그 캘린더를 선택하세요.
> 일정 중복 표시를 방지하기 위해 Dayloom은 **동기화 대상 캘린더의 일정을 타임라인에 별도 일정으로 표시하지 않습니다** (이미 할 일로 표시되고 있기 때문입니다).
> 기본 캘린더(`primary`)를 선택하면 기존 미팅 일정들도 타임라인에서 숨겨지므로 주의하세요.

### 9단계: 연동 테스트

1. Dayloom 뷰를 엽니다.
2. 헤더의 **동기화** 버튼(↻)을 누르거나 `F5` 키를 누릅니다 (스마트폰 환경: **더보기 → 동기화**).
3. "✅ 동기화 완료! ..." 알림이 뜨고 타임라인에 구글 일정이 나타나면 성공입니다.
4. 실패할 경우 OAuth 오류 알림이 표시됩니다 → [자주 묻는 질문(FAQ)](#8-자주-묻는-질문faq--문제-해결)을 참고하세요.

### 동기화 동작 원리

| 동작 | 결과 |
| --- | --- |
| **동기화 버튼 / `F5` / `Ctrl+R` (`Cmd+R`)** | 볼트 내 할 일을 다시 읽고, 현재 화면의 캘린더 일정을 새로고침하며, 시간이 지정된 할 일을 동기화 캘린더로 전송합니다 (과거 60일부터 미래 365일까지). |
| **동기화 버튼 우클릭 (또는 길게 누르기)** | *할 일을 구글 캘린더와 동기화 📤* 대화상자가 열립니다: 대상 캘린더를 선택하고 **지금 동기화**를 누릅니다. |
| **Dayloom 안에서 할 일 수정** (드래그, 편집 창, 체크박스 등) | 해당 할 일의 변경 사항이 구글 캘린더에 즉시 반영됩니다. |
| **노트 본문에서 직접 텍스트 수정** | 자동으로 즉시 전송되지 않으며, 다음번 동기화 실행 시 전송됩니다. |
| 할 일의 날짜/시간 제거 | Dayloom이 생성했던 일정인 경우 캘린더에서도 일정이 삭제됩니다. |
| Dayloom에서 동기화된 할 일 삭제 | 구글 캘린더의 해당 일정도 함께 삭제됩니다. |

- 동기화된 할 일 줄 끝에는 `[gcalId:: …]` 속성이 추가됩니다. 구글 캘린더 일정과 연결해 주는 고유 ID이므로 지우지 마세요.
- 동기화는 **Dayloom이 직접 생성한 일정**만 삭제합니다. 사용자의 기존 회의나 초대받은 일정 등은 동기화로 인해 삭제되지 않습니다.
- 타임라인에서 구글 일정을 드래그하거나 크기를 바꾸거나 편집하면 구글 캘린더에 즉시 저장되며, **되돌리기** 알림 버튼이 제공됩니다.
- 한 번 불러온 일정은 캐시되므로 다음 실행 시 즉시 표시되며 백그라운드에서 최신 내용으로 갱신됩니다.

## 3. 설정 탭별 가이드

설정은 다섯 개의 탭으로 나뉘어 있습니다:

`⚙️ 일반` · `⏱️ 타임라인` · `☁️ 구글 캘린더` · `🔔 알림` · `📱 보기/표시`

> 설정 항목 명칭은 선택한 언어로 표시되며, 본 가이드에서는 한국어 명칭을 기준으로 설명합니다.

### ⚙️ 일반

| 설정 항목 | 기능 설명 | 추천값 |
| --- | --- | --- |
| **언어 / Language** | Dayloom의 표시 언어: `자동 감지(Obsidian 기본값)`, `English`, `한국어`, `日本語`, `简体中文`. 변경 즉시 적용 | `자동 감지` |
| **릴리스 노트** | **릴리스 노트 보기**를 누르면 현재 설치된 버전의 새로운 기능 창을 엽니다 | — |
| **기본 할 일 파일 경로** | 새 할 일을 빠르게 추가할 때 저장될 기본 마크다운 노트 (빠른 입력, 타임라인 더블 클릭). 파일이 없으면 자동 생성 | `Day Planner.md` (기본값) 또는 `Inbox/Tasks.md` |
| **제외할 파일 및 폴더** | 할 일 검색에서 제외할 폴더나 노트 (아래 설명 참조) | Templates, Archive |
| **데일리 노트 폴더 경로** | 데일리 노트가 보관되는 폴더 경로 | 예: `Daily` |
| **데일리 노트 파일명 형식** | 데일리 노트의 파일명 형식 | `YYYY-MM-DD` |
| **데일리 노트 템플릿** | 새 데일리 노트를 생성할 때 사용할 템플릿 파일 | 예: `Templates/Daily.md` |
| **주간 노트 폴더 경로** | 주간 노트가 보관되는 폴더 경로 | 예: `Weekly` |
| **주간 노트 파일명 형식** | 주간 노트의 파일명 형식 | `gggg-[W]ww` (예: `2026-W41`) |
| **주간 노트 템플릿** | 새 주간 노트를 생성할 때 사용할 템플릿 파일 | 예: `Templates/Weekly.md` |

템플릿 파일 내부에서는 `{{date}}`, `{{title}}`, `{{time}}` 치환자를 사용할 수 있습니다.

#### 🔎 경로 자동완성 제안

경로 입력창에 글자를 입력하면 볼트 내 파일과 폴더를 퍼지 검색으로 찾아 제안합니다 (예: `dly`만 입력해도 `Daily` 폴더 제안).
파일 필드는 마크다운 노트만, 폴더 필드는 폴더만 표시합니다.

#### 🚫 제외할 파일 및 폴더

규칙은 옵시디언의 검색 필터처럼 **칩(태그 형태)**으로 관리됩니다.

1. 입력창 왼쪽에서 **제외** 또는 **유지**를 선택합니다.
2. 폴더나 노트 이름을 입력하고 제안 목록에서 선택하거나 `Enter`를 누릅니다.
3. 규칙이 칩 형태로 추가됩니다:
   - 칩을 **클릭**하면 제외와 유지 상태를 토글할 수 있습니다.
   - 칩의 **×** 버튼을 눌러 규칙을 삭제합니다.
   - 볼트에 실제로 존재하지 않는 경로는 회색 취소선으로 표시됩니다.
4. 아래에 표시되는 "노트 N개 중 M개를 제외합니다." 요약에서 제외된 노트 수를 실시간으로 확인할 수 있습니다.

| 입력 예시 | 적용 대상 |
| --- | --- |
| `Archive` | Archive 폴더 및 그 안의 모든 하위 노트 |
| `Templates/Daily.md` (또는 `Templates/Daily`) | 해당 노트 1개 |
| `**/Templates` | 경로 깊이에 상관없이 이름이 `Templates`인 모든 폴더 |
| `Daily/*.md` | `Daily` 폴더 바로 아래의 노트들 (하위 폴더 제외) |
| `Archive` 제외 + **유지** `Archive/2026` | Archive 전체를 제외하되, 2026 하위 폴더만 포함 |

> `*`는 단일 폴더 레벨 내에서, `**`는 여러 폴더 레벨에 걸쳐 일치합니다. 대소문자는 구분하지 않습니다.

## 4. 사이드 서랍 & 타임박싱 워크플로우

**타임박싱(Timeboxing)**이란 각 할 일마다 특정 시간대를 배정하여, 그 일을 *언제* 실행할지 명확히 결정하는 생산성 방식입니다.
Dayloom의 사이드 서랍은 아직 스케줄을 잡지 않은 할 일들을 모아두고, 오늘의 핵심 과제와 진행률을 보여주며, 마우스로 끌어 일정표에 쉽게 배치할 수 있도록 돕습니다.

### 서랍 열고 닫기

- **데스크톱 및 태블릿**의 **Dayloom** 메인 뷰의 모든 탭(일, N일, 주, 월, 보드, 목록)에서 지원됩니다.
- 단축키 `s`를 누르거나, 헤더 끝의 **패널 아이콘(▣)**을 클릭하거나, 커맨드 `Toggle Side Drawer`를 실행하여 열고 닫습니다. 서랍 내부 우측 상단에도 닫기(⨯) 버튼이 있습니다.
- **창 폭이 좁은 경우** (900px 이하, 예: 화면 분할 상태나 세로 모드 태블릿): 화면을 억지로 좁히지 않고 플래너 위에 플로팅 카드 형태로 오버레이됩니다. 바깥을 클릭하면 닫히며, 플로팅 상태에서도 할 일을 드래그하여 서랍 안으로 넣을 수 있습니다.
- **스마트폰과 Dayloom Compact**에는 사이드 서랍이 없습니다: 동일한 할 일과 통계 기능이 하단 바의 **더보기** 바텀 시트 안에 포함되어 있습니다 ([6섹션](#6-터치-스마트폰-태블릿--터치스크린-노트북) 참조).

### 서랍 구조

```
┌ 2026년 10월 ▾         ‹ 오늘 ›     ⨯ ┐  ← 미니 달력 (보드 뷰에서는 오늘 날짜 표시)
│ 일  월  화  수  목  금  토            │
│ ... 6주간의 달력, 할 일 많은 날 점 표시 ...│
│ [ ☑ 할 일 8 │ ◔ 통계 62% ]            │  ← 모드 전환 스위치
├───────────────────────────────────────┤
│ [+ 날짜 없는 할 일 추가 (🔺 ⏫ ...)]    │  ← 빠른 입력
│ ▾ 📅 오늘 할 일         (4)           │  ← 🎯 오늘의 핵심 카드가 상단에 위치
│ ▾ 🚨 기한 지난 할 일    (3) [오늘로 옮기기]│
│ ▾ 📂 날짜 없는 할 일    (5)           │
└───────────────────────────────────────┘
```

### 미니 달력

- **날짜 클릭**: 플래너 화면이 해당 날짜로 이동합니다. 현재 화면에 표시 중인 기간은 띠 형태로 하이라이트되고, 오늘 날짜는 채워진 원으로 표시됩니다.
- **Ctrl/Cmd+클릭**: 해당 날짜의 데일리 노트를 바로 엽니다.
- **날짜 아래 점**: 주황색 = 남은 할 일, 빛나는 빨간색 = 🔺 최상 우선순위 할 일 포함, 초록색 = 모든 할 일 완료, 파란색 = 구글 캘린더 일정.
- **‹ ›** 버튼 또는 **마우스 휠 스크롤**: 월 단위로 이동하며, **오늘** 버튼으로 오늘 달력으로 돌아옵니다.
- **월 이름 클릭**: 달력을 1주일 단위로 접을 수 있습니다 (‹ › 이동도 주 단위로 전환). 접힘 상태는 기억됩니다.
- **날짜 위에 할 일 드롭**: 해당 날짜로 할 일이 이동합니다 (지정된 시간은 그대로 유지).
- **보드** 뷰에서는 미니 달력 대신 오늘 날짜가 표시되어 할 일 목록 영역을 더 넓게 활용할 수 있습니다.

### 할 일 모드

- **📅 오늘 할 일**: 오늘 날짜로 지정된 모든 할 일(시간 지정 여부 무관). 미완료 할 일이 먼저 나오고 시간순으로 정렬됩니다. 완료된 할 일은 제자리에서 체크를 해제할 수 있도록 회색으로 유지되며, `↗` 아이콘을 누르면 원본 노트가 열립니다. **할 일을 여기로 드롭**하면 날짜가 오늘로 변경됩니다.
- **🎯 오늘의 핵심** (오늘 할 일 최상단): 오늘 할 일 중 **🔺 최상** 우선순위를 가진 할 일들이 하이라이트된 FOCUS 카드로 표시됩니다. **어떤 할 일이든 핵심 슬롯으로 드롭**하면 즉시 오늘의 핵심 할 일로 지정됩니다 (날짜가 오늘로 바뀌고 우선순위가 🔺 최상으로 승격되며, 날짜 없던 할 일은 `📅` 오늘 날짜가 부여됨). 핵심 할 일이 없을 때도 드래그 중에는 드롭 슬롯이 자동으로 나타납니다.
- **🚨 기한 지난 할 일**: 오늘 이전 날짜의 미완료 할 일들로, 우선순위 → 오래된 날짜순 → 제목순으로 정렬되며 지난 날짜가 빨간색으로 표시됩니다.
- **📂 날짜 없는 할 일**: 날짜가 없는 할 일들(보드 뷰의 *날짜 없음* 열과 동일한 목록)로, 우선순위 → 제목순으로 정렬됩니다.
- 내용이 없는 빈 섹션은 **자동으로 접히고** 할 일이 생기면 다시 펼쳐집니다. 섹션 헤더를 클릭하여 직접 접을 수도 있습니다.
- **🔺 최상** 카드는 빨간 테두리와 은은한 빛, **⏫ 높음** 카드는 주황빛 테두리가 적용되며, 완료된 카드는 회색으로 바뀝니다.

### 통계 모드

플래너에 **현재 표시 중인 날짜**의 요약 정보를 제공합니다 (미니 달력에서 다른 날을 클릭하여 확인 가능):

- **진행률 링**: 계획된 시간 대비 완료된 시간의 비율 (시간이 지정된 할 일 기준, 취소된 항목 제외). 시간 지정 할 일이 없는 경우 완료된 할 일 개수 비율로 표시됩니다.
- **계획 / 완료 / 남음** 시간 요약.
- **완료된 할 일 수**, **완료된 핵심 할 일 수**, **캘린더 일정 소요 시간**, **우선순위별 분포**.
- 상황에 맞는 짧은 격려 메시지.

검색 필터가 켜져 있어도 통계는 필터링되지 않고 하루 전체 일정을 온전히 반영합니다.

### ① 빠른 입력 (Quick capture)

1. 서랍 상단의 입력창에 할 일 내용을 입력하고 `Enter`를 누릅니다.
2. **기본 할 일 파일 경로**로 지정된 노트에 날짜 없는 할 일로 즉시 추가되며, 알림 메시지가 뜹니다.
3. 입력 시 `⏫ 제안서 초안 작성`과 같이 우선순위 이모지를 포함하여 작성할 수 있습니다.
4. 한글, 일본어, 중국어 IME 입력 중에도 조합 완료 후 `Enter` 한 번으로 깔끔하게 저장됩니다.

### ② 우선순위 설정

카드의 우선순위 배지를 클릭하거나(우선순위가 없을 때는 호버 시 옅은 깃발 표시), 카드를 선택한 상태에서 `p` 키를 누릅니다.
🔺 최상, ⏫ 높음, 🔼 중간, ○ 보통, 🔽 낮음, ⏬ 최하 중에서 선택할 수 있습니다 (방향키와 `Esc` 지원). 선택한 이모지가 노트 본문에 즉시 기록됩니다.

### ③ 일정에 할 일 드래그 배치

| 드롭 위치 | 동작 결과 |
| --- | --- |
| **타임라인 시간 슬롯** (일간 / N일 / 주간) | 해당 날짜 및 시간(15분 단위)에 배치. 소요 시간: **기본 할 일 길이** |
| **월간 뷰 또는 미니 달력의 날짜** | 날짜만 변경 (기존 시간 유지; 시간 없던 할 일은 종일 유지) |
| **주간 / N일 뷰의 요일 헤더** | **빈 시간에 넣기(Fit It In)**: 해당 날의 첫 번째 빈 시간대에 자동 배치 |
| **보드 열** | 칸반 모드: 해당 열의 날짜(또는 완료); 우선순위 모드: 해당 우선순위 부여 |
| **📅 오늘 할 일** | 날짜를 오늘로 변경 (기존 시간 유지) |
| **🎯 오늘의 핵심** | 날짜를 오늘로 변경 + 우선순위를 🔺 최상으로 설정 |
| **서랍의 빈 영역** | 일정 해제 (날짜 및 시간 제거, 아래 ⑤ 참조) |

- 드래그 중 타임라인 위에서는 배치될 시간(예: `14:30`)을 보여주는 점선 미리보기가 나타납니다. 그 외 영역에서는 할 일 제목이 적힌 작은 칩이 마우스를 따라다니며 마우스 아래의 날짜, 열, 서랍 섹션이 하이라이트됩니다.
- 드래그 도중 `j` / `k` 키를 누르면 마우스를 놓지 않고도 다음/이전 날짜(또는 주)로 화면을 넘길 수 있습니다.
- 드래그 도중 보기 전환 단축키(`d`, `x`, `w`, `m`, `b`, `l`)를 누르면 다른 보기로 할 일을 그대로 들고 이동할 수 있습니다 (예: 일간 뷰에서 블록을 집어 들고 `m`을 눌러 월간 달력의 특정 날짜에 놓기).
- 드래그 도중 `Esc`를 누르면 드래그가 취소됩니다.
- 변경이 일어날 때마다 화면 하단에 **되돌리기(Undo)** 버튼이 포함된 알림이 나타납니다.

### ④ 여러 할 일을 연달아 배치

1. 서랍 카드들을 **Ctrl/Cmd+클릭**하거나, 목록의 빈 공간을 **마우스로 드래그하여 사각 상자**로 여러 카드를 선택합니다.
2. 선택된 카드 중 하나를 타임라인으로 드래그합니다.
3. 드롭한 시점부터 서랍에 정렬된 순서대로 **빈틈없이 연달아(back-to-back)** 배치됩니다. 각 할 일의 기존 길이를 유지하거나 기본 할 일 길이가 적용됩니다.
4. 자정을 넘어가게 되는 할 일은 무리하게 넘기지 않고 기존 자리에 유지됩니다. 한 번의 되돌리기로 전체 배치를 취소할 수 있습니다.

`Esc`를 누르면 서랍의 다중 선택이 해제됩니다.

### ⑤ 일정 해제 (날짜 및 시간 제거)

타임라인 블록, 종일 할 일, 월간 뷰 할 일, 보드 카드를 **서랍 영역으로 드래그**하면 날짜와 시간이 제거되어 '날짜 없음' 상태로 돌아갑니다.

- 시간, `⏳` 예정일, `📅` 마감일이 모두 본문에서 제거됩니다.
- **데일리 노트 안에 작성된 할 일**은 파일명 자체가 날짜이므로 날짜가 지워지지 않고 유지됩니다 (안내 알림 표시).
- 구글 캘린더 일정을 서랍으로 끌어와도 캘린더에서 삭제되지 않습니다.
- 실수 방지를 위해 기한 지남 및 오늘의 핵심 카드는 **날짜 없는 할 일 섹션 위로 정확히 드롭했을 때만** 일정이 해제됩니다.

### ⑥ 기한 지난 할 일 정리 (트리아지)

- 기한 지난 카드 위에 마우스를 올리면 빠른 액션 버튼이 나타납니다 (터치스크린에서는 상시 표시):
  `오늘로 옮기기` · `내일` · `+1주` · `날짜 해제`. 날짜만 변경되며 지정된 시간은 유지됩니다.
- 섹션 헤더의 **오늘로 옮기기** 버튼을 누르면 기한 지난 모든 할 일을 오늘로 한 번에 이동할 수 있습니다 (되돌리기 지원).

### ⑦ 서랍 카드의 키보드 조작

`Tab` 키를 눌러 서랍 카드에 포커스를 맞춘 뒤:

| 단축키 | 동작 |
| --- | --- |
| `Enter` | 할 일 내용 편집 |
| `f` | **빈 시간에 넣기(Fit It In)**: 향후 14일 이내의 첫 번째 빈 시간대에 자동 배치 |
| `p` | 우선순위 변경 메뉴 열기 |

빈 시간에 넣기는 **타임라인 시작/종료 시각**을 근무 시간으로 인식하며, 오늘 날짜는 현재 시각 이후의 빈 시간만 찾고, 기존 할 일 및 구글 캘린더 일정과의 겹침을 자동으로 피해 배치합니다. 들어갈 자리가 없으면 "빈 슬롯 없음" 알림이 뜹니다.

### 하루 추천 루틴 ☀️

1. 아침에 Dayloom을 열고 `s`를 눌러 사이드 서랍을 엽니다.
2. **기한 지난 할 일**을 확인하고 `오늘로 옮기기`, `내일` 또는 `날짜 해제`로 정리합니다.
3. 오늘 가장 중요한 일 1~2개를 골라 **🎯 오늘의 핵심**으로 드래그합니다.
4. 머릿속에 떠오르는 새로운 일들을 서랍의 **빠른 입력**에 적어 넣습니다.
5. **날짜 없는 할 일**에서 오늘 할 일들을 다중 선택해 타임라인으로 끌어 놓아 시간표에 연달아 배치합니다.
6. 블록 하단 핸들을 조절해 예상 소요 시간에 맞추고, 하루 일과가 끝나면 **통계**를 확인하며 마무리합니다.

## 5. 보기, 검색, 선택 & 단축키

### 6가지 보기

| 보기 (탭) | 단축키 | 주요 특징 |
| --- | --- | --- |
| **일** (일간) | `d` | 하루 단위 타임라인. 현재 시각선, 진행 중인 작업 표시 바, 상단 고정 "종일" 행 |
| **N일** | `x` | 2~14일을 나란히 비교 (탭 내부에서 일수 즉시 변경 가능) |
| **주** (주간) | `w` | 1주일 단위 타임라인. **요일 헤더를 클릭**하면 해당 날의 일간 뷰로 즉시 이동 |
| **월** (월간) | `m` | 한 달 달력. **날짜 셀을 클릭**하면 일간 뷰로 이동, **주차 번호를 클릭**하면 주간 뷰로 이동 |
| **보드** | `b` | *칸반* 모드(날짜 없음 · 기한 지남 · 오늘 · 내일 · 예정 · 완료됨) 및 *우선순위* 모드(최상 🔺 … 최하 ⏬, 미완료 할 일). `j` / `k` 키로 두 모드 전환 |
| **목록** | `l` | 이번 달 일정을 아젠다 형태로 나열. 검색 중에는 모든 날짜의 일치 항목을 한 번에 표시 |

- **보드** 뷰에서는 카드를 다른 열로 드래그하면 날짜가 변경됩니다 (오늘 → 오늘, 내일 → 내일, 예정 → 3일 뒤, 기한 지남 → 어제, 날짜 없음 → 날짜 제거, 완료됨 → 완료 처리; 완료됨에서 밖으로 빼면 다시 미완료로 복원). *우선순위* 모드에서는 드래그 시 해당 우선순위로 변경됩니다. 여러 카드를 선택해 함께 옮길 수도 있으며, 열 제목 좌측의 화살표로 열을 접을 수 있습니다.
- 보기 전환은 즉각적입니다: 모든 뷰가 메모리에 캐시되어 데이터 변경 시에만 다시 그려집니다.

### 헤더 구성 (데스크톱 및 태블릿)

```
[📅 날짜]     [ 일 | 4일 | 주 | 월 | 보드 | 목록 ]     [‹ 오늘 ›] [🔍 🔎 ↻ ? ▣] [+]
```

| 컨트롤 | 기능 설명 |
| --- | --- |
| 📅 날짜 알약 버튼 | 해당 일의 데일리/주간 노트를 엽니다 (일간 뷰에서 주차 번호 클릭 시 주간 노트 열림) |
| 보기 탭 | 보기를 전환합니다. 전환해도 보고 있던 날짜가 유지되며, 창 폭이 좁아지면 별도 행으로 줄바꿈됩니다 |
| ‹ 오늘 › | 이전 / 오늘 / 다음 (상시 오늘 기준인 보드 뷰 제외) |
| 🔍 줌 슬라이더 | 일간 / N일 / 주간 타임라인의 1시간 높이 조절: 마우스를 올리거나 클릭하면 슬라이더 표시 |
| 🔎 검색 | 할 일 및 구글 캘린더 일정 검색 (`/`) |
| ↻ 동기화 | 구글 캘린더와 동기화 (우클릭: 할 일 동기화 대화상자). 구글 캘린더 연동 활성화 시 표시 |
| ? 단축키 | 키보드 단축키 안내 창 (설정에서 숨김 가능) |
| ▣ 패널 | 사이드 서랍 열기 / 닫기 |
| **+** 추가 | 새 로컬 할 일 추가, 또는 새 구글 일정 추가 (*로컬 할 일 추가* / *일정 추가*) |

보드 뷰에서는 헤더에 **칸반 / 우선순위** 전환 스위치가 함께 나타납니다.
헤더, 메뉴, 대화상자는 사용 중인 옵시디언 테마의 색상을 그대로 따릅니다.

### 🔍 검색

1. `/` 또는 `Ctrl/Cmd+F`를 누르거나 검색 아이콘을 클릭합니다. 헤더 컨트롤들이 접히고 전체 너비의 검색창이 펼쳐집니다.
2. 검색어를 입력하면 현재 보기가 실시간으로 필터링됩니다. 할 일 본문( `#태그` 포함), 노트 파일 경로, 구글 일정 제목, 장소, 설명, 캘린더 이름을 모두 검색합니다. 띄어쓰기로 여러 단어를 입력하면 모든 단어가 포함된 항목을 찾습니다. 일치 개수가 우측에 표시됩니다.
3. **Enter** 키를 누르면 **목록** 뷰로 전환되며, **과거와 미래를 포함한 모든 날짜의 일치 항목**이 한 화면에 나타납니다.
4. **Esc** 키를 누르거나 **×** 버튼을 누르면 검색창이 닫히고 모든 항목이 다시 나타납니다.

날짜 없는 할 일은 목록 뷰에 포함되지 않으므로, 검색 중에는 일치하는 날짜 없는 할 일이 서랍의 '날짜 없는 할 일' 섹션에 필터링되어 나타납니다.

### ✅ 다중 선택 및 삭제

| 작업 | 실행 방법 |
| --- | --- |
| 항목 하나씩 추가/제외 | 항목을 **Ctrl/Cmd+클릭** (편집 창이 열리지 않고 선택만 토글) |
| 여러 항목 한 번에 상자 선택 | 빈 공간에서 **마우스 드래그로 사각 영역(Marquee)** 지정: 타임라인, 종일 행, 보드 열, 서랍 할 일 목록 |
| 기존 선택에 영역 추가 | `Ctrl`, `Cmd` 또는 `Shift`를 누른 상태에서 사각 영역 드래그 |
| 선택 해제 | 빈 곳 클릭, `Esc` 키 누르기, 또는 하단 선택 바의 × 버튼 클릭 |
| 선택 항목 일괄 이동 | 선택된 항목 중 하나를 드래그: 다른 항목들도 함께 이동 (타임라인 블록은 간격 유지, 서랍 카드는 연달아 배치) |
| 삭제 | `Delete` 또는 `Backspace` 키를 누르거나, 선택 바의 **선택한 항목 삭제** 버튼 클릭 |

- 선택 영역은 **한 구역**에 귀속됩니다: 타임라인 / 보드 / 월간 그리드, 종일 행, 또는 사이드 서랍 중 한 곳. 다른 영역에서 새로 선택하면 기존 선택은 초기화됩니다.
- **삭제** 시에는 안전을 위해 확인 창이 먼저 뜹니다 (`Enter` 확인, `Esc` 취소). 노트 본문에서 할 일 줄이 제거되고 구글 캘린더에서도 일정이 삭제됩니다. 삭제 후 표시되는 알림에서 **되돌리기(Undo) 버튼을 한 번 누르면** 구글 일정을 포함해 전체가 원래대로 복원됩니다.
- 할 일 및 일정 편집 대화상자에도 **삭제** 버튼이 제공됩니다 (대화상자에서 `Delete`/`Backspace`를 누를 때도 확인을 거치며, 텍스트 입력 중에는 삭제되지 않습니다).

### ⌨️ 키보드 단축키

> 단축키는 Dayloom 뷰가 활성화된 상태(클릭 한 번)에서 동작합니다. 빠른 입력, 검색창, 편집 창 등 텍스트 입력 필드에 커서가 있을 때는 단축키가 실행되지 않고 글자가 입력됩니다. `Ctrl/Cmd+R` 및 `Ctrl/Cmd+F`를 제외한 일반적인 조합 키는 옵시디언 기본 기능을 위해 보존됩니다.

| 키 | 동작 |
| --- | --- |
| `j` / `k` | 다음 / 이전 날짜 또는 기간 (데스크톱 보드: 칸반/우선순위 전환; 컴팩트 보드: 다음 / 이전 열) |
| `t` | 오늘로 이동 |
| `d` / `x` / `w` / `m` / `b` / `l` | 일간 / N일 / 주간 / 월간 / 보드 / 목록 보기 전환 |
| `s` | 사이드 서랍 열기 / 닫기 |
| `/` 또는 `Ctrl/Cmd+F` | 할 일 및 일정 검색 |
| `?` 또는 `h` | 단축키 목록 열기 / 닫기 |
| `F5` 또는 `Ctrl/Cmd+R` | 동기화 (할 일 다시 읽기 + 구글 캘린더 새로고침) |
| `Delete` / `Backspace` | 선택한 항목 삭제 |
| `Esc` | 드래그/크기 조절/상자 선택 취소 → 선택 해제 → 검색 닫기 순으로 취소 |
| `Ctrl/Cmd + 클릭` | 선택 항목에 추가 또는 제외 |
| `Ctrl/Cmd + 드래그` | 사각 상자 드래그로 선택 항목에 추가 |
| `Enter` / `f` / `p` (서랍 카드 선택 시) | 편집 / 빈 시간에 넣기 / 우선순위 설정 |
| `j` / `k` / 보기 단축키 (드래그 중) | 할 일을 놓지 않고 날짜 넘기기 또는 보기 전환 |

### 🖱️ 마우스 조작

| 작업 | 마우스 동작 |
| --- | --- |
| 할 일 편집 | 블록 본문 클릭 → 편집 창 열림 |
| 완료 처리 | 체크박스 클릭 (완료 ↔ 할 일 토글; 진행 중 등 다른 상태는 완료로 변경). 다른 상태는 편집 창에서 선택 |
| 원본 노트 열기 | 블록의 `↗` 링크 아이콘 클릭 |
| 할 일 이동 | 블록을 잡고 다른 시간이나 다른 날짜로 드래그 (15분 단위) |
| 소요 시간 조절 | 블록의 **상단 또는 하단 핸들 바**를 잡고 위아래로 드래그 |
| 새 할 일 생성 | 빈 시간 슬롯을 **더블 클릭** → 제목 입력(우선순위 이모지 지원) → `Enter` (`Esc`는 취소). 기본 할 일 파일에 저장됨 |
| 컨텍스트 메뉴로 생성 | 빈 슬롯 **우클릭** → `HH:MM에 할 일 추가` / `HH:MM에 일정 추가` (구글 캘린더) |

> 🔒 **완료(`[x]`) 및 취소(`[-]`)된 할 일은 안전을 위해 잠깁니다**: 마우스로 드래그하거나 크기를 바꿀 수 없습니다 (클릭하여 편집 창을 열 수는 있습니다).
> 구글 캘린더 일정 블록은 제목 아래에 회색 글씨로 장소와 설명이 함께 표시됩니다.

### 상태 표시줄 (Status bar)

옵시디언 창 하단 상태 표시줄에 현재 진행 중인 할 일(`📅 [진행 중: …] … 남음`, 진행률 바 포함) 또는 다음 예정된 할 일(`📅 [다음 예정: …] … 남음`)이 실시간으로 표시됩니다.

## 6. 터치: 스마트폰, 태블릿 & 터치스크린 노트북

### 길게 눌러 드래그 (모든 터치스크린 기기)

터치스크린에서는 짧은 터치 스와이프가 화면 스크롤로 동작하므로, 할 일을 집어 올리려면 **약 0.3초간 길게 누르기(Long-press)**를 사용합니다:

1. 블록이나 카드가 살짝 떠오를 때까지 **길게 누릅니다** (기기가 지원하는 경우 가벼운 햅틱 진동 발생).
2. 손가락을 떼지 않고 **원하는 위치로 드래그**합니다: 마우스로 할 수 있는 모든 작업(서랍, 월간 달력, 보드 열 등)이 동일하게 지원됩니다.
3. 손가락을 떼면 그 자리에 배치됩니다. 이동하지 않고 제자리에서 손을 떼면 원래 위치로 돌아갑니다.

타임라인 블록을 길게 누르면 블록 상·하단에 **크기 조절 바**가 함께 표시됩니다: 상단이나 하단 바를 드래그하여 시간을 늘리거나 줄일 수 있습니다. 크기 조절 바가 표시된 상태에서는 블록 가운데를 터치해 바로 드래그할 수도 있습니다. 다른 빈 곳을 탭하면 조절 모드가 종료됩니다.

한 손가락으로 할 일을 누르고 있는 상태에서, **다른 손가락으로 보기 탭이나 날짜 이동 화살표, 날짜 알약을 탭**하면 다른 보기나 다른 날짜로 할 일을 들고 이동할 수 있습니다.

### 터치스크린 노트북

Dayloom은 손가락 터치와 마우스/트랙패드를 지능적으로 구분합니다:

- **손가락 터치**: 위 설명처럼 길게 눌러 드래그하며, 짧게 문지르면 스크롤됩니다.
- **마우스 / 트랙패드 / 펜**: 일반 데스크톱처럼 즉시 드래그할 수 있습니다. 블록에 마우스를 올리면 크기 조절 바가 나타납니다.

### 스마트폰 (및 Dayloom Compact)

- **하단 바**: **일간 · 목록 · 월간 · 보드** 4개 탭과 **더보기** 버튼으로 구성됩니다 (주간 및 N일 보기는 메인 Dayloom 뷰에서 지원).
- **헤더**: 날짜, **‹ 오늘 ›** 이동 버튼, **+** 추가 버튼이 배치됩니다.
- **날짜 스트립**: 일간 및 목록 뷰의 헤더 아래에 1주일 날짜 알약이 표시되어, 원하는 날을 탭해 바로 이동할 수 있습니다.
- **스와이프 날짜 이동**: 플래너 내부를 좌우로 스와이프하여 날짜(보드에서는 열)를 넘길 수 있습니다. 화면 맨 가장자리에서 시작하는 스와이프는 옵시디언 고유 사이드바를 정상적으로 엽니다. 이 기능은 설정 → 보기/표시에서 끌 수 있습니다.
- **목록 뷰**: 하루 일정을 아젠다 형태로 깔끔하게 보여줍니다 (왼쪽 시작 시각, 색상 레일, 소요 시간, 저장된 노트 파일명, 완료 통계 요약).
- **월간 뷰**: 날짜 셀 크기에 맞춰 들어가는 만큼 일정이 표시되고 초과분은 `+N`으로 나타납니다. 날짜를 탭하면 일간 뷰로 이동합니다.
- **보드 뷰**: 한 번에 한 열씩 큼직하게 보여주며, 상단 스트립 탭이나 좌우 스와이프로 열을 넘깁니다.
- **더보기**: 탭하면 바텀 시트가 열리며 **검색**, **동기화**(길게 누르면 세부 옵션), **타임라인 확대/축소** 슬라이더, 그리고 서랍의 **할 일** 및 **통계** 패널(오늘 할 일, 오늘의 핵심, 기한 지난 할 일, 날짜 없는 할 일)이 제공됩니다. 바깥을 탭하거나 아래로 쓸어내리거나 `Esc`를 누르면 닫힙니다.
- **더블 탭**: 빈 시간 슬롯을 두 번 탭하여 새 할 일을 추가합니다.

### 태블릿

태블릿에서는 사이드 서랍을 포함한 전체 데스크톱 레이아웃이 그대로 제공되며, 롱프레스 터치 드래그를 지원합니다. 트랙패드, 마우스, Apple Pencil을 사용할 경우 데스크톱처럼 즉시 드래그됩니다.

## 7. 할 일 문법 & 인라인 코드블록

### 기본 문법

```markdown
- [ ] 할 일 제목 ⏰09:00-10:30 ⏫ 🔁 every week ⏳ 2026-10-07 📅 2026-10-10
```

| 구성 요소 | 문법 표기 | 설명 |
| --- | --- | --- |
| 상태 | `[ ]` `[/]` `[x]` `[-]` | 할 일 / 진행 중 / 완료 / 취소됨 |
| 시간 | `⏰09:00-10:30` | 시작–종료. 종료 시간이 없으면(`⏰09:00`) 기본 30분으로 표시 |
| 우선순위 | 🔺 ⏫ 🔼 🔽 ⏬ | 최상 / 높음 / 중간 / 낮음 / 최하 (없으면 보통) |
| 예정일 | `⏳ YYYY-MM-DD` | Dayloom에서 일정을 잡을 때 기록되는 기준 날짜 |
| 마감일 | `📅 YYYY-MM-DD` | 예정일이 없을 때 차순위로 사용되는 날짜 |
| 시작일 | `🛫 YYYY-MM-DD` | 옵시디언 Tasks 플러그인 호환용 |
| 완료 / 취소일 | `✅ YYYY-MM-DD` / `❌ YYYY-MM-DD` | 할 일을 완료하거나 취소할 때 자동으로 기록됨 |
| 반복 | `🔁 every day` 등 | 완료 체크 시 다음 일정이 새 줄로 자동 생성됨 |
| 구글 링크 | `[gcalId:: …]` | 구글 동기화 시 자동 부여 (직접 수정하지 마세요) |

#### 다양한 시간 표기 형식

Dayloom은 아래와 같은 다양한 시간 형식도 인식합니다:

```markdown
- [ ] 09:00 - 10:00 회의          ← 제목 앞에 시간
- [ ] 회의 [09:00-10:00]          ← 대괄호 표기
- [ ] 회의 [startTime:: 09:00 - 10:00]
```

#### 날짜 인식 우선순위

`⏳ 예정일` → `📅 마감일` → **노트의 파일명에 포함된 날짜** (데일리 노트).
예를 들어 `Daily/2026-10-07.md` 노트 본문에 `- [ ] 운동 ⏰07:00-08:00`이라고만 적어도 10월 7일 07:00 블록으로 배치됩니다.

#### 반복 규칙

`every day` (`daily`), `every week` (`weekly`), `every month` (`monthly`), `every year` (`yearly`), `every weekday`(평일 매일), 그리고 `every N day/week/month/year`(예: `every 3 days`).

### 인라인 코드블록: ```` ```dayloom ````

일반 마크다운 노트 본문 어디에나 Dayloom 플래너를 직접 삽입할 수 있습니다. 커맨드 팔레트에서 **Insert Inline View (dayloom block)**를 실행하면 쉽게 삽입할 수 있습니다.

````markdown
```dayloom
type: daily
height: 500px
```
````

> 이전 버전의 코드블록 명칭인 ```` ```dayplanner ```` 및 ```` ```dayplanner-pro ````도 계속 호환됩니다.

| 옵션 | 설정 가능 값 | 설명 |
| --- | --- | --- |
| `type` | `daily` · `multiDay` · `weekly` · `monthly` · `board` · `list` | 표시할 보기 유형. 블록 내부의 탭을 클릭하면 자동으로 이 값이 갱신됩니다 |
| `date` | `YYYY-MM-DD` 또는 `today` | 표시할 기준 날짜 |
| `height` | `500px`, `80vh` 등 (단위 없는 숫자는 px) | 블록 높이. 블록 하단 가장자리를 마우스로 끌어 높이를 조절하면 자동 저장됩니다 |
| `hourHeight` | 숫자 | 이 블록에만 적용할 타임라인 1시간 높이 |
| `showFilters` | `true` | 필터 패널이 열린 상태로 시작 |
| `collapsedColumns` | `[undated, completed]` | 기본으로 접어둘 보드 열 목록 |
| `filters` | (필터 패널에서 자동 기록) | 아래 필터 섹션 참조 |

- **데일리 노트** 안에 `type`이나 `date`가 없는 블록을 넣으면 자동으로 해당 날짜가 표시되며, **주간 노트** 안에 넣으면 해당 주가 표시됩니다. 또한 그 날짜/주에 해당하는 항목들만 깔끔하게 나열됩니다.
- 인라인 블록 내부에서는 요일 헤더, 날짜, 주차 번호를 클릭하면 해당 데일리/주간 **노트**가 열립니다 (인라인 블록 자체에는 전환 탭이 없기 때문). 목록 뷰에는 자체 아젠다 검색창이 제공됩니다.
- 블록 내부에서도 메인 뷰와 동일하게 마우스 드래그가 동작하며, 화면에 보일 때만 렌더링되어 성능이 최적화됩니다.

### 🔍 인라인 블록 필터

블록 헤더의 **🔍 필터** 버튼을 클릭하면 한 줄짜리 필터 바가 열립니다. 버튼에는 적용 중인 필터 개수(예: `🔍 필터 · 2`)가 표시됩니다.

```
[모두 일치 ▾] [📁 폴더 = Work ×] [# 태그 포함 #urgent ×] [+ 필터]
```

1. **+ 필터** → 필터 종류 선택: `폴더` · `파일` · `태그` · `상태` · `우선순위` · `날짜` · `텍스트` · `항목 종류`
2. 열리는 편집 행에서 조건과 값을 선택한 뒤 **완료**를 누릅니다 (또는 `Enter`).
3. 칩을 클릭해 언제든 조건을 수정할 수 있고, `×`를 눌러 삭제합니다.
4. 맨 앞의 **모두 일치 / 하나라도 일치 / 일치하지 않는 것** 드롭다운으로 결합 방식을 지정합니다.
5. 더 복잡한 조건이 필요하면 **+ 필터 → 그룹 (조건 중 하나라도 일치...)**을 선택해 괄호로 묶인 조건 그룹을 추가할 수 있습니다.

| 필터 종류 | 조건 옵션 |
| --- | --- |
| 폴더 | `포함` / `포함하지 않음` + 폴더명 (자동완성 제안 지원) |
| 파일 | `일치` / `일치하지 않음` + 파일명 |
| 태그 | `포함` / `일치` 등 + `urgent` (`#`는 생략 가능, 하위 태그 포함) |
| 상태 | `일치` / `일치하지 않음` + 할 일 · 진행 중 · 완료 · 취소됨 |
| 우선순위 | `일치` / `이상` / `이하` + 우선순위 |
| 날짜 | `일치` / `이전` / `이후` + 오늘 · 내일 · 이번 주 · 이번 달 · 특정 날짜, 또는 `비어 있음` / `지정됨` |
| 텍스트 | `포함` / `시작` 등 + 텍스트 |
| 항목 종류 | 할 일 / 구글 캘린더 일정 |

필터는 편집하는 동안 실시간으로 적용됩니다. 필터 패널을 닫으면 코드블록 내부에 YAML 형식으로 자동 저장됩니다 (직접 손으로 수정할 수도 있습니다):

```yaml
filters:
  kind: group
  mode: all
  children:
    - kind: rule
      type: folder
      operator: contains
      value: "Work"
    - kind: rule
      type: status
      operator: notEquals
      value: "completed"
```

> 💡 팁: 프로젝트 노트 본문에 `Folder in Projects/Alpha` 필터를 건 보드 블록을 삽입하면 해당 프로젝트만을 위한 전용 칸반 보드가 완성됩니다.

## 8. 자주 묻는 질문(FAQ) & 문제 해결

### Q1. 할 일이 플래너에 나타나지 않아요.

- 체크박스 줄이 정확히 `- [ ] `로 시작하는지 확인하세요 (`*` 기호나 번호 매기기 목록은 인식되지 않습니다).
- 타임라인은 **날짜가 있는 할 일**만 표시합니다. 날짜가 없는 할 일은 서랍의 **날짜 없는 할 일** 섹션이나 보드 뷰의 **날짜 없음** 열을 확인하세요.
- 설정 → 일반 → **제외할 파일 및 폴더**에 해당 노트가 포함되어 있지 않은지 확인하세요.
- 동기화 도구(Syncthing 등)가 생성한 충돌 파일(`.sync-conflict-`가 포함된 파일명)은 의도적으로 제외됩니다.
- 검색창이 켜져 있는지 확인하세요. `Esc` 키를 눌러 검색을 닫아보세요.
- `F5` 키를 눌러 볼트 전체를 다시 스캔해 보세요.

### Q2. 노트 본문에 글을 쓰는 동안 플래너가 바로 갱신되지 않아요.

부드럽고 쾌적한 타이핑 환경을 위해 의도된 동작입니다: Dayloom은 사용자가 **타이핑을 멈추고 약 2초가 지난 뒤** 노트를 다시 읽고 플래너를 갱신합니다.

### Q3. 구글 토큰을 갱신할 때 "invalid_grant" 오류가 발생해요.

구글 갱신 토큰(Refresh Token)이 만료되었거나 취소된 경우입니다.

- OAuth 동의 화면이 **테스트(Testing)** 상태인 경우 토큰이 **7일 후 자동 만료**됩니다. 동의 화면을 **프로덕션 환경(In production)**으로 전환한 뒤, [5단계](#5단계-갱신-토큰refresh-token-발급-oauth-20-playground)에 따라 새 갱신 토큰을 다시 발급받으세요.
- 구글 계정 비밀번호를 변경했거나, 구글 계정 보안 설정에서 해당 앱의 접근 권한을 삭제한 경우에도 기존 토큰이 무효화됩니다.

### Q4. "unauthorized_client" 또는 "invalid_client" 오류가 발생해요.

- 클라이언트 ID와 클라이언트 보안 비밀이 글자 누락 없이 정확하게 복사되었는지 확인하세요.
- 갱신 토큰은 **반드시 해당 클라이언트 ID 및 보안 비밀로 발급받은 것**이어야 합니다. Playground에서 *Use your own OAuth credentials*를 체크하지 않고 기본 자격 증명으로 발급받은 토큰은 작동하지 않습니다.

### Q5. 구글 캘린더 일정이 보이지 않거나 일부만 나타나요.

- 설정 → ☁️ 구글 캘린더 → **구글 캘린더 📅** 목록에서 해당 캘린더가 등록되어 있고 **체크박스가 켜져 있는지** 확인하세요.
- **할 일 동기화 캘린더**로 지정된 캘린더의 일정은 중복 방지를 위해 플래너에 별도 일정으로 표시되지 않습니다. 회의 등이 들어 있는 개인 캘린더를 동기화 캘린더로 지정하지 마세요.
- 동기화 버튼(↻)을 누르거나 `F5` 키를 눌러 새로고침해 보세요.

### Q6. 노트에서 시간을 수정했는데 구글 캘린더에 바로 반영되지 않아요.

노트 본문에서 직접 텍스트로 수정한 내용은 구글 API로 자동 즉시 전송되지 않습니다. 헤더의 **동기화(↻)** 버튼이나 `F5`를 한 번 눌러주세요.
Dayloom 플래너 화면 안에서 블록을 드래그하거나 편집한 내용은 즉시 구글 캘린더로 전송됩니다.

### Q7. 할 일 끝에 붙는 `[gcalId:: …]`가 지저분해 보여요.

이 필드는 할 일과 구글 캘린더 일정을 연결해 주는 필수 식별자이므로 삭제하면 안 됩니다. 대신 설정 → 📱 보기/표시 → **인라인 메타데이터 필드 숨기기**를 켜면 파일 내용은 보존하면서 화면에서만 깔끔하게 숨길 수 있습니다.

### Q8. 시작 알림이 오지 않아요.

- 설정 → 🔔 알림 → **알림 방식**이 `끄기`로 되어 있지 않은지 확인하세요.
- 해당 할 일에 **오늘 날짜**와 **시작 시간(`⏰HH:mm`)**이 정확히 들어가 있는지 확인하세요.
- 시스템 알림을 사용하려면 운영체제의 알림 권한 허용이 필요합니다. 거부하셨다면 OS 설정에서 옵시디언의 알림 권한을 켜주세요 (권한이 없으면 Dayloom이 앱 내 알림으로 대체합니다).
- 차임 소리가 들리지 않는다면 🔊 테스트 버튼을 눌러보세요. 모바일 기기의 경우 브라우저/앱 정책상 화면을 한 번 이상 터치해야 소리 재생이 허용될 수 있습니다.

### Q9. 단축키가 작동하지 않아요.

- Dayloom 플래너 영역을 마우스로 한 번 클릭하여 **활성 뷰**로 만들어 주세요.
- 빠른 입력창, 검색창, 에디터 등 텍스트 입력 칸에 커서가 깜빡이고 있을 때는 글자가 입력되며 단축키가 동작하지 않습니다 (정상 동작).
- `?` 키를 한 번 더 누르면 열려 있던 단축키 도움말 창이 닫힙니다.

### Q10. 타임라인 블록이 드래그되지 않아요.

- 완료(`[x]`)되었거나 취소(`[-]`)된 할 일은 안전을 위해 잠깁니다. 체크를 해제하면 다시 이동할 수 있습니다.
- 터치스크린에서는 빠른 스와이프가 스크롤로 동작하므로, 블록을 **약 0.3초간 길게 누른 뒤** 드래그해야 합니다.

### Q11. 사이드 서랍이 보이지 않아요.

사이드 서랍은 **데스크톱 및 태블릿의 Dayloom 메인 뷰**에서 제공됩니다. `s` 키를 누르거나 헤더 우측의 패널 아이콘(▣)을 클릭해 보세요.
스마트폰 환경이나 우측 사이드바의 Dayloom Compact에서는 하단 바의 **더보기** 시트 안에 동일한 패널들이 들어 있습니다.

### Q12. 서랍이 타임라인 화면을 가려요.

플래너 창 폭이 900px 이하일 때는 화면이 지나치게 좁아지는 것을 방지하기 위해 서랍이 플로팅 카드 오버레이로 뜹니다. 서랍 바깥을 클릭하거나 `s` 키를 눌러 닫을 수 있으며, 창 너비를 넓히면 다시 화면 옆에 고정(도킹)됩니다.

### Q13. 빠른 입력으로 추가한 할 일이 '날짜 없음'에 나타나지 않아요.

설정의 **기본 할 일 파일 경로**로 지정된 노트의 파일명에 날짜가 포함되어 있는 경우(예: `2026-10-07.md`), 추가된 할 일이 해당 날짜의 할 일로 인식됩니다. 날짜가 포함되지 않은 파일명(예: `Inbox.md` 또는 `Day Planner.md`)을 지정하세요.

### Q14. 실수로 일정을 옮기거나 삭제했어요. 되돌릴 수 있나요?

네. 일정을 변경하거나 삭제할 때마다 화면 하단에 몆 초간 **되돌리기(Undo)** 버튼이 있는 알림이 뜹니다. 여러 항목을 한꺼번에 이동하거나 삭제했더라도 한 번에 원상복구되며, 함께 삭제되었던 구글 캘린더 일정도 동일한 일정으로 다시 복원됩니다.

### Q15. 구글 계정 인증 정보는 어디에 저장되나요? 안전한가요?

클라이언트 보안 비밀과 갱신 토큰은 사용자의 볼트 폴더 내부 `.obsidian/plugins/obsidian-day-planner-pro/data.json` 파일에 로컬로 안전하게 저장됩니다. 단기 액세스 토큰은 메모리에만 유지되며 디스크에 기록되지 않습니다. 가져온 일정 캐시는 같은 위치의 `gcal-cache.json`에 보관됩니다.
볼트 전체를 공개 GitHub 저장소 등에 업로드(퍼블리시)할 때는 이 설정 파일들이 외부에 노출되지 않도록 `.gitignore` 등으로 제외하세요.
연동을 완전히 해제하려면 구글 계정 설정 → 보안 → **타사 앱 및 서비스**에서 Dayloom 앱의 연결을 삭제하면 됩니다.

### Q16. Syncthing 등으로 볼트를 동기화하고 있어요. 주의할 점이 있나요?

Dayloom은 설정이 실제로 변경되었을 때만 `data.json`을 다시 쓰고, 다른 기기에서 수신된 최신 `data.json`을 자동으로 감지해 반영하며, `.sync-conflict-`가 붙은 충돌 복사본 파일들은 안전하게 무시합니다. 동기화 도중 파일이 잠겨 `data.json`을 읽을 수 없는 순간에는 기존 파일을 덮어쓰지 않고 안전하게 기본값으로 동작합니다.

### Q17. Dayloom의 언어나 색상이 이상하게 나와요.

- 언어: 설정 → 일반 → **언어 / Language**를 확인하세요. `자동 감지`는 옵시디언의 자체 언어 설정을 따르며, 원하는 언어로 고정할 수도 있습니다.
- 색상은 사용 중인 옵시디언 테마를 따릅니다. 할 일 블록은 **로컬 할 일 색상**을 사용하며, 각 구글 캘린더는 설정(설정 → ☁️ 구글 캘린더)에서 지정한 고유 색상으로 표시됩니다.
