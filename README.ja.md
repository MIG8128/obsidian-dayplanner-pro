## 1. Dayloom とは？ 基本コンセプト

### どんなプラグイン？

Dayloom は、Obsidian のノートに書かれた **チェックボックスタスク（`- [ ]`）** を自動収集し、タイムライン形式のスケジュールとして可視化するプラグインです。  
タスクに日付と時間を指定するとタイムライン上に時間ブロックとして現れ、タイムライン上でブロックをドラッグすると **ノート本文のテキストがリアルタイムに書き換わります。**  
外部のデータベースは一切使わず、すべてあなた自身の純粋な Markdown ファイル内で安全に管理されます。

### 主な機能一覧

| 機能 | 説明 |
| --- | --- |
| 6 つのビュー | 日タイムライン、N日ビュー（2〜14日）、週ビュー、月カレンダー、ボード（標準カンバン / 優先度フォーカス）、リストビュー |
| タイムブロッキング | 目的の時間枠へタスクをドラッグ配置、上下ハンドルで所要時間を伸縮調整 |
| サイドドロワー | ミニカレンダー、🎯 今日のフォーカス、期限切れのタスク、日付なしのタスク、日別統計パネル（デスクトップの全ビューで利用可能） |
| 展開式検索 | `/` キーでヘッダー全体が検索バーに展開、Enter でリストビューへ移行し一致項目を一括表示 |
| 複数選択＆削除 | 全ビューで Ctrl/Cmd+クリックおよびマウス枠囲み選択に対応、Delete キーで一括削除（元に戻す対応） |
| Google カレンダー | 予定の閲覧・編集・作成、および指定カレンダーとの双方向タスク同期 |
| 開始前リマインダー | 開始時刻（または 5〜30 分前）にアプリ内通知やシステム通知でお知らせ（チャイム音付き） |
| インラインビュー埋め込み | ```` ```dayloom ```` コードブロックで任意のノート本文にフィルター付きプランナーを埋め込み |
| Tasks プラグイン互換 | Obsidian Tasks プラグインの標準絵文字構文（📅 ⏳ 🛫 ✅ ❌ 🔁 🔺⏫🔼🔽⏬）と完全互換 |
| 多言語対応 | English、한국어、日本語、简体中文に対応（Obsidian の言語自動検出または手動選択） |

### 2 つのウィンドウ：Dayloom と Dayloom Compact

| 名称 | 開き方 | 説明 |
| --- | --- | --- |
| **Dayloom** | リボンのカレンダーアイコン *Open Dayloom*、またはコマンド `Open Dayloom` | メインのプランナータブです。デスクトップではサイドドロワーが付属します。 |
| **Dayloom Compact** | リボンの時計カレンダーアイコン *Open Dayloom Compact*、またはコマンド `Open Dayloom Compact` | 右サイドバーにドッキングされるコンパクトビューです。下部 5 つのタブ（日 · 2日ビュー · 月 · ボード · リスト）で構成されます。 |

> 💡 `Ctrl+P`（Mac は `Cmd+P`）で **コマンドパレット** を開き、"Dayloom" と入力すると関連コマンド一覧を確認できます。

### 基本の仕組み

- **タスクはチェックボックス 1 行です**：ノートに `- [ ] レポートを書く` と書くだけで Dayloom が検出します。
- **日付の判定順序**：`⏳ 2026-10-07`（予定日） $\rightarrow$ `📅 2026-10-07`（期限日） $\rightarrow$ **デイリーノートのファイル名** の順で判定されます。  
  例えば `2026-10-07.md` というデイリーノート内に書いたタスクは、日付絵文字がなくても自動的にその日のタスクになります。
- **時間の指定**：`⏰09:00-10:30` の形式で記録されます。時刻のあるタスクはタイムラインのブロックになり、時刻のないタスクは上部の「終日（All Day）」行に入ります。
- **ステータスの種類**：チェックボックス内の文字で区別します：`[ ]` 未着手、`[/]` 進行中、`[x]` 完了、`[-]` キャンセル済み。

## 2. Google カレンダー OAuth 2.0 連携ガイド

> 📌 Google カレンダー連携は **任意（オプショナル）** です。連携しなくても Dayloom のローカルタスク機能はすべて正常に動作します。

### Dayloom の認証方式

Dayloom には **「Google でログイン」ボタンがありません。** その代わり、設定画面に以下の 3 つの認証キーを入力して動作します：

| 設定項目 | 説明 | 形式の例 |
| --- | --- | --- |
| `Google クライアント ID` | 自分で作成した Google Cloud アプリのクライアント ID | `xxxx.apps.googleusercontent.com` |
| `Google クライアントシークレット` | そのアプリのシークレットキー | `GOCSPX-xxxx` |
| `Google リフレッシュトークン` | 新しいアクセストークンを自動取得するための永続トークン | `1//0xxxx` |

Dayloom はこの 3 つを使って Google サーバー（`https://oauth2.googleapis.com/token`）から短時間有効なアクセストークンを自動更新します。  
そのため、初回に **① Google Cloud で OAuth アプリを作成し、② リフレッシュトークンを一度だけ取得する作業** が必要です（所要時間：約 15〜20 分）。

> ⚠️ Google Cloud Console の画面レイアウトは頻繁に変更されます。メニュー名が多少異なっていても、同等の項目を探して進めてください。

---

### ステップ 1：Google Cloud プロジェクトの作成

1. [Google Cloud Console](https://console.cloud.google.com/) にアクセスし、Google アカウントでログインします。
2. 上部ヘッダーの **プロジェクト選択ドロップダウン** をクリックし、右上の **[新しいプロジェクト]** をクリックします。
3. 分かりやすいプロジェクト名（例：`Dayloom`）を入力し、**[作成]** をクリックします。
4. 作成したプロジェクトが上部の選択欄で選ばれていることを確認します。

### ステップ 2：Google Calendar API の有効化

1. 左メニュー（☰）を開き、**[API とサービス] $\rightarrow$ [ライブラリ]** へ移動します。
2. 検索バーに `Google Calendar API` と入力して選択します。
3. **[有効にする]** ボタンをクリックします。

### ステップ 3：OAuth 同意画面の設定

*(最新のコンソールでは **Google Auth Platform** と表記されている場合があります。)*

1. 左メニューの **[API とサービス] $\rightarrow$ [OAuth 同意画面]**（または *Google Auth Platform $\rightarrow$ ブランディング*）を開き、**[使ってみる]** をクリックします。
2. アプリ情報の入力：
   - **アプリ名**：`Dayloom`（任意の名前）
   - **ユーザーサポートメール**：ご自身の Google メールアドレス
3. **ユーザータイプ**：個人アカウントの場合、**外部 (External)** を選択します。
4. 連絡先メールアドレスを入力し、**[保存して次へ]** をクリックします。
5. **テストユーザー** の画面で **[+ ADD USERS]** を押し、**ご自身の Google アカウントのメールアドレス** を必ず追加します。

> ⚠️ **重要：7日間のトークン失効を防ぐ**  
> アプリが **テスト (Testing)** 状態のままだと、Google のセキュリティ仕様によりカレンダーのリフレッシュトークンが **7 日で失効** します。  
> 毎週トークンを再取得する手間を避けるため、トークンを取得する前に OAuth 同意画面ページ上部の **[アプリを公開 (Publish app)]** を押して、ステータスを **本番環境 (In production)** に移行してください。  
> 自分専用アプリのため Google の審査なしで即座に本番移行できます。（ログイン時に「このアプリは Google で確認されていません」と出た場合は **[詳細] $\rightarrow$ [(アプリ名) に移動]** をクリックすれば安全に続行できます。）

### ステップ 4：OAuth クライアント ID / シークレットの作成

Dayloom ではウェブクライアントとして動作するため、クライアントの種類は **ウェブ アプリケーション** を選択します。

1. 左メニューの **[API とサービス] $\rightarrow$ [認証情報]** を開き、上部の **[+ 認証情報を作成] $\rightarrow$ [OAuth クライアント ID]** をクリックします。
2. **アプリケーションの種類**：**ウェブ アプリケーション** を選択
3. **名前**：`Dayloom Web Client`（任意）
4. **承認済みのリダイレクト URI** セクションで **[+ URI を追加]** を押し、以下の Google 公式ツールのアドレスを **正確にコピーして貼り付け** ます：
   ```text
   https://developers.google.com/oauthplayground
   ```
5. **[作成]** をクリックします。表示された **クライアント ID** と **クライアント シークレット** をメモ帳などに安全に控えておきます。

### ステップ 5：リフレッシュトークンの取得 (OAuth 2.0 Playground)

1. [OAuth 2.0 Playground](https://developers.google.com/oauthplayground) を開きます。
2. 右上の **歯車アイコン（⚙️, OAuth 2.0 configuration）** をクリックします。
   - **`Use your own OAuth credentials`** にチェックを入れます。
   - ステップ 4 で控えた **OAuth Client ID** と **OAuth Client secret** を貼り付けます。
   - **Access type** が `Offline` になっていることを確認します（オフラインでないとリフレッシュトークンが発行されません）。
3. 左側の **Step 1** の下にある *Input your own scopes* 入力欄に、以下のスコープを貼り付けます：
   ```text
   https://www.googleapis.com/auth/calendar.events
   ```
   > Dayloom はカレンダー予定の **読み取り・作成・編集・削除** のみを行うため、このスコープだけで十分です。
4. **[Authorize APIs]** をクリックし、テストユーザーに登録したご自身の Google アカウントでログインして権限を許可します。  
   *(警告画面が出た場合は「詳細」$\rightarrow$「(安全ではないページ) に移動」をクリック)*
5. 認証が完了すると自動的に **Step 2** の画面に移ります。  
   青い **[Exchange authorization code for tokens]** ボタンをクリックします。
6. 画面下部に表示された項目の中から **`Refresh token`** の値をコピーします（`1//0` で始まる文字列です）。これで必要なキーがすべて揃いました！🎉

> 🔒 クライアントシークレットとリフレッシュトークンは **パスワードと同じ** です。絶対に他人に共有しないでください。

### ステップ 6：Dayloom の設定画面へ入力

1. Obsidian の **設定 (⚙️) $\rightarrow$ コミュニティプラグイン $\rightarrow$ Dayloom** を開きます。
2. 上部タブの **☁️ Google カレンダー** をクリックします。
3. **Google カレンダー連携を有効にする** スイッチをオンにします。
4. **Google カレンダー OAuth 2.0（同期と編集）** の下の各項目に、控えておいた値を貼り付けます：
   - `Google クライアント ID`
   - `Google クライアントシークレット`
   - `Google リフレッシュトークン`

### ステップ 7：表示したいカレンダーの登録

1. 同じタブの下部にある **Google カレンダー 📅** セクションで **[+ カレンダーを追加]** をクリックします。
2. 追加された行に入力します：
   - **チェックボックス**：オン = 表示、オフ = 非表示
   - **Name**：Dayloom 上での表示名（例：仕事、個人）
   - **ID**：メインカレンダーは `primary`、他のカレンダーは固有のカレンダー ID を入力
   - **Color**：タイムライン上での表示色
3. 他のカレンダー ID の確認方法：  
   ブラウザで Google カレンダーを開く $\rightarrow$ 対象カレンダーの **⋮ $\rightarrow$ 設定と共有 $\rightarrow$ カレンダーの統合 $\rightarrow$ カレンダー ID** をコピー  
   *(通常は `xxxx@group.calendar.google.com` 形式、メインカレンダーはご自身の Gmail アドレスです。)*
4. 不要なカレンダーは右側の **Delete** ボタンで削除できます。

### ステップ 8：タスク同期先カレンダーの指定（任意）

**タスク同期先の Google カレンダー** ドロップダウンでカレンダーを選択すると、Obsidian 内の日付と時刻があるタスクが、その Google カレンダーへ自動同期されます。

> 💡 **おすすめ**：Google カレンダー側で **`Obsidian Tasks` という専用カレンダーを新規作成** してステップ 7 で追加し、ここへ指定することを推奨します。  
> Dayloom は画面の重複を防ぐため、**同期先カレンダーの予定はタイムライン上に予定として重複表示しません**（すでに同じ Obsidian タスクが表示されているためです）。  
> メインカレンダー（`primary`）を同期先に指定してしまうと、元々あった大切な打ち合わせ等の予定がタイムライン上で見えなくなってしまうのでご注意ください。

### ステップ 9：接続テスト

1. Dayloom メインビューを開きます。
2. ヘッダーツールバーの **同期ボタン (↻)** をクリックするか、`F5` キーを押します。
3. 少し待って「✅ …」という完了通知が表示され、タイムラインに Google カレンダーの予定がブロックとして現れれば成功です！
4. 失敗する場合は [FAQ](#7-よくある質問-faq-とトラブルシューティング) を確認してください。

### 同期（Sync）の仕組み

| 操作 | 動作 |
| --- | --- |
| **同期ボタン / `F5` / `Ctrl+R` (`Cmd+R`)** | Vault 内のタスクを再スキャンし、表示範囲の Google 予定を再取得して、日時の設定されたタスクを同期先カレンダーへ一括送信します（過去 60 日〜未来 365 日）。 |
| **同期ボタンを右クリック** | *タスクを Google カレンダーと同期 📤* ダイアログが開き、対象カレンダーを確認して **今すぐ同期** を実行できます。 |
| **Dayloom 内でタスクを編集**（ドラッグ移動、時間伸縮、モーダル編集、チェック等） | その 1 つのタスクが即座に Google カレンダーへリアルタイム反映されます。 |
| **ノート本文でテキストを直接編集** | 即座には送信されず、次回の同期時（F5 など）に反映されます。 |
| タスクの日時を削除 | Dayloom が作成した予定であれば、Google カレンダー側からも自動削除されます。 |
| 同期されたタスクを削除 | 連携されていた Google カレンダーの予定も一緒に削除されます。 |

- 同期済みタスク行の末尾には `[gcalId:: …]` メタデータが付与されます。予定との紐付けに必要な情報ですので削除しないでください。
- 同期処理は **Dayloom 自体が作成した予定のみを削除** します。ユーザーが元々 Google カレンダーで作成した個人的な予定が勝手に消えることはありません。
- タイムライン上で Google カレンダーの予定ブロックをドラッグ移動・伸縮すると、Google カレンダー側にも即時保存されます。

## 3. 設定タブ別ガイド

設定画面は 5 つのタブに分かれています：

`⚙️ 一般` · `⏱️ タイムライン` · `☁️ Google カレンダー` · `🔔 通知` · `📱 表示`

> 設定項目の名称は `i18n.ts` の公式日本語辞書に基づいています。

### ⚙️ 一般 (General)

| 設定項目 | 説明 | おすすめの初期値 |
| --- | --- | --- |
| **Language / 言語** | Dayloom の表示言語：`Auto（自動検出）`、`English`、`한국어`、`日本語`、`简体中文`。変更は即座に反映されます | `Auto` |
| **既定のタスクファイル** | プランナー内でタスクを新規作成した際に追加される既定の Markdown ファイルパス（クイック入力、ダブルクリック作成、`+` ボタン）。ファイルがない場合は自動作成 | `Day Planner.md` または `Inbox/Tasks.md` |
| **除外するファイルとフォルダー** | タスク検索から除外するルール設定（下記参照） | Templates, Archive |
| **デイリーノートのフォルダー** | デイリーノートが保存されている Vault 内のフォルダーパス | 例：`Daily` |
| **デイリーノートのファイル名形式** | デイリーノートのファイル名形式 | `YYYY-MM-DD` |
| **デイリーノートのテンプレート** | 新規デイリーノート作成時に使うテンプレートファイルのパス | 例：`Templates/Daily.md` |
| **ウィークリーノートのフォルダー** | ウィークリーノートが保存されている Vault 内のフォルダーパス | 例：`Weekly` |
| **ウィークリーノートのファイル名形式** | ウィークリーノートのファイル名形式 | `gggg-[W]ww`（例：`2026-W41`） |
| **ウィークリーノートのテンプレート** | 新規ウィークリーノート作成時に使うテンプレートファイルのパス | 例：`Templates/Weekly.md` |

#### 🔎 パスのあいまい検索 (Fuzzy Search)
パス入力欄は Vault 内の実際のフォルダーやノートを自動補完します。例えば `dly` と打つだけで `Daily` フォルダーが候補に出ます。

#### 🚫 除外するファイルとフォルダー
Obsidian の検索フィルターのように **チップ（タグ形状）** で視覚的に管理できます。

1. 入力欄の左側で **除外 (Exclude)** または **保持 (Keep)** を選びます。
2. フォルダー名やファイル名を入力して候補から選ぶか、`Enter` を押します。
3. ルールがチップとして追加されます：
   - チップを **クリック** すると「除外 $\leftrightarrow$ 保持」が切り替わります。
   - 右側の **×** を押すとルールを削除できます。
   - Vault 内に実在しないパスは打ち消し線付きの薄い色で表示されます。
4. 下部の *「M 件中 N 件のノートを除外しています」* で、全体の何件が除外されたか確認できます。

| ルールの例 | 意味 |
| --- | --- |
| `Archive` | Archive フォルダーとその中にある全ノートを除外 |
| `Templates/Daily.md` | 該当のテンプレートノート 1 つだけを除外 |
| `**/Templates` | 階層の深さにかかわらず、Vault 内のすべての `Templates` フォルダーを除外 |
| `Daily/*.md` | `Daily` 直下のノートのみを除外（サブフォルダーは含む） |
| `Archive` + **保持** `Archive/2026` | Archive 全体を除外しつつ、その中の `Archive/2026` だけはスキャン対象に含める |

> `*` は同一フォルダー内の一致、`**` はサブフォルダーを含む全階層の一致です（大文字小文字は区別されません）。

### ⏱️ タイムライン (Timeline)

| 設定項目 | 説明 | おすすめの初期値 |
| --- | --- | --- |
| **N日ビューの日数** | N日ビューで連続表示する日数（2〜14日） | `4` |
| **Dayloom と Dayloom Compact の高さを個別に設定** | メイン画面とサイドバーコンパクト画面の拡大率（1時間の高さ）を別々に管理するかどうか | オフ |
| **タイムラインの 1 時間の高さ (…)** | タイムラインにおける 1 時間あたりの縦ピクセル高さ（30〜180px） | `60`（標準）；予定が多い場合は `90` 以上 |
| **タイムラインの開始時刻 / 終了時刻** | タイムラインが表示する開始・終了時刻。**「最初の空き時間に入れる (Fit It In)」機能の活動時間基準** にもなります | 例：`7` – `23` |
| **タスクの既定の長さ（分）** | 時刻のないタスクをタイムラインへドラッグした際に割り当てられる初期所要時間（1〜1440分）。複数タスクを連続配置する際の間隔にも使われます | `60`（標準）；ポモドーロなら `25` |

> 💡 ヘッダーツールバーの **ズームコントロール（🔍+）** でも 1 時間の高さを素早く変更できます。

### ☁️ Google カレンダー (Google Calendar)

| 設定項目 | 説明 |
| --- | --- |
| **Google カレンダー連携を有効にする** | カレンダー連携機能全体のオン/オフ |
| **タスク同期先の Google カレンダー** | 時刻付きタスクを同期する Google カレンダーを選択（[ステップ 8](#ステップ-8タスク同期先カレンダーの指定任意) 参照） |
| **Google クライアント ID / クライアントシークレット / リフレッシュトークン** | 取得した OAuth 2.0 認証情報（[セクション 2](#2-google-カレンダー-oauth-20-連携ガイド) 参照） |
| **Google カレンダー 📅** | 表示するカレンダー一覧：有効化チェック、表示名、ID、色、削除 |
| **ローカルタスクの色** | Google カレンダーの予定と見分けやすいよう、Obsidian ローカルタスク枠線のアクセント色を指定 |

### 🔔 通知 (Notifications)

| 設定項目 | 選択肢 | 説明 |
| --- | --- | --- |
| **通知方法** | `オフ` / `自動` / `アプリ内通知` / `システム通知` | **自動（推奨）**：Obsidian が前面にあるときはチャイム音付きのアプリ内通知、最小化時は OS のシステム通知でお知らせします。 |
| **通知のタイミング** | `開始時刻に`（標準） / `5分前`, `10分前`, `15分前`, `30分前` | いつ通知を鳴らすか |
| **通知音** | オン / オフ； 🔊 チャイムを試聴 | アプリ内通知時に鳴る心地よい 2 音チャイム（システム通知は OS 本体の通知音になります） |
| **タスクを通知** | オン / オフ | 今日の予定で、開始時刻（`⏰HH:mm`）が指定されたタスクを通知 |
| **Google カレンダーの予定を通知** | オン / オフ | 今日の時刻指定がある Google カレンダーの予定を通知（終日の予定は除外） |

> 初めてシステム通知を選んだ際、OS から権限許可を求められます。**必ず「許可」** してください。  
> 完了したタスク（`[x]`）やキャンセルされたタスク（`[-]`）は通知されません。

### 📱 表示 (View/Display)

| 設定項目 | 説明 | おすすめの初期値 |
| --- | --- | --- |
| **インラインメタデータを隠す** | `[gcalId:: …]` などの角括弧フィールドをプランナー、閲覧ビュー、ライブプレビュー上で非表示化（ファイル本文の内容は保持） | オン |
| **ヘッダーにショートカットボタンを表示** | ツールバーのショートカット（?）ボタンの表示切替。隠しても `?` や `h` キーでの表示は有効です | お好みで |
| **スワイプで日付を移動** | スマートフォン上で左右スワイプして日付を切り替えます。オフにすると前へ/次へ（`< >`）ボタンが表示されます | オン |
| **触覚フィードバック** | タスク完了、タブ切り替え、ドラッグ移動やサイズ変更時に心地よい振動を返します（対応端末のみ） | オン |

## 4. サイドドロワーとタイムブロッキングの手順

**タイムブロッキング（Timeboxing）** とは、タスクに具体的な時間枠を割り当てて *「いつ実行するか」* を明確にスケジューリングする手法です。  
Dayloom のサイドドロワーは、未スケジュールのタスクをプールしておき、今日の重要タスクや進捗を確認しながらスムーズにタイムラインへドラッグ配置できるように設計されています。

### ドロワーの開閉

- **デスクトップ版 Dayloom メインビュー** のすべてのタブ（日、N日、週、月、ボード、リスト）で利用できます。（Dayloom Compact やスマートフォン画面では非表示になります。）
- 開閉方法：`s` キーを押すか、ツールバー右端の **パネルアイコン (▣)** をクリックするか、コマンド `Toggle Side Drawer` を実行します。
- ドロワー右上の閉じるボタン（⨯）でも閉じられます。

### レイアウト構造

```text
┌ October 2026 ▾        ‹ Today ›    ⨯ ┐  ← ミニカレンダー（ボードビューでは自動非表示）
│ Su  Mo  Tu  We  Th  Fr  Sa            │
│ ...  6週のカレンダーグリッド、点表示 ... │
│ [ ☑ タスク 8 │ ◔ 統計 62% ]            │  ← ドロワーモード切り替え
├───────────────────────────────────────┤
│ [+ 日付なしのタスクを追加 (🔺 ⏫...)]    │  ← クイック入力
│ ▾ 🎯 今日のフォーカス    (1)            │
│ ▾ 🚨 期限切れのタスク    (3) [今日へ移動] │
│ ▾ 📂 日付なしのタスク    (5)            │
└───────────────────────────────────────┘
```

### ミニカレンダー

- **日付をクリック**：プランナーがその日付へジャンプします。現在メイン画面に表示されている期間は薄い帯で強調され、今日は塗りつぶしの円で示されます。
- **Ctrl/Cmd+クリック**：その日のデイリーノートを開きます。
- **日付の下の点 (Dot)**：
  - オレンジ：未完了タスクあり
  - 赤く光る点：🔺 最高 (Highest) 優先度のタスクあり
  - 緑：その日のタスクがすべて完了
  - 青：カレンダーの予定あり
- **‹ ›** または **マウスホイール**：月送り（**Today** で今日に戻る）。
- **月名をクリック**：1 週間のスリムな帯に折りたたまれます。Dayloom はこの状態を記憶します。
- **日付の上へタスクをドロップ**：その日付へスケジュールが変更されます（設定済み時刻は維持）。
- **ボードビュー** を開くとミニカレンダーは自動的に隠れ、タスク一覧が縦いっぱいに広がります。

### タスク (Tasks) モード

- **🎯 今日のフォーカス (Today's Focus)**：今日の日付が設定された未完了の **🔺 最高 (Highest)** タスク一覧です。**どんなタスクでもここへドラッグ＆ドロップすると**、即座に今日の日付が付与されて 🔺 最高優先度に昇格します（日付なしタスクには今日の日付が付きます）。
- **🚨 期限切れのタスク (Overdue Tasks)**：今日より前の日付で未完了のタスクです（優先度 $\rightarrow$ 古い日付 $\rightarrow$ タイトル順で並び、過去日は赤字で強調）。
- **📂 日付なしのタスク (Undated Tasks)**：日付の決まっていない全タスクのプールです（ボードビューの *日付なし* 列と同じ内容）。
- 空のセクションは **自動で折りたたまれ**、タスクが入ると自動で展開します。ヘッダーをクリックして手動で折りたたむことも可能です。
- **🔺 最高** カードは赤い枠線とグロー効果、**⏫ 高** カードはオレンジの枠線で強調されます。

### 統計 (Stats) モード

プランナーが表示している **その日の生産性データ** をグラフィカルに要約します：

- **プログレスリング**：計画時間に対する完了時間の達成割合（時刻付きタスク基準）。時刻付きタスクがない場合は完了件数/総件数の比率になります。
- **予定 (Planned) / 完了 (Completed) / 残り (Remaining)** の時間表示。
- **タスク完了件数**、**フォーカスタスク完了件数**、**カレンダー予定の総時間**、**優先度別の分布**。
- 達成度に応じた前向きな応援メッセージ。

検索中であっても、統計モードはその日の全体集計を正しく表示し続けます。

---

### ① クイック入力 (Quick capture)

1. ドロワー最上部の入力欄にタスクを書いて `Enter` を押します。
2. 設定された **既定のタスクファイル** に日付なしタスクとして即時追加され、「新しいタスクを追加しました」と通知が出ます。
3. 入力時に優先度絵文字を含めると、優先度も同時に設定されます（例：`⏫ 企画書の骨子を作成`）。
4. 日本語 IME に完全対応しており、確定の `Enter` で誤送信されることなく、次の `Enter` で気持ちよく登録されます。

### ② 優先度の設定

カードの優先度バッジをクリックするか（未設定時にマウスを乗せると薄い旗が出ます）、カードにフォーカスして `p` キーを押します。  
🔺 最高、⏫ 高、🔼 中、○ 標準、🔽 低、⏬ 最低 から選択すると、ノート本文へ自動的に絵文字が書き込まれます。

### ③ タイムラインへのドラッグ配置

| ドロップ先 | 結果 |
| --- | --- |
| **タイムラインの時間枠**（日 / N日 / 週） | その日付とドロップ位置の時刻に配置（15分単位）。長さは **タスクの既定の長さ** が適用 |
| **月カレンダーの日付マスまたはミニカレンダー** | 日付のみ変更（時刻は維持。時刻なしタスクは終日行のまま） |
| **週 / N日ビューの日付ヘッダー** | **最初の空き時間に入れる (Fit It In)**：その日の最も早い空き時間を見つけて自動配置 |
| **ボードビューの列** | カンバンモード：その列の日付（または完了）；優先度モード：その優先度を付与 |
| **🎯 今日のフォーカス** | 今日の日付を付与 ＋ 🔺 最高優先度に設定 |
| **ドロワーの空き領域** | スケジュール解除（⑤ 参照） |

- ドラッグ中は配置予定時刻（例：`14:30`）が点線プレビューでリアルタイム表示されます。
- ドラッグ中に `j` / `k` キーを押すと、指を離さずに日付ページを前後にめくることができます。
- ドラッグ中に `Esc` を押すと移動がキャンセルされます。
- すべての移動操作後、画面右上の通知に **元に戻す (Undo)** ボタンが表示されます。

### ④ 複数タスクの連続自動スケジュール

1. **Ctrl/Cmd+クリック** またはドロワーの空き領域を **マウスで枠囲みドラッグ** して、複数のカードを選択します。
2. 選択されたカードの 1 つを掴み、タイムラインの開始したい時間帯へドラッグします。
3. ドロップした開始時刻を起点として、ドロワーに並んでいた順番通りに **隙間なく連続して配置** されます！（各タスク本来の所要時間が保たれ、時刻がなかったタスクは設定の既定時間ずつ順に埋まります。）
4. 深夜 24:00 を超えるタスクはその場に留まります。Undo ボタン 1 回でまとめて元に戻せます。

`Esc` を押すと選択がクリアされます。

### ⑤ スケジュール解除 (Unschedule)

タイムライン上のブロック、終日タスク、月カレンダーのタスク、ボードのカードを **マウスで掴んでサイドドロワー内へドラッグ＆ドロップ** すると、日時が削除されて純粋な [日付なしのタスク] に戻ります。

- 時間表記、`⏳` 予定日、`📅` 期限日がノート本文から安全に取り除かれます。
- **デイリーノート内に書かれているタスク** はファイル名自体が日付であるため、日付は解除されません（説明の通知が表示されます）。
- Google カレンダーの予定をドロワーへ入れてもカレンダーから削除されることはありません。
- 誤操作防止のため、「期限切れ」や「今日のフォーカス」のカードは **[日付なしのタスク] セクションの上に落とした時のみ** 解除されます。

### ⑥ 期限切れタスクの整理

- 期限切れカードにカーソルを合わせると素早い処理ボタンが現れます：  
  `今日へ移動` · `明日(Tmrw)` · `+1週` · `日付解除(Undate)`。時刻を保ったまま日付だけが更新されます。
- セクションヘッダーの **今日へ移動** を押すと、溜まっていた期限切れタスクがワンクリックですべて今日の日付へ繰り越されます（Undo 対応）。

### ⑦ ドロワーのキーボード操作

`Tab` キーでカードにフォーカスを当てた後：

| キー | 動作 |
| --- | --- |
| `Enter` | タスクを編集 |
| `f` | **最初の空き時間に入れる**：今後 14 日以内で最も早い空き枠を探して自動配置 |
| `p` | 優先度を設定 |

*Fit It In* は設定された活動時間（開始・終了時刻）を守り、今日の分は現在時刻以降の空き枠のみを探索して、既存の予定やタスクと重ならない場所へきれいに差し込みます。

### ☀️ おすすめのデイリールーティン

1. 朝、Obsidian を開いて `s` キーでサイドドロワーを展開します。
2. **期限切れのタスク** を確認し、`今日へ移動` で引き継ぐか日程を再調整します。
3. 今日絶対にやり遂げる重要タスクを 1〜2 件選び、**🎯 今日のフォーカス** へドラッグします。
4. 新しく思いついたタスクを上部の **クイック入力** でどんどん放り込みます。
5. 今日やる **日付なし** のタスクを複数選択し、タイムラインの空き時間へドラッグして連続スケジュール化します。
6. 各ブロックの端を引っ張って見積もり時間を合わせ、一日の終わりに **統計** 画面でリングの達成感を味わいましょう！

## 5. ビュー、検索、選択とショートカット

### 6 つのビュー (Views)

| ビュー (タブ) | キー | 特徴 |
| --- | --- | --- |
| **日タイムライン (Daily Timeline)** | `d` | 1 日の詳細ビュー。現在時刻バー、実行中タスクの進捗プログレスバー、上部固定の終日行 |
| **N日ビュー (N-day View)** | `x` | 2〜14 日を横並びで表示（タブ上部で日数を即座に変更可能）。スマホでは 2 日ビューとして動作 |
| **週ビュー (Weekly View)** | `w` | 1 週間（7 日間）を一望。**曜日の日付ヘッダーをクリック** するとその日の日タイムラインへジャンプ |
| **月カレンダー (Monthly Calendar)** | `m` | 月間カレンダー。**日付マスをクリック** するとその日の日タイムラインへ、**週番号をクリック** するとその週の週ビューへジャンプ |
| **ボード (Board)** | `b` | カンバンボード。*標準カンバン*（日付なし · 期限切れ · 今日 · 明日 · 今後 · 完了済み）および *優先度フォーカス*（最高 🔺 … 最低 ⏬） |
| **リストビュー (List View)** | `l` | アジェンダ形式のアジェンダリスト。検索時は全期間の一致タスクを一覧化する専用ビューとして機能 |

- ヘッダー左側の日付ピル（例：📅 2026-10-07 (Wk 41)）をクリックすると、対応するデイリー / ウィークリーノートが開きます。
- **ボードビュー** では、カードを他の列へドラッグするとノート本文の日付や優先度が自動で書き換わります。複数カードを選択して一括移動することも可能です。

### デスクトップのヘッダー構成

```text
[📅 日付ピル]                [‹ Today ›]  [🔍 ↻ 🔍+ ? ▣]  [+]
```

| コントロール | 機能 |
| --- | --- |
| 📅 日付ピル | デイリー / ウィークリーノートを開く |
| ‹ Today › | 前へ / 今日 / 次へ |
| 🔍 検索 | 展開式検索バーを起動 (`/`) |
| ↻ 同期 | Google カレンダーと同期（右クリック：手動同期モーダル） |
| 🔍+ ズーム | タイムラインの 1 時間の高さを拡大・縮小（日 / N日 / 週） |
| ? ショートカット | キーボードショートカット一覧（設定で非表示可能） |
| ▣ パネル | サイドドロワーの開閉 |
| **+ 追加** | ローカルタスクまたは Google カレンダーの予定を追加 |

ボードビューでは、ヘッダーに **標準カンバン / 優先度フォーカス** の切り替えスイッチが加わります。

---

### 🔍 展開式検索 (Search)

1. キーボードの `/` を押すか、ヘッダーの虫眼鏡アイコンをクリックします。
2. 上部ヘッダーのボタン群がスムーズに隠れ、**ヘッダーの横幅いっぱいに広がる検索バー** が現れて自動でフォーカスされます。
3. 文字を入力すると、現在のビューがリアルタイムに絞り込まれます：
   - タスク本文、`#タグ`、ノートのファイルパス、予定のタイトル、場所、カレンダー名をすべて対象にします。
   - スペースで区切って複数単語を入力すると AND 検索になります。
4. **Enter キーを押すと即座に [リストビュー (List View)] へ自動遷移** し、特定の日付にとらわれず **Vault 全体の一致する全タスク・予定** を網羅的にリストアップします！
5. `Esc` を押すか右端の **×** をクリックすると検索が終了し、元のツールバーボタンが復元されます。

---

### ✅ 選択と一括削除

| 目的 | 操作 |
| --- | --- |
| 項目を 1 つ追加/除外選択 | 目的の項目を **Ctrl/Cmd+クリック**（編集画面を開かずに選択状態だけをトグル） |
| マウスドラッグで範囲選択 | 空き領域で **マウスを四角くドラッグ（枠囲み選択）**（タイムライン、終日行、ボード、ドロワーすべて対応） |
| 既存の選択に範囲を追加 | `Ctrl` / `Cmd` / `Shift` を押しながら四角くドラッグ |
| 選択の全解除 | 空白をクリック、`Esc` キー、または選択バーの × を押す |
| まとめて移動 | 選択された項目の 1 つをドラッグ（タイムライン上では間隔を保ち、ドロワーからは連続配置） |
| まとめて削除 | キーボードの `Delete` または `Backspace`、または選択バーの **削除** を押す |

- 削除操作を行うと、誤操作防止の確認ダイアログが必ず表示されます（`Enter` で実行、`Esc` でキャンセル）。  
  ノートから該当行が削除され、直後に表示される通知の **元に戻す (Undo)** ボタンで一発復元できます。
- 選択されていた Google カレンダーの予定や同期タスクのカレンダー側コピーもカレンダーから削除されます。
- ⚠️ **注意**：Google カレンダー側の予定自体は、Google の仕様上 Undo ボタンで復元できません。
- 各タスクの編集モーダル内にも個別の **Delete** ボタンが用意されています。

### ⌨️ キーボードショートカット一覧

> ショートカットは Dayloom ビュー内を一度クリックしてアクティブにした状態で動作します。  
> 入力欄や検索バー、ノート本文の編集中は、文字入力を妨げないようショートカットが無効化されます。

| キー | 動作 |
| --- | --- |
| `j` | 次の日 / 期間（コンパクトボード：次の列） |
| `k` | 前の日 / 期間（コンパクトボード：前の列） |
| `t` | 今日へ移動 |
| `d` / `x` / `w` / `m` / `b` / `l` | 日タイムライン / N日ビュー / 週ビュー / 月カレンダー / ボード / リストビュー切り替え |
| `s` | サイドドロワーの切り替え（デスクトップ） |
| `/` | タスクと予定を検索 |
| `?` または `h` | キーボードショートカット一覧を表示 |
| `F5` または `Ctrl+R` (`Cmd+R`) | 同期（タスクを再スキャン、Google カレンダーを更新） |
| `Delete` / `Backspace` | 選択したタスクと予定を削除 |
| `Esc` | ドラッグ中止 $\rightarrow$ 選択解除 $\rightarrow$ 検索終了 |
| `Ctrl/Cmd + クリック` | 項目を選択に追加 / 選択から外す |
| `Ctrl/Cmd + ドラッグ` | タイムラインの空き部分をドラッグして選択に追加 |
| `Enter` / `f` / `p`（ドロワーカード選択時） | 編集 / 最初の空き時間に入れる / 優先度を設定 |
| `j` / `k`（ドラッグ中） | タスクを持ったまま日付を移動 |

### 🖱️ マウス操作

| 目的 | 操作 |
| --- | --- |
| タスクを編集 | ブロックをクリック $\rightarrow$ 編集モーダルが開く |
| 完了チェック | チェックボックスをクリック（`[ ]` $\rightarrow$ `[/]` $\rightarrow$ `[x]` $\rightarrow$ `[-]`） |
| 元ノートを開く | ブロック右上の `↗` アイコンをクリック |
| 日時を移動 | ブロックをドラッグして移動（15 分単位でスナップ） |
| 所要時間を伸縮 | ブロックの **上端または下端のハンドル** をドラッグ |
| タスク新規作成 | 空きスロットを **ダブルクリック** $\rightarrow$ タイトルを入力して `Enter` |
| 右クリックメニュー | 空きスロットを **右クリック** $\rightarrow$ `Add Task at HH:MM`（ローカル） / `Add Appointment at HH:MM`（Google） |

> 🔒 **完了（`[x]`）やキャンセル（`[-]`）されたタスクはロックされます**：誤操作を防ぐためドラッグ移動やリサイズが無効になります（クリックして編集画面を開くことは可能です）。

### 📱 モバイル環境

- 下部タブバー：**日 · リスト · 月 · ボード**
- 日ビューの上部に週間日付ピルが表示され、タップして曜日を素早く切り替えられます。
- 左右 **スワイプ** で日付送り（ボードでは列の切り替え）。
- ブロックを **長押し（約 0.35 秒ロングプレス）** すると、振動とともに上下ハンドルが現れ、位置や時間を自由に調節できます。
- 空白部分をタップすると調整モードが解除されます。

### ステータスバー

Obsidian 最下部のステータスバーに、現在進行中のタスク（プログレスバーと残り時間）または次に控えているタスクが表示されます。

## 6. タスク構文とインラインコードブロック

### 基本構文

```markdown
- [ ] タスクのタイトル ⏰09:00-10:30 ⏫ 🔁 every week ⏳ 2026-10-07 📅 2026-10-10
```

| 要素 | 構文 | 意味 |
| --- | --- | --- |
| ステータス | `[ ]` `[/]` `[x]` `[-]` | 未着手 / 進行中 / 完了 / キャンセル済み |
| 時刻 | `⏰09:00-10:30` | 開始–終了時刻。終了がない場合（`⏰09:00`）は 30 分として扱われます |
| 優先度 | 🔺 ⏫ 🔼 🔽 ⏬ | 最高 / 高 / 中 / 低 / 最低（未指定時は標準） |
| 予定日 | `⏳ YYYY-MM-DD` | Dayloom のタイムラインに配置された際に記録される日付 |
| 期限日 | `📅 YYYY-MM-DD` | 予定日がない場合に優先参照される日付 |
| 開始日 | `🛫 YYYY-MM-DD` | Tasks プラグイン互換の開始日 |
| 完了/取消日 | `✅ YYYY-MM-DD` / `❌ YYYY-MM-DD` | チェックを入れた際に自動付与される記録日付 |
| 繰り返し | `🔁 every day` など | チェック完了時に次のサイクルのタスク行が自動生成されます |
| カレンダー連携 | `[gcalId:: …]` | Google カレンダーと紐付ける識別子（手動編集不要） |

#### 柔軟な時刻表記
以下のフォーマットも自動認識されます：

```markdown
- [ ] 09:00 - 10:00 ミーティング       ← 先頭に時間を記述
- [ ] ミーティング [09:00-10:00]       ← 角括弧で記述
- [ ] ミーティング [startTime:: 09:00 - 10:00] ← Dataview インライン形式
```

#### 繰り返しルール
`every day` (`daily`), `every week` (`weekly`), `every month` (`monthly`), `every year` (`yearly`), `every weekday`, および `every N day/week/month/year`（例：`every 3 days`）。

### インラインコードブロック：```` ```dayloom ````

任意のノート本文にプランナービューを直接埋め込むことができます。コマンド **Insert Inline View (dayloom block)** を実行するとひな形が挿入されます。

````markdown
```dayloom
type: daily
height: 500px
```
````

> 後方互換性のため、旧名称である ```` ```dayplanner ```` や ```` ```dayplanner-pro ```` もそのまま動作します。

| オプション | 指定できる値 | 説明 |
| --- | --- | --- |
| `type` | `daily` · `multiDay` · `weekly` · `monthly` · `board` · `list` | 表示するビュー種類。内部のタブを押せばコードブロック側も自動更新 |
| `date` | `YYYY-MM-DD` または `today` | 基準日 |
| `height` | `500px`、`80vh` など | ブロックの高さ。下端をドラッグして伸ばすと新しい高さが保存されます |
| `hourHeight` | 数値（例：`80`） | このブロック専用の 1 時間あたりの高さ |
| `showFilters` | `true` | フィルターパネルを開いた状態で開始 |
| `collapsedColumns` | `[undated, completed]` | ボードビューで初期状態で閉じておく列 |
| `filters` | （UI からの操作で自動生成） | 下記フィルター構文を参照 |

- **デイリーノート** 内にパラメーターなしで配置すると、その日のスケジュールが表示されます。
- **ウィークリーノート** 内に配置すると、その週のスケジュールが表示されます。

### 🔍 インラインブロックのフィルター機能

ブロック右上にある **🔍 フィルター** ボタンを押すとフィルター行が現れます。

1. **+ フィルター** から条件を追加：`フォルダー` · `ファイル` · `タグ` · `ステータス` · `優先度` · `日付` · `テキスト` · `項目の種類`
2. 条件と値を設定し、**完了**（または `Enter`）をクリック。
3. 左端の **すべて一致（AND） / いずれかに一致（OR） / すべて除外（NOR）** で組み合わせ方法を選択。
4. グループ化（入れ子条件）もサポートされています。

## 7. よくある質問 (FAQ) とトラブルシューティング

### Q1. ノートに書いたタスクがプランナーに出てきません。
- 行の先頭が正確に `- [ ] ` になっているか確認してください（`*` 記号や数字付きリストには対応していません）。
- タイムライン時間割には **日付のあるタスク** だけが表示されます。日付のないタスクはサイドドロワーの **日付なしのタスク** やボードビューの **日付なし** 列をご確認ください。
- 設定 $\rightarrow$ 一般 $\rightarrow$ **除外するファイルとフォルダー** で除外されていないか確認してください。
- 同期アプリの衝突ファイル（`.sync-conflict-` を含むファイル名）は自動除外されます。
- 検索バーが開いたままになっていませんか？ `Esc` で解除してください。
- `F5` キーを押して再読み込みしてみてください。

### Q2. トークン更新時に "invalid_grant" エラーが出ます。
リフレッシュトークンが失効したか取り消されています。
- 同意画面が **テスト (Testing)** のままだと **7 日で失効** します。同意画面を **本番環境 (In production)** へ移行し、[ステップ 5](#ステップ-5リフレッシュトークンの取得-oauth-20-playground) の手順で新しいトークンを取得してください。
- Google アカウントのパスワード変更時にも失効します。

### Q3. "unauthorized_client" または "invalid_client" エラーが出ます。
- クライアント ID やシークレットの前後に余分な空白が入っていないか確認してください。
- リフレッシュトークンは **該当の Client ID / Secret とペアで発行されたもの** である必要があります。

### Q4. Google カレンダーの予定が表示されません。
- 設定 $\rightarrow$ ☁️ Google カレンダー $\rightarrow$ **Google カレンダー 📅** 一覧で該当カレンダーの **チェックが入っているか** 確認してください。
- **タスク同期先の Google カレンダー** に指定されたカレンダーの予定は、重複防止のため予定としては表示されません。私用の予定があるカレンダーを同期先に指定しないでください。
- 同期ボタン（↻）または `F5` を押してください。

### Q5. ノートで時間を変えたのに Google カレンダーに反映されません。
ノート本文で直接タイピングした変更は即座には送信されません。同期ボタン（↻）または `F5` を押してください。  
（Dayloom 上でブロックをドラッグ移動したりモーダルで編集した内容は即時反映されます。）

### Q6. タスク末尾の `[gcalId:: …]` が目障りです。
予定との接続キーですので削除しないでください。  
設定 $\rightarrow$ 📱 表示 $\rightarrow$ **インラインメタデータを隠す** をオンにすると画面上ではすっきり非表示になります。

### Q7. 通知が鳴りません。
- 設定 $\rightarrow$ 🔔 通知 $\rightarrow$ **通知方法** が `オフ` になっていないか確認してください。
- タスクに **今日の日付** と **開始時刻（`⏰HH:mm`）** の両方が必要です。
- システム通知を使用する場合、OS の設定で Obsidian の通知が許可されている必要があります。
- 音が出ない場合は設定の 🔊 試聴ボタンを試してください。

### Q8. ショートカットが効きません。
- Dayloom の画面内を一度クリックして **アクティブ** にしてください。
- テキスト入力欄にカーソルがある間はキー入力が優先される仕様です。

### Q9. ブロックをドラッグ移動できません。
- 完了（`[x]`）やキャンセル（`[-]`）されたタスクは安全のためロックされています。チェックを外して未完了に戻してから移動してください。
- スマートフォンではブロックを **約 0.35 秒長押し** すると編集モードに入り、移動や伸縮が可能になります。

### Q10. サイドドロワーが表示されません。
サイドドロワーは **デスクトップ版 Dayloom メインビュー** で利用可能です。`s` キーまたはツールバーのパネルアイコン（▣）を押してください。（スマートフォンやサイドバーの Dayloom Compact では非表示になります。）

### Q11. クイック入力したタスクが「日付なし」に入りません。
設定の **既定のタスクファイル** のファイル名に日付（例：`2026-10-07.md`）が含まれていると、デイリーノートとみなされ日付が付いてしまいます。日付を含まないファイル名（例：`Inbox.md`）を指定してください。

### Q12. 誤って削除したタスクを元に戻せますか？
はい。移動や削除を行った直後に画面右上に表示される **元に戻す (Undo)** ボタンを押せば、一括操作であっても完全に復元できます。  
（ただし、Google カレンダー側で直接削除された予定は復元できません。）

### Q13. 認証情報はどこに保存されますか？ 安全ですか？
シークレットやリフレッシュトークンは、Vault 内の `.obsidian/plugins/obsidian-day-planner-pro/data.json` にローカル保存され、外部サーバーへ送信されることは一切ありません。  
Vault を GitHub 等の公開リポジトリで管理している場合は、このファイルが除外されているか確認してください。

### Q14. 言語表示がおかしいです。
設定 $\rightarrow$ 一般 $\rightarrow$ **Language / 言語** で変更してください。`Auto` は Obsidian 本体の言語設定に従いますが、手動で希望の言語に固定することも可能です。
