## 1. Dayloom とは？ 基本コンセプト

### どんなプラグイン？

Dayloom は、Obsidian のノートに書かれた **チェックボックスタスク（`- [ ]`）** を自動収集し、タイムライン形式のスケジュールとして可視化するプラグインです。
タスクに日付と時間を指定するとタイムライン上に時間ブロックとして現れ、タイムライン上でブロックをドラッグすると **ノート本文のテキストがリアルタイムに書き換わります。**
外部のデータベースは一切使わず、すべてあなた自身の純粋な Markdown ファイル内で安全に管理されます。

### 主な機能一覧

| 機能 | 説明 |
| --- | --- |
| 6 つのビュー | 日タイムライン、N日ビュー（2〜14日）、週、月、ボード（標準カンバン / 優先度フォーカス）、リスト |
| タイムブロッキング | 目的の時間枠へタスクをドラッグ配置、上下ハンドルでブロックのサイズ（所要時間）を伸縮調整 |
| どこへでもドラッグ | タスクを掴んだまま手を離さずに日付、週、さらには別のビュー（日 → 月やボード）をまたいで移動 |
| サイドドロワー | ミニカレンダー、🎯 今日のフォーカス、期限切れのタスク、日付なしのタスク、日別統計（デスクトップおよびタブレット） |
| 検索 | `/` または `Ctrl/Cmd+F` でヘッダー全体が検索バーに展開、`Enter` でリストビューに一致項目を一括表示 |
| 複数選択＆削除 | Ctrl/Cmd+クリックやドラッグ枠囲み選択に対応、`Delete` キーでタスクや予定を一括削除（1回の元に戻すに対応） |
| Google カレンダー | 予定の閲覧・編集・作成・削除、時刻指定されたタスクをカレンダーへ同期 |
| 通知 | 開始時刻（または 5〜30 分前）にアプリ内通知やシステム通知でお知らせ、チャイム音付き |
| タッチ操作 | スマートフォン、タブレット、タッチ対応ノートPCでの長押しドラッグ、スマートフォンでのスワイプ日付切り替え |
| インラインビュー埋め込み | ```` ```dayloom ```` コードブロックで任意のノート本文にフィルター付きプランナーを埋め込み |
| Tasks プラグイン互換 | Obsidian Tasks プラグインの標準絵文字構文（📅 ⏳ 🛫 ✅ ❌ 🔁 🔺⏫🔼🔽⏬）に対応 |
| テーマ＆多言語対応 | Obsidian のテーマ色に自動追従、English、한국어、日本語、简体中文に対応 |

### 2 つのウィンドウ：Dayloom と Dayloom Compact

| 名称 | 開き方 | 説明 |
| --- | --- | --- |
| **Dayloom** | リボンのカレンダーアイコン *Open Dayloom*、またはコマンド `Open Dayloom` | メインのプランナータブです。すべてのビューと、（デスクトップおよびタブレット環境で）サイドドロワーが付属します。 |
| **Dayloom Compact** | リボンの時計カレンダーアイコン *Open Dayloom Compact*、またはコマンド `Open Dayloom Compact` | 右サイドバーにドッキングされるコンパクトプランナーです。スマートフォン用レイアウトを使用し、下部バーに **日 · リスト · 月 · ボード** と **その他** が配置されます。 |

> 💡 `Ctrl+P`（Mac は `Cmd+P`）で **コマンドパレット** を開き、"Dayloom" と入力すると関連コマンド一覧を確認できます：
> `Open Dayloom`, `Open Dayloom Compact`, `Go to Today`, `Toggle Side Drawer`, `Insert Inline View (dayloom block)`, `Show Keyboard Shortcuts`, `What's New (Release Notes)`。

### 基本の仕組み

- **タスクはチェックボックス 1 行です。** ノートに `- [ ] レポートを書く` と書くだけで Dayloom が検出します。
- **日付の判定順序** は、`⏳ 2026-10-07`（予定日） → `📅 2026-10-07`（期限日） → **デイリーノートのファイル名** の順です。
  例えば `2026-10-07.md` というデイリーノート内に書いたタスクは、日付絵文字がなくても自動的にその日のタスクになります。
- **時間の指定** は、`⏰09:00-10:30` の形式で記録されます。時刻のあるタスクはタイムラインのブロックになり、時刻のないタスクは上部の「終日」行に入ります。
- **ステータスの種類** は、チェックボックス内の文字で区別します：`[ ]` 未着手、`[/]` 進行中、`[x]` 完了、`[-]` キャンセル済み。

### 新機能（What's New）

アップデート後、**新機能** ウィンドウが変更点を一度表示します。コマンド `What's New (Release Notes)` を実行するか、設定 → 一般の **リリースノートを見る** ボタンからいつでも再表示できます。

## 2. Google カレンダー OAuth 2.0 連携ガイド

Google カレンダー連携は **任意（オプショナル）** です。連携しなくても、Dayloom のすべてのタスク管理機能はそのまま利用できます。

### Dayloom のログイン方式

Dayloom には **「Google でログイン」ボタンがありません。** 代わりに設定画面で 3 つの値を手動で入力します：

| 設定項目 | 内容 | 形式の例 |
| --- | --- | --- |
| `Google クライアント ID` | 作成した OAuth アプリの ID | `xxxx.apps.googleusercontent.com` |
| `Google クライアントシークレット` | そのアプリのシークレットキー | `GOCSPX-xxxx` |
| `Google リフレッシュトークン` | 新しいアクセストークンを取得するための永続トークン | `1//0xxxx` |

これらの設定により、Dayloom は Google のエンドポイント（`https://oauth2.googleapis.com/token`）へ直接リクエストし、短命なアクセストークンを取得してメモリ内のみに保持します。
そのため、ユーザーの手順は **① Google Cloud で OAuth アプリを作成し、② リフレッシュトークンを 1 回だけ取得して設定すること** です。
落ち着いて進めれば、20〜30 分ほどで完了します。

> ⚠️ Google Cloud コンソールは画面構成が頻繁に変更されます。メニューの名称が多少異なる場合は、同じ意味の項目を探して進めてください。

### ステップ 1：Google Cloud プロジェクトの作成

1. [Google Cloud Console](https://console.cloud.google.com/) にアクセスし、Google アカウントでログインします。
2. 上部の **プロジェクト選択メニュー** → **新しいプロジェクト** をクリックします。
3. プロジェクト名にわかりやすい名前（例：`Dayloom`）を入力し、**作成** をクリックします。
4. 上部の選択メニューで、新しく作成したプロジェクトが選択されていることを確認します。

### ステップ 2：Google Calendar API の有効化

1. 左側のメニューから **API とサービス → ライブラリ** を開きます。
2. `Google Calendar API` を検索して選択します。
3. **有効にする** をクリックします。

### ステップ 3：OAuth 同意画面の構成

（最近のコンソールでは **Google Auth Platform** と表記されている場合があります。）

1. **API とサービス → OAuth 同意画面**（または *Google Auth Platform → ブランディング*）を開き、**利用開始** をクリックします。
2. アプリ情報：
   - **アプリ名**：`Dayloom`（任意）
   - **ユーザーサポートメール**：ご自身のメールアドレス
3. **対象 / ユーザータイプ（Audience）**：個人の Google アカウントの場合は **外部（External）** を選択します。
4. 連絡先メールアドレスを入力し、規約に同意して **作成 / 保存** をクリックします。
5. **テストユーザー（Test users）** に、**ご自身の Google アカウントのメールアドレス** を追加します。

> ⚠️ **重要：7日間の有効期限について**
> アプリが **テスト中（Testing）** の状態では、Google の仕様によりリフレッシュトークンが **7 日後に失効** します。
> 毎週トークンを再発行する手間を避けるため、トークンを取得する *前* に、同意画面（対象ユーザーページ）で **アプリを公開（Publish app） → 本番環境（In production）** へ移行してください。
> あなた自身のみが使用する個人アプリの場合、Google による審査なしでそのまま公開できます。ログイン時に「Google はこのアプリを確認していません」という警告画面が表示されますが、**詳細 → （アプリ名）に移動** をクリックして続行できます。

### ステップ 4：OAuth クライアント ID / シークレットの作成

Dayloom の設定ではこれを *OAuth ウェブクライアント* と呼んでいるため、**ウェブ アプリケーション（Web application）** クライアントを作成します。

1. **API とサービス → 認証情報 → 認証情報を作成 → OAuth クライアント ID**
   （または *Google Auth Platform → クライアント → クライアントを作成*）を開きます。
2. **アプリケーションの種類**：`ウェブ アプリケーション（Web application）`
3. **名前**：任意（例：`Dayloom Web Client`）
4. **承認済みのリダイレクト URI** に、以下の正確なアドレスを追加します（次のステップでトークン取得ツールとして使用する Google 公式のアドレスです）：
   ```
   https://developers.google.com/oauthplayground
   ```
5. **作成** をクリックします。**クライアント ID** と **クライアント シークレット** が表示されますので、両方を安全な場所に控えておきます。

### ステップ 5：リフレッシュトークンの取得（OAuth 2.0 Playground）

1. [OAuth 2.0 Playground](https://developers.google.com/oauthplayground) を開きます。
2. 右上の **歯車アイコン（⚙️, OAuth 2.0 configuration）** をクリックします。
   - **Use your own OAuth credentials** にチェックを入れます。
   - ステップ 4 で控えた **OAuth Client ID** と **OAuth Client secret** を貼り付けます。
   - **Access type** が `Offline` になっていることを確認します（リフレッシュトークンの取得に必須です）。
3. 左側の **Step 1** の入力欄（*Input your own scopes*）に以下のスコープを入力します：
   ```
   https://www.googleapis.com/auth/calendar.events
   ```
   > Dayloom は **予定の閲覧・作成・編集・削除** のみを行うため、このスコープだけで十分です。
4. **Authorize APIs** をクリックし、ステップ 3 でテストユーザーとして追加した Google アカウントでログインしてアクセスを許可します。
   （未確認アプリの警告が出た場合は、*詳細 → …に移動* をクリックします。）
5. **Step 2** の画面に進んだら、**Exchange authorization code for tokens** をクリックします。
6. 右側に表示された **Refresh token**（`1//0` から始まる文字列）をコピーします。これで最後の鍵が揃いました！ 🎉

> 🔒 クライアントシークレットとリフレッシュトークンは **パスワードと同じように厳重に管理** してください。第三者へ絶対に公開しないでください。

### ステップ 6：Dayloom に値を入力

1. Obsidian の **設定（⚙️） → コミュニティプラグイン → Dayloom** を開きます。
2. 上部タブで **☁️ Google カレンダー** をクリックします。
3. **Google カレンダー連携を有効にする** をオンにします。
4. **Google カレンダー OAuth 2.0（同期と編集）** の下にある入力欄に以下を貼り付けます：
   - `Google クライアント ID`
   - `Google クライアントシークレット`
   - `Google リフレッシュトークン`

   コピー時に含まれた余計な空白や改行は自動的に除去されます。

### ステップ 7：表示したいカレンダーの追加

1. 同じタブ内の **Google カレンダー 📅** の横にある **+ カレンダーを追加** をクリックします。
2. 追加された行を設定します：
   - **チェックボックス**：オン = 表示、オフ = 非表示
   - **名前**：Dayloom 上に表示される名前（例：仕事、プライベート）
   - **ID**：メインカレンダーは `primary`、またはカレンダーの ID
   - **色**：このカレンダーの予定の表示色
3. 他のカレンダーの ID を確認する方法：
   ウェブ版 Google カレンダー → 該当カレンダーの **⋮ → 設定と共有 → カレンダーの統合 → カレンダー ID**
   （通常は `xxxx@group.calendar.google.com` の形式です。メインカレンダーの ID はあなたの Gmail アドレスです）。
4. 不要なカレンダーは **削除** ボタンで消去できます。

### ステップ 8：タスク同期先カレンダーの選択（任意）

**タスク同期先の Google カレンダー** でカレンダーを指定すると、日付と時刻のあるすべてのタスクがそのカレンダーへ予定として自動同期されます。

> 💡 **推奨**：Google カレンダー側で `Obsidian Tasks` など **専用のカレンダー** を作成し、ステップ 7 で追加したうえで、ここでそれを選択してください。
> 重複表示を防ぐため、Dayloom は **同期先カレンダーの予定をタイムライン上に予定としては表示しません**（タスクとしてすでに表示されているためです）。
> メインカレンダー（`primary`）を選択してしまうと、既存のミーティング予定などもタイムラインから消えてしまうのでご注意ください。

### ステップ 9：接続のテスト

1. Dayloom ビューを開きます。
2. ヘッダーの **同期** ボタン（↻）をクリックするか、`F5` キーを押します（スマートフォン：**その他 → 同期**）。
3. 「✅ タスクの同期が完了しました！…」通知が表示され、タイムラインに予定が表示されれば成功です。
4. 失敗した場合は OAuth エラー通知が表示されます → [よくある質問 (FAQ)](#8-よくある質問-faq-とトラブルシューティング) を参照してください。

### 同期の仕組み

| 操作 | 結果 |
| --- | --- |
| **同期ボタン / `F5` / `Ctrl+R` (`Cmd+R`)** | Vault 内のタスクを再読み込みし、画面内の予定を再取得し、時刻指定されたタスクを同期先カレンダーへ送信します（60 日前から 365 日先まで）。 |
| **同期ボタンを右クリック（または長押し）** | *タスクを Google カレンダーと同期 📤* ダイアログが開き、対象カレンダーを選択して **今すぐ同期** を実行できます。 |
| **Dayloom 内でタスクを編集**（ドラッグ、編集ダイアログ、チェックボックスなど） | そのタスクの変更内容が Google カレンダーへ即座に反映されます。 |
| **ノート本文のテキストを直接編集** | 自動的には即時送信されず、次回の同期実行時に送信されます。 |
| タスクの日付や時刻を削除 | Dayloom が作成した予定であれば、カレンダーからも予定が削除されます。 |
| Dayloom で同期済みタスクを削除 | カレンダー側の予定も同時に削除されます。 |

- 同期されたタスク行の末尾には `[gcalId:: …]` が付与されます。タスクと予定を紐付ける ID ですので削除しないでください。
- 同期によって削除されるのは **Dayloom が作成した予定のみ** です。ユーザー自身のミーティングや招待された予定が同期によって消えることはありません。
- タイムライン上で Google の予定をドラッグ、サイズ変更、または編集すると、Google カレンダーへ即時保存され、**元に戻す** 通知ボタンが表示されます。
- 一度取得した予定はキャッシュされるため、次回起動時も即座に表示され、バックグラウンドで最新情報に更新されます。

## 3. 設定タブ別ガイド

設定は 5 つのタブに分かれています：

`⚙️ 一般` · `⏱️ タイムライン` · `☁️ Google カレンダー` · `🔔 通知` · `📱 表示`

> 設定項目名は選択した言語で表示されます。本ガイドでは日本語の項目名で説明します。

### ⚙️ 一般

| 設定項目 | 機能説明 | 推奨値 |
| --- | --- | --- |
| **言語 / Language** | Dayloom の表示言語：`自動検出 (Obsidian の既定値)`、`English`、`한국어`、`日本語`、`简体中文`。変更は即座に反映されます | `自動検出` |
| **リリースノート** | **リリースノートを見る** でインストール中のバージョンの新機能ウィンドウを開きます | — |
| **既定のタスクファイル** | 新しいタスクを作成したときに保存される Markdown ノート（クイック入力、タイムラインのダブルクリック）。存在しない場合は自動作成 | `Day Planner.md`（既定）または `Inbox/Tasks.md` |
| **除外するファイルとフォルダー** | タスクのスキャン対象から除外するフォルダーやノート（下記参照） | Templates, Archive |
| **デイリーノートのフォルダー** | デイリーノートが保存されているフォルダーのパス | 例：`Daily` |
| **デイリーノートのファイル名形式** | デイリーノートのファイル名の形式 | `YYYY-MM-DD` |
| **デイリーノートのテンプレート** | 新しいデイリーノートのテンプレートとして使うノート | 例：`Templates/Daily.md` |
| **ウィークリーノートのフォルダー** | ウィークリーノートが保存されているフォルダーのパス | 例：`Weekly` |
| **ウィークリーノートのファイル名形式** | ウィークリーノートのファイル名の形式 | `gggg-[W]ww`（例：`2026-W41`） |
| **ウィークリーノートのテンプレート** | 新しいウィークリーノートのテンプレートとして使うノート | 例：`Templates/Weekly.md` |

テンプレート内では `{{date}}`、`{{title}}`、`{{time}}` プレースホルダーを使用できます。

#### 🔎 パスの入力候補サジェスト

パス入力欄に入力すると、Vault 内のファイルやフォルダーがファジー検索でサジェストされます（例：`dly` と入力するだけで `Daily` フォルダーが見つかります）。
ファイル欄には Markdown ノートのみ、フォルダー欄にはフォルダーのみが表示されます。

#### 🚫 除外するファイルとフォルダー

ルールは Obsidian の検索フィルターのように **チップ（タグ形式）** で管理されます。

1. 入力欄の左側で **除外** または **保持** を選びます。
2. フォルダーまたはノート名を入力し、候補から選択するか `Enter` を押します。
3. ルールがチップとして追加されます：
   - チップを **クリック** すると除外と保持を切り替えられます。
   - チップの **×** で削除できます。
   - Vault 内に実在しないパスはグレーアウト＆取り消し線で表示されます。
4. 下部の「{total} 件中 {excluded} 件のノートを除外しています。」で除外されたノート数を確認できます。

| 指定例 | 適用対象 |
| --- | --- |
| `Archive` | Archive フォルダーとその中のすべてのノート |
| `Templates/Daily.md`（または `Templates/Daily`） | その 1 つのノート |
| `**/Templates` | 階層を問わず名前が `Templates` であるすべてのフォルダー |
| `Daily/*.md` | `Daily` 直下のノート（サブフォルダーは除く） |
| `Archive` を除外 ＋ **保持** `Archive/2026` | Archive 全体を除外しつつ、その中の 2026 フォルダーのみ含める |

> `*` は同一フォルダー階層内、`**` は複数階層をまたいで一致します。大文字と小文字は区別されません。

### ⏱️ タイムライン

| 設定項目 | 機能説明 | 推奨値 |
| --- | --- | --- |

## 4. サイドドロワーとタイムブロッキングの手順

**タイムブロッキング（Timeboxing）** とは、各タスクに特定の時間枠を割り当て、それを *いつ実行するか* を明確に決める手法です。
Dayloom のサイドドロワーは、未スケジュールのタスクを整理し、今日のフォーカスと達成状況を可視化し、スケジュール表へ直感的にドラッグ配置できるようにします。

### ドロワーの開閉

- **デスクトップおよびタブレット** の **Dayloom** メインビューの全タブ（日、N日、週、月、ボード、リスト）で利用できます。
- 開閉操作：`s` キーを押す、ヘッダー右端の **パネルアイコン（▣）** をクリックする、またはコマンド `Toggle Side Drawer` を実行します。ドロワー右上の ⨯ ボタンでも閉じられます。
- **ウィンドウ幅が狭い場合**（900px 以下、分割画面や縦向きタブレットなど）：画面を圧迫せず、プランナーの上にフローティングカードとして重なって表示されます。外側をクリックすれば閉じますが、フローティング中もタスクを中へドラッグできます。
- **スマートフォンおよび Dayloom Compact** にはサイドドロワーがありません：同じタスク一覧や統計パネルは、下部バーの **その他** シート内に収められています（[第6項](#6-タッチ操作スマートフォンタブレットタッチ対応ノートpc) を参照）。

### ドロワーの構成

```
┌ 2026年10月 ▾          ‹ 今日 ›     ⨯ ┐  ← ミニカレンダー（ボードビューでは今日の日付）
│ 日  月  火  水  木  金  土            │
│ ... 6週間のカレンダー、忙しい日にドット ... │
│ [ ☑ タスク 8 │ ◔ 統計 62% ]           │  ← モード切り替え
├───────────────────────────────────────┤
│ [+ 日付なしのタスクを追加 (🔺 ⏫ ...)]   │  ← クイック入力
│ ▾ 📅 今日のタスク       (4)           │  ← 🎯 今日のフォーカスカードが先頭に表示
│ ▾ 🚨 期限切れのタスク   (3) [今日へ移動]│
│ ▾ 📂 日付なしのタスク   (5)           │
└───────────────────────────────────────┘
```

### ミニカレンダー

- **日付をクリック**：プランナーがその日を表示します。現在画面に表示されている期間は帯状にハイライトされ、今日は塗りつぶしの丸で示されます。
- **Ctrl/Cmd+クリック**：その日のデイリーノートを直接開きます。
- **日付の下のドット**：オレンジ = 残りタスクあり、発光する赤 = 🔺 最高のタスクあり、緑 = すべて完了、青 = カレンダーの予定。
- **‹ ›** ボタンまたは **マウスホイール**：月単位で前後に切り替え、**今日** で今月に戻ります。
- **月名をクリック**：カレンダーを 1 週間表示に折りたためます（‹ › 移動も 1 週間単位に変化）。この状態は記憶されます。
- **日付の上にタスクをドロップ**：その日付へタスクが移動します（時間は保持）。
- **ボード** ビューではミニカレンダーの代わりに今日の日付が表示され、タスク一覧を縦いっぱいに広げて使えます。

### タスクモード

- **📅 今日のタスク**：今日に指定されたすべてのタスク（時刻指定の有無を問わず）。未完了タスクが先頭に並び、時刻順にソートされます。完了タスクはチェックをその場で外せるようにグレー表示で残り、`↗` を押すと該当ノートが開きます。**ここへタスクをドロップ** すると今日の日付に変更されます。
- **🎯 今日のフォーカス**（今日のタスクの最上部）：今日の中で **🔺 最高** 優先度を持つタスクが、FOCUS バッジ付きの強調カードとして表示されます。**任意のタスクをフォーカス枠へドロップ** すると、そのタスクが今日のフォーカスになります（日付が今日になり、優先度が 🔺 最高へ昇格。日付なしタスクには今日の日付 `📅` が付与）。フォーカスタスクがない状態でも、ドラッグ中には受け入れ枠が自動出現します。
- **🚨 期限切れのタスク**：今日より前の日付の未完了タスク。優先度 → 古い日付順 → タイトル順に並び、過ぎた日付が赤字で示されます。
- **📂 日付なしのタスク**：日付を持たないタスク（ボードビューの *日付なし* 列と同じ一覧）。優先度 → タイトル順に並びます。
- 空のセクションは **自動的に折りたたまれ**、タスクが入ると展開されます。ヘッダーをクリックして手動で折りたたむこともできます。
- **🔺 最高** のカードは赤い縁取りと微光、**⏫ 高** のカードは琥珀色の縁取りが付き、完了カードはグレーに変わります。

### 統計モード

プランナーで **現在表示されている日** のまとめ情報を提供します（ミニカレンダーで別の日を選ぶと切り替わります）：

- **進捗サークル**：計画時間に対する完了時間の割合（時刻指定タスク基準、キャンセルを除く）。時刻指定タスクがない場合は完了タスク数ベースで表示されます。
- **計画 / 完了 / 残り** 時間の要約。
- **完了タスク数**、**フォーカスタスク完了数**、**カレンダー予定の時間**、**優先度別の内訳**。
- 状況に応じた短い励ましのメッセージ。

検索中であっても統計は絞り込まれず、常に一日全体の状況を集計します。

### ① クイック入力

1. ドロワー最上部の入力欄にタスクを入力し、`Enter` を押します。
2. **既定のタスクファイル** に日付なしタスクとして即時追加され、通知が表示されます。
3. `⏫ 企画書のドラフト作成` のように優先度絵文字を含めて入力できます。
4. 日本語・韓国語・中国語の IME 入力中も変換確定後の `Enter` 1 回で保存されます。

### ② 優先度の設定

カードの優先度バッジをクリックするか（未設定時はホバーで薄い旗アイコン表示）、カードを選んで `p` キーを押します。
🔺 最高、⏫ 高、🔼 中、○ 標準、🔽 低、⏬ 最低 から選択できます（矢印キーと `Esc` も対応）。絵文字がノート本文に直接書き込まれます。

### ③ スケジュール表へタスクをドラッグ配置

| ドロップ先 | 結果 |
| --- | --- |
| **タイムスロット**（日 / N日 / 週） | その日付と時刻（15分刻み）に配置。長さ：**タスクの既定の長さ** |
| **月ビューまたはミニカレンダーの日付** | 日付のみ変更（時刻は保持。時刻なしタスクは終日のまま） |
| **週 / N日ビューの曜日ヘダー** | **空き時間に配置（Fit It In）**：その日の最初の空き時間枠へ自動配置 |
| **ボードの列** | カンバンモード：その列の日付（または完了）；優先度モード：その優先度を付与 |
| **📅 今日のタスク** | 日付を今日に変更（時刻は保持） |
| **🎯 今日のフォーカス** | 日付を今日に変更 ＋ 優先度を 🔺 最高 に設定 |
| **ドロワーのその他の領域** | スケジュール解除（日付・時刻を削除、下記 ⑤ 参照） |

- ドラッグ中、タイムライン上では配置される時刻（例：`14:30`）を示す点線プレビューが現れます。それ以外の場所ではタスク名が書かれた小さなチップがポインタに追従し、真下の日付、列、ドロワーセクションがハイライトされます。
- ドラッグ中に `j` / `k` を押すと、タスクを掴んだまま次の日 / 前の日（または週）へページをめくれます。
- ドラッグ中にビュー切り替えキー（`d`, `x`, `w`, `m`, `b`, `l`）を押すと、タスクを保持したまま別のビューへ持ち運べます（例：日ビューでブロックを持ち上げ、`m` を押して月ビューの特定の日付に置く）。
- ドラッグ中に `Esc` を押すと操作をキャンセルできます。
- すべての変更操作に対して、画面下部に **元に戻す（Undo）** ボタン付きの通知が表示されます。

### ④ 複数のタスクを連続して配置

1. ドロワーのカードを **Ctrl/Cmd+クリック** するか、リストの空きスペースを **ドラッグして四角い枠** で囲み、複数のカードを選択します。
2. 選択されたカードのいずれかをタイムラインへドラッグします。
3. ドロップした時刻から、ドロワーの並び順に従って **連続して隙間なく（back-to-back）** 配置されます。各タスクの既存の長さを保持するか、既定の長さが適用されます。
4. 深夜（24:00）を越えてしまうタスクはみ出さず、元の位置に留まります。1 回の元に戻すで全体の配置を元に戻せます。

`Esc` を押すとドロワーの選択が解除されます。

### ⑤ スケジュール解除（日付と時刻の削除）

タイムラインのブロック、終日タスク、月ビューのタスク、ボードのカードを **ドロワー内へドラッグ** すると、日付と時刻が削除されて「日付なし」に戻ります。

- 時刻、`⏳` 予定日、`📅` 期限日がすべてノート本文から削除されます。
- **デイリーノート内に書かれたタスク** はファイル名自体が日付であるため、日付は消えずに保持されます（通知で案内されます）。
- Google カレンダーの予定をドロワーへドラッグしてもカレンダーから削除されることはありません。
- 誤操作を防ぐため、期限切れカードやフォーカスカードは、ドロワー内の **日付なしのタスク セクション上へドロップした場合にのみ** スケジュールが解除されます。

### ⑥ 期限切れタスクの整理（トリアージ）

- 期限切れカードにカーソルを合わせると素早い操作ボタンが現れます（タッチ画面では常時表示）：
  `今日へ移動` · `明日` · `+1週` · `日付解除`。日付のみが変更され、設定されていた時刻はそのまま維持されます。
- セクションヘッダーの **今日へ移動** ボタンを押すと、期限切れのタスクすべてを一度に今日へ移動できます（元に戻す対応）。

### ⑦ ドロワーカードのキーボード操作

`Tab` キーを押してカードにフォーカスを当ててから：

| キー | 動作 |
| --- | --- |
| `Enter` | タスクの内容を編集 |
| `f` | **空き時間に配置（Fit It In）**：今後 14 日以内の最初の空き枠へ自動配置 |
| `p` | 優先度設定メニューを開く |

「空き時間に配置」は **タイムラインの開始/終了時刻** を稼働時間とみなし、今日については現在時刻以降の空き枠のみを探し、既存のタスクや Google カレンダーの予定との重複を自動的に避けて配置します。入る枠がない場合は「空きスロットがありません」という通知が出ます。

### おすすめの一日のルーティン ☀️

1. 朝、Dayloom を開いて `s` キーでサイドドロワーを展開します。
2. **期限切れのタスク** を確認し、`今日へ移動`、`明日`、または `日付解除` で整理します。
3. 今日の最も重要なタスクを 1〜2 個選び、**🎯 今日のフォーカス** へドラッグします。
4. 頭に浮かんだ新しいタスクをドロワーの **クイック入力** で書き留めます。
5. **日付なしのタスク** から今日やるものを複数選択し、タイムラインへドラッグしてスケジュールに連続配置します。
6. ブロックの下端を引っ張って想定される所要時間に合わせ、一日が終わったら **統計** を確認して振り返ります。

## 5. ビュー、検索、選択とショートカット

### 6 つのビュー

| ビュー（タブ） | ショートカット | 主な特徴 |
| --- | --- | --- |
| **日** | `d` | 1 日分のタイムライン。現在時刻線、進行中のタスクの進行バー、上部に固定された「終日」行 |
| **N日** | `x` | 2〜14 日間を並べて比較（タブ内で日数を即座に変更可能） |
| **週** | `w` | 1 週間分のタイムライン。**曜日ヘッダーをクリック** するとその日の日ビューへ移動 |
| **月** | `m` | 1 ヶ月のカレンダー。**日付セルをクリック** するとその日の日ビューへ、**週番号をクリック** すると週ビューへ移動 |
| **ボード** | `b` | *カンバン* モード（日付なし · 期限切れ · 今日 · 明日 · 今後 · 完了済み）および *優先度* モード（最高 🔺 … 最低 ⏬、未着手タスク）。`j` / `k` で両モードを切り替え |
| **リスト** | `l` | 今月のアジェンダ形式一覧。検索中は全日程の一致項目をまとめて表示 |

- **ボード** では、カードを別の列へドラッグすると日付が変わります（今日 → 今日、明日 → 明日、今後 → 3日後、期限切れ → 昨日、日付なし → 日付削除、完了済み → 完了；完了済みから外へ出すと未着手へ復帰）。*優先度* モードではドラッグ先の優先度に変更されます。複数カードを選んでまとめて動かすこともでき、列の左にある矢印で列を折りたためます。
- ビューの切り替えは一瞬です：すべてのビューがメモリにキャッシュされ、データに変更があったときだけ再描画されます。

### ヘッダーの構成（デスクトップおよびタブレット）

```
[📅 日付]     [ 日 | 4日 | 週 | 月 | ボード | リスト ]     [‹ 今日 ›] [🔍 🔎 ↻ ? ▣] [+]
```

| コントロール | 機能説明 |
| --- | --- |
| 📅 日付ピル | その日のデイリーノート / ウィークリーノートを開く（日ビューで週番号をクリックするとウィークリーノートが開く） |
| ビュータブ | ビューを切り替えます。切り替えても日付は維持され、画面幅が狭いときは別行へ折り返されます |
| ‹ 今日 › | 前へ / 今日 / 次へ（常に今日基準のボードビューを除く） |
| 🔍 ズーム | 日 / N日 / 週ビューにおける 1 時間の高さ調整：ホバーまたはクリックでスライダー表示 |
| 🔎 検索 | タスクと Google カレンダー予定の検索（`/`） |
| ↻ 同期 | Google カレンダーと同期（右クリック：タスク同期ダイアログ）。カレンダー連携が有効な場合に表示 |
| ? | キーボードショートカット一覧（設定で非表示に可能） |
| ▣ パネル | サイドドロワーの開閉 |
| **+** 追加 | 新しいローカルタスクまたは Google の予定を追加（*ローカルタスクを追加* / *予定を追加*） |

ボードビューでは、ヘッダーに **カンバン / 優先度** の切り替えスイッチが加わります。
ヘッダー、メニュー、ダイアログの色は、お使いの Obsidian テーマに完全に馴染みます。

### 🔍 検索

1. `/` または `Ctrl/Cmd+F` を押すか、検索アイコンをクリックします。ヘッダーのボタンが引っ込み、全幅の検索入力バーが展開されます。
2. 文字を入力すると、現在のビューがリアルタイムに絞り込まれます。タスク本文（`#タグ` を含む）、ノートのファイルパス、Google 予定のタイトル・場所・説明・カレンダー名すべてが検索対象です。スペース区切りで複数単語を入力すると AND 検索になります。一致した件数が表示されます。
3. **Enter** を押すと **リスト** ビューに切り替わり、**過去や未来を含む全日程の一致項目** が一覧表示されます。
4. **Esc** を押すか **×** をクリックすると検索が閉じ、すべての項目が再び表示されます。

日付なしタスクはリストビューには含まれないため、検索中の一致する日付なしタスクはドロワーの日付なしセクションに絞り込まれて表示されます。

### ✅ 複数選択と削除

| 操作 | 実行方法 |
| --- | --- |
| 1 項目を追加 / 選択解除 | 項目を **Ctrl/Cmd+クリック**（編集ダイアログは開かず、選択状態のみ反転） |
| 複数項目を一度に枠囲み選択 | 空きスペース上で **マウスをドラッグして四角い枠（Marquee）** を作る：タイムライン、終日行、ボード、ドロワーのリスト |
| 既存の選択に枠囲みを追加 | `Ctrl`、`Cmd`、または `Shift` を押しながら四角い枠をドラッグ |
| 選択の解除 | 空白をクリック、`Esc` を押す、または選択バーの × ボタンをクリック |
| まとめて移動 | 選択されたいずれかの項目をドラッグ：他の項目も連動して移動（タイムラインブロックは間隔を維持、ドロワーカードは連続配置） |
| 削除 | `Delete` または `Backspace` を押す、あるいは選択バーの **削除** ボタンをクリック |

- 選択範囲は **1 つのエリア** に属します：タイムライン / ボード / 月グリッド、終日行、またはサイドドロワーのいずれかです。別のエリアで新しく選択すると、前の選択は解除されます。
- **削除** を実行すると、まず確認ダイアログが表示されます（`Enter` で実行、`Esc` でキャンセル）。ノート本文からタスク行が削除され、選択された Google 予定もカレンダーから削除されます。削除後に表示される通知で **元に戻す（Undo）を 1 回押すだけ** で、Google 予定を含めたすべてが完全に復元されます。
- タスクや予定の編集ダイアログにも **削除** ボタンがあります（ダイアログ内で `Delete` / `Backspace` を押した際も確認画面が出ます。文字入力中に誤って削除されることはありません）。

### ⌨️ キーボードショートカット

> ショートカットは、Dayloom ビューがアクティブな状態（一度クリックした状態）で作動します。クイック入力、検索バー、エディタなどの入力欄にカーソルがある間は文字入力が優先されます。`Ctrl/Cmd+R` と `Ctrl/Cmd+F` を除き、一般的な修飾キーの組み合わせは Obsidian 本来の機能のために保持されます。

| キー | 動作 |
| --- | --- |
| `j` / `k` | 次 / 前の日または期間（デスクトップボード：カンバン/優先度切り替え；コンパクトボード：次 / 前の列） |
| `t` | 今日へ移動 |
| `d` / `x` / `w` / `m` / `b` / `l` | 日 / N日 / 週 / 月 / ボード / リスト ビュー切り替え |
| `s` | サイドドロワーの開閉 |
| `/` または `Ctrl/Cmd+F` | タスクと予定の検索 |
| `?` または `h` | ショートカット一覧の表示 / 非表示 |
| `F5` または `Ctrl/Cmd+R` | 同期（タスクの再スキャン ＋ Google カレンダーの更新） |
| `Delete` / `Backspace` | 選択した項目を削除 |
| `Esc` | ドラッグ/サイズ変更/枠選択のキャンセル → 選択の解除 → 検索の終了 |
| `Ctrl/Cmd + クリック` | 選択項目への追加 / 選択解除 |
| `Ctrl/Cmd + ドラッグ` | 枠囲みドラッグで選択に追加 |
| `Enter` / `f` / `p`（ドロワーカード選択時） | 編集 / 空き時間に配置 / 優先度設定 |
| `j` / `k` / 各ビューキー（ドラッグ中） | タスクを離さずに日付送りやビュー切り替え |

### 🖱️ マウス操作

| やりたいこと | 操作 |
| --- | --- |
| タスクの編集 | ブロックをクリック → 編集ダイアログが開く |
| 完了にする | チェックボックスをクリック（完了 ↔ 未着手の切り替え；進行中などの状態は完了へ）。他のステータスは編集ダイアログで指定 |

## 6. タッチ操作：スマートフォン、タブレット＆タッチ対応ノートPC

### 長押しドラッグ（すべてのタッチ画面対応）

タッチスクリーンでは素早くスワイプすると画面スクロールになるため、タスクを持ち上げるには **長押し（約0.3秒）** を行います：

1. ブロックやカードが少し浮き上がるまで **指で長押し** します（対応端末では短い触覚振動が発生）。
2. そのまま指を離さずに **ドラッグ** します：マウスドラッグで可能な操作（ドロワー、月ビューの日付、ボードの列など）がすべて同様に機能します。
3. 指を離すとその場所にドロップされます。動かさずに指を離せば元の位置に戻ります。

タイムライン上のブロックを長押しすると、ブロックの **サイズ変更バー** も同時に表示されます：上端または下端のバーを引っ張って時間を変更できます。サイズ変更バーが表示されている間は、ブロックの中央をタッチすれば即座にドラッグ移動できます。画面の他の場所をタップするとこのモードが終了します。

一本の指でタスクを押さえたまま、**もう一方の指でビュータブや日付の矢印、日付ピルをタップ** することで、タスクを持ったまま別のビューや別の日付へ持ち運ぶことができます。

### タッチ対応ノートPC

Dayloom は指によるタッチと、マウスやタッチパッドの操作を賢く識別します：

- **指でのタッチ**：上記のように長押しでドラッグし、素早く払うとスクロールになります。
- **マウス / タッチパッド / スタイラスペン**：通常のデスクトップ同様、即座にドラッグできます。マウスを重ねるとサイズ変更バーが現れます。

### スマートフォン（および Dayloom Compact）

- **下部バー**：**日 · リスト · 月 · ボード** と **その他** のボタンで構成されます（週ビューと N日ビューはメインの Dayloom で利用可能）。
- **ヘッダー**：日付、**‹ 今日 ›** ボタン、**+** 追加ボタンが並びます。
- **日付ストリップ**：日およびリストビューのヘッダー直下に 1 週間分の日付ピルが並び、タップするだけでその日に切り替わります。
- **スワイプで日付移動**：プランナー内を左右にスワイプして日付（ボードでは列）をめくります。画面の端から始めたスワイプは常に Obsidian のサイドバーを開きます。このスワイプ機能は設定 → 表示でオフにできます。
- **リスト**：一日分のアジェンダ形式で見やすく表示します（左側に時刻、カラーレール、所要時間、保存先ノート名、完了状況の要約）。
- **月**：日付セルに入る分だけ予定を表示し、溢れた分は `+N` で示されます。日付をタップすると日ビューで開きます。
- **ボード**：1 列ずつ大きく表示され、上部ストリップのタップや左右スワイプで列を切り替えます。
- **その他**：タップするとボトムシートが開き、**検索**、**同期**（長押しでタスク同期オプション）、**タイムラインのズーム** スライダー、そしてドロワーの **タスク** および **統計** パネル（今日のタスク、今日のフォーカス、期限切れのタスク、日付なしのタスク）が利用できます。シートの外側をタップするか、下へスワイプするか、`Esc` を押すと閉じます。
- **ダブルタップ**：空いている時間枠をダブルタップして新しいタスクを作成します。

### タブレット

タブレットでは、サイドドロワーを含むフルデスクトップレイアウトがそのまま提供され、長押しタッチによるドラッグに対応します。トラックパッド、マウス、Apple Pencil を使用する場合は、デスクトップ同様に即座にドラッグ操作が行えます。

## 7. タスク構文とインラインコードブロック

### 基本構文

```markdown
- [ ] タスクのタイトル ⏰09:00-10:30 ⏫ 🔁 every week ⏳ 2026-10-07 📅 2026-10-10
```

| 構成要素 | 構文表記 | 意味 |
| --- | --- | --- |
| ステータス | `[ ]` `[/]` `[x]` `[-]` | 未着手 / 進行中 / 完了 / キャンセル済み |
| 時刻 | `⏰09:00-10:30` | 開始–終了。終了時刻がない場合（`⏰09:00`）は 30 分として表示 |
| 優先度 | 🔺 ⏫ 🔼 🔽 ⏬ | 最高 / 高 / 中 / 低 / 最低（指定なし = 標準） |
| 予定日 | `⏳ YYYY-MM-DD` | Dayloom でスケジュールした際に書き込まれる基準日 |
| 期限日 | `📅 YYYY-MM-DD` | 予定日がない場合に参照される日付 |
| 開始日 | `🛫 YYYY-MM-DD` | Obsidian Tasks プラグイン互換用 |
| 完了日 / キャンセル日 | `✅ YYYY-MM-DD` / `❌ YYYY-MM-DD` | タスクを完了またはキャンセルした際に自動付与 |
| 繰り返し | `🔁 every day` など | チェックを入れると次の期日のタスクが新しい行に自動生成 |
| Google リンク | `[gcalId:: …]` | 同期によって自動付与（手動で編集しないでください） |

#### その他の時刻表記

Dayloom は以下の表記形式も時刻として認識します：

```markdown
- [ ] 09:00 - 10:00 ミーティング          ← タイトルの前に時刻
- [ ] ミーティング [09:00-10:00]          ← 角括弧表記
- [ ] ミーティング [startTime:: 09:00 - 10:00]
```

#### 日付の判定優先順位

`⏳ 予定日` → `📅 期限日` → **ノートのファイル名に含まれる日付**（デイリーノート）。
例えば `Daily/2026-10-07.md` ノート内に `- [ ] 筋トレ ⏰07:00-08:00` とだけ書いても、10 月 7 日の 07:00 のブロックとして配置されます。

#### 繰り返しルール

`every day`（`daily`）、`every week`（`weekly`）、`every month`（`monthly`）、`every year`（`yearly`）、`every weekday`（平日毎日）、および `every N day/week/month/year`（例：`every 3 days`）。

### インラインコードブロック：```` ```dayloom ````

ノート本文の好きな場所に Dayloom のビューを直接埋め込むことができます。コマンドパレットの **Insert Inline View (dayloom block)** を実行すると簡単に挿入できます。

````markdown
```dayloom
type: daily
height: 500px
```
````

> 以前のブロック名である ```` ```dayplanner ```` や ```` ```dayplanner-pro ```` も引き続き機能します。

| オプション | 指定可能な値 | 意味 |
| --- | --- | --- |
| `type` | `daily` · `multiDay` · `weekly` · `monthly` · `board` · `list` | 表示するビュー。ブロック内のタブをクリックすると自動的に更新されます |
| `date` | `YYYY-MM-DD` または `today` | 表示する日付 |
| `height` | `500px`、`80vh` など（単位なしの数字は px） | ブロックの高さ。下端をドラッグして高さを変えると自動保存されます |
| `hourHeight` | 数値 | このブロック専用の 1 時間の高さ |
| `showFilters` | `true` | 最初からフィルターバーを開いた状態で表示 |
| `collapsedColumns` | `[undated, completed]` | 初期状態で折りたたんでおくボード列 |
| `filters` | （フィルターパネルから自動書き込み） | 下記フィルター項を参照 |

- **デイリーノート** 内に `type` や `date` のないブロックを置くと自動的にその日のタスクが表示され、**ウィークリーノート** 内ではその週が表示されます。ブロック内はその日またはその週のタスクのみに絞られます。
- インラインブロック内では、曜日ヘッダー、日付、週番号をクリックすると該当するデイリー / ウィークリー **ノート** が開きます（ブロック自体には切り替えタブがないため）。リストビューには専用の検索ボックスが付属します。
- メインビューと同様にマウスドラッグで操作でき、画面に表示されているときだけ描画されるため快適に動作します。

### 🔍 インラインブロックのフィルター機能

ブロックのヘッダーにある **🔍 フィルター** ボタンをクリックすると、1 行のフィルターバーが開きます。ボタンには適用中の条件数が表示されます（例：`🔍 フィルター · 2`）。

```
[すべて一致 ▾] [📁 フォルダー = Work ×] [# タグが #urgent を含む ×] [+ フィルター]
```

1. **+ フィルター** → 種類を選択：`フォルダー` · `ファイル` · `タグ` · `ステータス` · `優先度` · `日付` · `テキスト` · `項目の種類`
2. 表示されるエディター行で条件と値を選択し、**完了**（または `Enter`）を押します。
3. チップをクリックすればいつでも再編集でき、`×` で削除できます。
4. 先頭の **すべて一致 / いずれかに一致 / いずれにも一致しない** で条件の結合方法を指定します。
5. より複雑な条件を作りたい場合は、**+ フィルター → グループ（いずれかに一致…）** で括弧付きのグループを追加できます。

| フィルター種類 | 指定可能な条件 |
| --- | --- |
| フォルダー | `含まれる` / `含まれない` ＋ フォルダー名（サジェスト機能付き） |
| ファイル | `一致する` / `一致しない` ＋ ノート名 |
| タグ | `含む` / `完全一致` など ＋ `urgent`（`#` は省略可、サブタグも対象） |
| ステータス | `一致する` / `一致しない` ＋ 未着手 · 進行中 · 完了 · キャンセル済み |
| 優先度 | `一致する` / `以上` / `以下` ＋ 優先度 |
| 日付 | `一致する` / `より前` / `より後` ＋ 今日 · 明日 · 今週 · 今月 · 指定日、または `未設定` / `設定あり` |
| テキスト | `含む` / `前方一致` など ＋ テキスト |
| 項目の種類 | タスク / Google カレンダーの予定 |

フィルターは編集中にリアルタイムで適用されます。パネルを閉じると、コードブロック内に YAML 形式で自動保存されます（手動で直接編集することも可能です）：

```yaml
filters:
  kind: group
  mode: all
  children:
    - kind: rule
      type: folder
      operator: contains
      value: "Work"
    - kind: rule
      type: status
      operator: notEquals
      value: "completed"
```

> 💡 ヒント：プロジェクトノートに `Folder in Projects/Alpha` のフィルターを適用したボードブロックを置けば、そのプロジェクト専用のカンバンボードが完成します。

## 8. よくある質問 (FAQ) とトラブルシューティング

### Q1. タスクがプランナーに表示されません。

- 行が正しく `- [ ] ` で始まっているか確認してください（`*` 記号や番号付きリストはタスクとして認識されません）。
- タイムラインは **日付のあるタスクのみ** 表示します。日付のないタスクはドロワーの **日付なしのタスク** セクションやボードの **日付なし** 列を確認してください。
- 設定 → 一般 → **除外するファイルとフォルダー** でそのノートが除外対象になっていないか確認してください。
- 同期ツール（Syncthing など）によって生成された競合コピーファイル（ファイル名に `.sync-conflict-` を含むもの）は意図的に除外されます。
- 検索が有効になっていないか確認してください。`Esc` を押して検索をクリアしてみてください。
- `F5` を押して Vault 全体を再スキャンしてみてください。

### Q2. ノートに文字を入力している間、プランナーがすぐに更新されません。

これはタイピングの快適さを保つための意図的な仕様です：Dayloom はユーザーが **キーボードの入力を止めてから約 2 秒後** にノートを再読み込みし、画面を更新します。

### Q3. Google トークンを更新するときに "invalid_grant" エラーが出ます。

リフレッシュトークンが有効期限切れか、取り消されています。

- OAuth 同意画面が **テスト中（Testing）** の場合、トークンは **7 日後に自動失効** します。同意画面を **本番環境（In production）** に切り替えたうえで、[ステップ 5](#ステップ-5リフレッシュトークンの取得oauth-20-playground) に従って新しいリフレッシュトークンを再発行してください。
- Google アカウントのパスワードを変更した場合や、Google のセキュリティ設定でアプリの連携を解除した場合にもトークンは無効化されます。

### Q4. "unauthorized_client" または "invalid_client" エラーが出ます。

- クライアント ID とクライアントシークレットが文字抜けなく完全にコピーされているか確認してください。
- リフレッシュトークンは、**必ず同じクライアント ID とシークレットを使用して発行されたもの** である必要があります。Playground で *Use your own OAuth credentials* にチェックを入れずに取得したトークンは機能しません。

### Q5. Google カレンダーの予定が表示されない、または一部しか表示されません。

- 設定 → ☁️ Google カレンダー → **Google カレンダー 📅** 一覧で該当カレンダーが追加され、**チェックが入っているか** 確認してください。
- **タスク同期先の Google カレンダー** に指定されたカレンダーの予定は、重複を防ぐため画面上に予定としては表示されません。ミーティングなどが入っているメインカレンダーを同期先カレンダーに指定しないでください。
- 同期ボタン（↻）をクリックするか `F5` キーを押して更新してください。

### Q6. ノート側で時刻を変更したのに Google カレンダーが更新されません。

ノート本文で直接テキストを書き換えた内容は、Google API へ自動的に即時送信されません。ヘッダーの **同期** ボタン（↻）または `F5` を一度押してください。
Dayloom のプランナー画面内でドラッグしたり編集したりしたタスクは、即座に Google カレンダーへ送信されます。

### Q7. タスクの末尾に付く `[gcalId:: …]` が邪魔です。

これはタスクと Google カレンダーの予定を結びつける重要な識別子ですので、削除しないでください。代わりに設定 → 📱 表示 → **インラインメタデータを隠す** を有効にすれば、ノート本文のデータはそのまま画面の表示上だけ綺麗に非表示にできます。

### Q8. 通知が届きません。

- 設定 → 🔔 通知 → **通知方法** が `オフ` になっていないか確認してください。
- そのタスクに **今日の日付** と **開始時刻（`⏰HH:mm`）** が設定されているか確認してください。
- システム通知を使用する場合、OS 側の通知許可が必要です。拒否してしまった場合は、OS の設定で Obsidian の通知を許可してください（許可がない場合は Dayloom がアプリ内通知に切り替えます）。
- チャイム音が鳴らない場合は 🔊 テストボタンを押してみてください。スマートフォン等のモバイル端末では、セキュリティ仕様上画面を一度タップするまで音声再生が許可されないことがあります。

### Q9. ショートカットキーが効きません。

- Dayloom の画面内を一度マウスクリックして **アクティブビュー** にしてください。
- クイック入力欄、検索バー、エディタなどテキスト入力欄にカーソルがあるときは、文字入力が優先されショートカットは反応しません（正常な挙動です）。
- `?` をもう一度押すと開いているショートカット一覧が閉じます。

### Q10. タイムライン上のブロックが動かせません。

- 完了（`[x]`）やキャンセル（`[-]`）されたタスクは安全のためロックされます。チェックを外せば再び動かせます。
- タッチ画面では、素早く払うとスクロールになるため、ブロックを **約 0.3 秒長押ししてから** ドラッグしてください。

### Q11. サイドドロワーが表示されません。

サイドドロワーは **デスクトップおよびタブレットの Dayloom メインビュー** で提供されます。`s` キーを押すか、ヘッダー右端のパネルアイコン（▣）をクリックしてください。
スマートフォンや右サイドバーの Dayloom Compact では、下部バーの **その他** シート内に同じパネルが収められています。

### Q12. ドロワーがタイムラインの一部を覆ってしまいます。

プランナーのウィンドウ幅が 900px 以下のときは、画面が狭くなりすぎるのを防ぐため、ドロワーがフローティングカードとして重なって表示されます。外側をクリックするか `s` キーを押せば閉じられます。ウィンドウ幅を広げると画面の横にドッキングされます。

### Q13. クイック入力で追加したタスクが「日付なし」に現れません。

設定の **既定のタスクファイル** に指定されているノートのファイル名に日付が含まれている場合（例：`2026-10-07.md`）、追加されたタスクはその日のタスクとして扱われます。日付を含まないファイル名（例：`Inbox.md` や `Day Planner.md`）を指定してください。

### Q14. 誤って項目を移動または削除してしまいました。元に戻せますか？

はい。項目を変更または削除するたびに、画面下部に数秒間 **元に戻す（Undo）** ボタン付きの通知が表示されます。複数の項目をまとめて移動・削除した場合でも 1 回で元に戻り、一緒に削除された Google カレンダーの予定も同一の予定として復元されます。

### Q15. Google の認証情報はどこに保存されますか？ 安全ですか？

クライアントシークレットとリフレッシュトークンは、Vault 内の `.obsidian/plugins/obsidian-day-planner-pro/data.json` にローカル保存されます。短命なアクセストークンはメモリ内にのみ保持され、ディスクに書き込まれることはありません。取得した予定のキャッシュは同じ場所の `gcal-cache.json` に保持されます。
Vault 全体を公開 GitHub リポジトリ等にアップロードする場合は、これらのファイルを `.gitignore` などで確実に除外してください。
アクセスを完全に遮断したい場合は、Google アカウント設定 → セキュリティ → **サードパーティ製のアプリとサービス** から Dayloom の連携を解除してください。

### Q16. Syncthing などで Vault を同期しています。注意点はありますか？

Dayloom は設定が実際に変更されたときのみ `data.json` を書き込み、他端末から届いた最新の `data.json` を自動検出して取り込み、`.sync-conflict-` の付いた競合コピーファイルは安全に無視します。同期の途中で `data.json` が一時的に読み取れない瞬間があっても、ファイルを上書きせず安全に既定値で動作します。

### Q17. Dayloom の言語や色が正しく表示されません。

- 言語：設定 → 一般 → **言語 / Language** を確認してください。`自動検出` は Obsidian 自身の言語設定に従いますが、手動で特定の言語に固定することもできます。
- 色は Obsidian のテーマ設定に従います。タスクブロックは **ローカルタスクの色** を使用し、各 Google カレンダーは設定（設定 → ☁️ Google カレンダー）で指定した色で表示されます。
