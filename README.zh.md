## 1. 什么是 Dayloom？核心概念

### 它是做什么的？

Dayloom 会自动收集你 Obsidian 笔记中的**复选框任务（`- [ ]`）**，并将它们排布成直观的时间线日程表。  
为任务添加日期和时间后，它就会在时间线上以色块呈现；拖动色块时，**你笔记中的文本内容也会随之实时同步修改。**  
无需任何外部数据库：所有数据完全保存在你自己的本地 Markdown 文件中。

### 功能概览

| 功能 | 说明 |
| --- | --- |
| 6 种视图 | 日时间线、N 天视图（2–14 天）、周视图、月历、看板（标准看板 / 优先级聚焦）、列表视图 |
| 时间块管理 | 拖动任务到指定时段；通过上/下边缘手柄拖拽调整持续时长 |
| 侧边抽屉 | 迷你日历、🎯 今日焦点、逾期任务、无日期任务、每日统计面板（桌面端所有视图均支持） |
| 展开式搜索 | 按 `/` 键标题栏直接化身为搜索框；回车后自动跳转至列表视图并列出所有匹配项 |
| 多选与删除 | 全视图支持 Ctrl/Cmd+点击以及鼠标框选；Delete 键可批量删除（支持撤销） |
| Google 日历 | 浏览、编辑、创建日程；可将带时间的任务双向同步到指定日历 |
| 开始提醒 | 在开始时（或提前 5–30 分钟）通过应用内提示或系统通知进行提醒，伴有提示音 |
| 行内代码块嵌入 | 使用 ```` ```dayloom ```` 代码块在任意笔记正文中嵌入带筛选器的规划器组件 |
| Tasks 插件兼容 | 完美支持 Obsidian Tasks 插件的标准 Emoji 语法（📅 ⏳ 🛫 ✅ ❌ 🔁 🔺⏫🔼🔽⏬） |
| 多语言支持 | 支持 English、한국어、日本語、简体中文（自动跟随系统或在设置中手动指定） |

### 两个窗口：Dayloom 与 Dayloom Compact

| 名称 | 如何打开 | 说明 |
| --- | --- | --- |
| **Dayloom** | 点击功能区日历图标 *Open Dayloom*，或运行命令 `Open Dayloom` | 主规划器标签页。在桌面端配有侧边抽屉。 |
| **Dayloom Compact** | 点击功能区时钟日历图标 *Open Dayloom Compact*，或运行命令 `Open Dayloom Compact` | 停靠在右侧边栏的紧凑型视图，底部带有 5 个标签页（日 · 2 天视图 · 月 · 看板 · 列表）。 |

> 💡 按 `Ctrl+P`（Mac 为 `Cmd+P`）打开**命令面板**并输入 "Dayloom"，即可查看所有相关命令。

### 基本概念

- **一条任务即一行复选框**：在笔记中写入 `- [ ] 撰写报告`，Dayloom 就会自动识别。
- **日期判断顺序**：优先识别 `⏳ 2026-10-07`（计划日期），其次识别 `📅 2026-10-07`（截止日期），最后识别**日记文件的名称**。  
  例如在 `2026-10-07.md` 日记中书写的任务，即便行内没有日期标识，也会自动属于当天。
- **时间格式**：格式为 `⏰09:00-10:30`。带时间的任务会排布在时间线上；未安排时间的任务则置于顶部的“全天（All Day）”栏。
- **任务状态**：由复选框内的字符决定：`[ ]` 待办，`[/]` 进行中，`[x]` 完成，`[-]` 已取消。

## 2. Google 日历 OAuth 2.0 配置指南

> 📌 Google 日历集成是**可选功能**。即使不配置，Dayloom 的所有本地任务规划功能依然完全可用。

### Dayloom 的登录认证机制

Dayloom **没有提供一键式的“使用 Google 登录”按钮**。你需要将以下三个关键凭据手动填入插件设置中：

| 设置项 | 说明 | 示例外观 |
| --- | --- | --- |
| `Google 客户端 ID` | 你在 Google Cloud 创建的 OAuth 网页应用的客户端 ID | `xxxx.apps.googleusercontent.com` |
| `Google 客户端密钥` | 该应用的密钥字符串 | `GOCSPX-xxxx` |
| `Google 刷新令牌` | 用于自动获取短期访问令牌的离线长效令牌 | `1//0xxxx` |

Dayloom 会使用这组凭据定期向 Google 授权服务器（`https://oauth2.googleapis.com/token`）申请刷新访问令牌。  
因此，你只需在首次使用时**① 在 Google Cloud 中创建 OAuth 应用，② 获取一次长效刷新令牌**即可（全程约需 15–20 分钟）。

> ⚠️ Google Cloud 控制台的界面可能会发生改动。若个别菜单名称稍有差异，寻找对应含义的选项操作即可。

---

### 第 1 步：创建 Google Cloud 项目

1. 前往 [Google Cloud Console](https://console.cloud.google.com/) 并使用你的 Google 账号登录。
2. 点击顶部导航栏的**项目选择下拉框**，然后点击右上角的 **[新建项目]**。
3. 输入易于识别的项目名称（如 `Dayloom`），然后点击 **[创建]**。
4. 确保在顶部下拉框中已切换至刚刚新建的项目。

### 第 2 步：启用 Google Calendar API

1. 打开左侧菜单（☰），依次进入 **[API 和服务] $\rightarrow$ [库]**。
2. 在搜索框中搜索 `Google Calendar API` 并点击进入。
3. 点击 **[启用]** 按钮。

### 第 3 步：配置 OAuth 同意屏幕

*(在较新的控制台中可能被称为 **Google Auth Platform**。)*

1. 打开左侧菜单中的 **[API 和服务] $\rightarrow$ [OAuth 同意屏幕]**（或 *Google Auth Platform $\rightarrow$ 品牌*），点击 **[开始使用]**。
2. 填写应用信息：
   - **应用名称**：`Dayloom`（任意命名）
   - **用户支持电子邮件**：选择你的 Google 邮箱
3. **用户类型**：个人账号请选择**外部 (External)**。
4. 填写开发者联系邮箱，点击 **[保存并继续]**。
5. 在**测试用户 (Test users)**页面中，点击 **[+ ADD USERS]**，务必添加**你自己的 Google 账号邮箱**。

> ⚠️ **至关重要：避免 7 天令牌失效**  
> 如果应用一直处于**测试中 (Testing)**状态，根据 Google 的安全策略，日历刷新令牌将会在 **7 天后自动过期**。  
> 为免去每周重新配置的麻烦，请在获取令牌前，点击同意屏幕顶部的 **[发布应用 (Publish app)]** 按钮，将其切换为**正式版/生产环境 (In production)**。  
> 仅供个人使用的应用无需经过 Google 审核即可直接发布。登录时如果出现“Google 未验证此应用”提示，只需点击 **[高级] $\rightarrow$ [转至 (应用名)]** 即可安全继续。

### 第 4 步：创建 OAuth 客户端 ID 与密钥

Dayloom 采用 Web 客户端标准，因此需要创建**网页应用**类型的凭据。

1. 打开左侧菜单中的 **[API 和服务] $\rightarrow$ [凭据]**，点击顶部的 **[+ 创建凭据] $\rightarrow$ [OAuth 客户端 ID]**。
2. **应用类型**：选择 **网页应用 (Web application)**
3. **名称**：`Dayloom Web Client`（任意）
4. 在**已获授权的重定向 URI** 下点击 **[+ 添加 URI]**，准确粘贴 Google 官方调试工具的地址：
   ```text
   https://developers.google.com/oauthplayground
   ```
5. 点击 **[创建]**。将弹出的 **客户端 ID** 和 **客户端密钥** 妥善复制保存。

### 第 5 步：获取刷新令牌 (OAuth 2.0 Playground)

1. 打开 [OAuth 2.0 Playground](https://developers.google.com/oauthplayground)。
2. 点击右上角的**齿轮图标（⚙️，OAuth 2.0 configuration）**。
   - 勾选 **`Use your own OAuth credentials`**。
   - 粘贴第 4 步中保存的 **OAuth Client ID** 和 **OAuth Client secret**。
   - 确认 **Access type** 设为 `Offline`（离线访问才能生成长效刷新令牌）。
3. 在左侧 **Step 1** 下方的 *Input your own scopes* 输入框中，粘贴以下权限作用域：
   ```text
   https://www.googleapis.com/auth/calendar.events
   ```
   > Dayloom 仅需**读取、创建、编辑和删除日程**的权限，因此该作用域完全足够。
4. 点击 **[Authorize APIs]** 按钮，登录刚刚添加到测试用户的 Google 账号并同意授权。  
   *(若弹出警告，点击“高级” $\rightarrow$ “继续前往”)*
5. 授权完成后会自动跳转至 **Step 2** 界面。  
   点击蓝色的 **[Exchange authorization code for tokens]** 按钮。
6. 在下方生成的输出中，复制 **`Refresh token`**（以 `1//0` 开头的一长串字符）。所有凭据准备完毕！🎉

> 🔒 客户端密钥和刷新令牌等同于**账户密码**，切勿泄露给他人。

### 第 6 步：将凭据填入 Dayloom

1. 打开 Obsidian **设置 (⚙️) $\rightarrow$ 第三方插件 $\rightarrow$ Dayloom**。
2. 点击顶部的 **☁️ Google 日历** 标签页。
3. 开启 **启用 Google 日历集成**。
4. 在 **Google 日历 OAuth 2.0（同步与编辑）** 下方分别填入：
   - `Google 客户端 ID`
   - `Google 客户端密钥`
   - `Google 刷新令牌`

### 第 7 步：添加需要显示的日历

1. 在同一标签页下方的 **Google 日历 📅** 部分，点击 **[+ 添加日历]**。
2. 填写新增的行：
   - **复选框**：勾选表示显示，取消勾选表示隐藏
   - **名称**：在 Dayloom 中的显示名称（如：工作、个人）
   - **ID**：你的主日历填写 `primary`，其他副日历填写对应的日历 ID
   - **颜色**：时间线上的日程块颜色
3. 查询其他日历 ID 的方法：  
   网页版 Google 日历 $\rightarrow$ 对应日历右侧 **⋮ $\rightarrow$ 设置和共享 $\rightarrow$ 集成日历 $\rightarrow$ 日历 ID**  
   *(通常为 `xxxx@group.calendar.google.com` 格式，主日历 ID 即为你自己的 Gmail 地址。)*
4. 不需要显示的日历可通过右侧的 **Delete** 删除。

### 第 8 步：指定任务同步的目标日历（可选）

在 **任务同步的 Google 日历** 下拉菜单中选择一个日历后，Obsidian 中所有带有日期与时间的任务就会自动同步到该 Google 日历中。

> 💡 **强烈建议**：在 Google 日历中**新建一个名为 `Obsidian Tasks` 的专用独立日历**，在第 7 步中添加它并在此处指定为同步日历。  
> Dayloom 为了防止画面重叠干扰，**不会将同步日历中的日程作为普通日程重复渲染到时间线上**（因为对应的 Obsidian 任务已经展示在时间线上了）。  
> 如果你将主日历（`primary`）选为同步日历，你原本记录在主日历中的日常会议和个人日程就会从时间线上消失，请务必注意。

### 第 9 步：测试连接

1. 打开 Dayloom 主视图。
2. 点击顶部工具栏中的**同步按钮 (↻)**，或按快捷键 `F5`。
3. 稍候片刻，如果弹出 "✅ …" 同步完成通知，且 Google 日程显示在时间线上，说明配置成功！
4. 如遇报错，请参阅后文的 [常见问题](#7-常见问题-faq-与故障排除)。

### 同步机制详解

| 操作 | 产生结果 |
| --- | --- |
| **同步按钮 / `F5` / `Ctrl+R` (`Cmd+R`)** | 重新扫描仓库任务，拉取当前视图跨度内的 Google 日程，并将带日期的任务推送到同步日历（范围覆盖过去 60 天至未来 365 天）。 |
| **右键点击同步按钮** | 唤起*将任务与 Google 日历同步 📤*弹窗，确认目标日历后可执行**立即同步**。 |
| **在 Dayloom 内修改任务**（拖拽、时长调整、弹窗编辑、勾选等） | 该任务修改会立即实时同步更新到 Google 日历。 |
| **在笔记文本中直接修改内容** | 不会实时上传，将在下一次手动或自动同步（如按 F5）时生效。 |
| 清除任务的日期/时间 | 若该日程由 Dayloom 创建，对应的 Google 日历日程也会被自动删除。 |
| 在 Dayloom 中删除已同步任务 | Google 日历中的对应副本也会一并移除。 |

- 同步后的任务行末尾带有 `[gcalId:: …]`。这是关联链接标识，请勿手动删除。
- 同步机制**仅会删除由 Dayloom 自身创建的日程**，绝不会删除你在 Google 日历中自行添加的既有会议或私人事件。
- 直接在时间线上拖拽移动或缩放 Google 日程色块，变动会立即保存到 Google 日历。

## 3. 设置选项逐项详解

Dayloom 设置分为 5 大标签页：

`⚙️ 常规` · `⏱️ 时间线` · `☁️ Google 日历` · `🔔 通知` · `📱 视图/显示`

> 设置项名称均遵照 `i18n.ts` 的官方中文翻译。

### ⚙️ 常规 (General)

| 设置项 | 说明 | 推荐设定值 |
| --- | --- | --- |
| **Language / 语言** | Dayloom 的界面显示语言：`Auto（自动检测）`、`English`、`한국어`、`日本語`、`简体中文`。修改后即时生效 | `Auto` |
| **默认任务文件路径** | 在规划器中创建新任务时写入的默认 Markdown 笔记路径（快捷记录、双击新建、`+` 按钮）。若不存在会自动创建 | `Day Planner.md` 或 `Inbox/Tasks.md` |
| **排除的文件和文件夹** | 排除不需要扫描任务的目录与文件规则（详见下文） | Templates, Archive |
| **日记文件夹路径** | 存放日常日记笔记的仓库文件夹路径 | 例如：`Daily` |
| **日记文件名格式** | 日记文件的命名格式 | `YYYY-MM-DD` |
| **日记模板** | 新建日记时所用的模板笔记路径 | 例如：`Templates/Daily.md` |
| **周记文件夹路径** | 存放周记笔记的仓库文件夹路径 | 例如：`Weekly` |
| **周记文件名格式** | 周记文件的命名格式 | `gggg-[W]ww`（如：`2026-W41`） |
| **周记模板** | 新建周记时所用的模板笔记路径 | 例如：`Templates/Weekly.md` |

#### 🔎 路径模糊搜索推荐
路径输入框支持仓库实际文件与文件夹的模糊补全。例如只需输入 `dly` 即可快速检索出 `Daily` 文件夹。

#### 🚫 排除的文件和文件夹（标签规则）
类似 Obsidian 搜索过滤器，以**彩色标签（Chip）**直观管理排除规则。

1. 在输入框左侧选择 **排除 (Exclude)** 或 **保留 (Keep)**。
2. 输入文件夹或文件名并从补全下拉菜单中选取，或直接按回车。
3. 生成的标签可进行如下操作：
   - **点击**标签可在“排除 $\leftrightarrow$ 保留”之间快捷切换。
   - 点击右侧的 **×** 即可删除该规则。
   - 若路径在仓库中不存在，会呈现灰色删除线状态。
4. 输入框下方的提示 *“已排除 M 篇笔记中的 N 篇”* 会实时显示排除生效状态。

| 规则示例 | 含义 |
| --- | --- |
| `Archive` | 排除 Archive 文件夹及其内部所有子笔记 |
| `Templates/Daily.md` | 排除特定的单个模板文件 |
| `**/Templates` | 无论处于第几层目录，排除仓库内所有的 `Templates` 文件夹 |
| `Daily/*.md` | 仅排除 `Daily` 根目录下的笔记（子目录中的笔记不受影响） |
| `Archive` + **保留** `Archive/2026` | 排除 Archive 目录，但对其子文件夹 `Archive/2026` 保持扫描 |

> `*` 匹配单级目录，`**` 匹配任意深度的多级子目录（不区分大小写）。

### ⏱️ 时间线 (Timeline)

| 设置项 | 说明 | 推荐设定值 |
| --- | --- | --- |
| **N 天视图天数** | N 天视图连续并列显示的天数（2–14 天） | `4` |
| **分别设置 Dayloom 与 Dayloom Compact 的高度** | 是否独立调整主标签页与侧边栏紧凑视图的每小时像素缩放高度 | 关闭 |
| **时间线每小时高度 (…)** | 时间线 1 小时所占的垂直像素高度（30–180px） | `60`（默认）；日程密集时推荐 `90` 以上 |
| **时间线开始时间 / 结束时间** | 时间线日常显示的起止整点。**同时作为“放入第一个空闲时段 (Fit It In)”的工作时间基准** | 例如：`7` – `23` |
| **默认任务时长（分钟）** | 将未设定时长的任务拖至时间线时默认赋予的时长（1–1440分钟）。连续安排多个任务时的间隔也使用此值 | `60`（默认）；番茄钟用户推荐 `25` |

> 💡 点击顶部工具栏的**缩放控件（🔍+）**也能快速拖拉调整每小时高度。

### ☁️ Google 日历 (Google Calendar)

| 设置项 | 说明 |
| --- | --- |
| **启用 Google 日历集成** | Google 日历集成总开关 |
| **任务同步的 Google 日历** | 选择用于同步带时间任务的目标 Google 日历（参见 [第 8 步](#第-8-步指定任务同步的目标日历可选)） |
| **Google 客户端 ID / 客户端密钥 / 刷新令牌** | 填入前文获取的 OAuth 2.0 凭据（参见 [第 2 节](#2-google-日历-oauth-20-配置指南)） |
| **Google 日历 📅** | 管理显示的日历列表：勾选状态、名称、ID、颜色、删除 |
| **本地任务颜色** | 本地 Markdown 任务边框的主题高亮色彩，方便与 Google 日历区分 |

### 🔔 通知 (Notifications)

| 设置项 | 选项 | 说明 |
| --- | --- | --- |
| **提醒方式** | `关闭` / `自动` / `应用内通知` / `系统通知` | **自动（推荐）**：Obsidian 在前台时弹窗提示并附带双音提示音，最小化或在后台时使用系统级弹窗。 |
| **提醒时间** | `开始时`（默认） / `提前 5、10、15、30 分钟` | 何时推送提醒 |
| **提醒声音** | 开启 / 关闭； 🔊 试听提示音 | 应用内通知时播放的轻脆双音提示音（系统通知使用操作系统默认声音） |
| **提醒任务** | 开启 / 关闭 | 是否对今天已安排开始时间（`⏰HH:mm`）的本地任务推送提醒 |
| **提醒 Google 日历日程** | 开启 / 关闭 | 是否对今天具体时间的 Google 日历日程推送提醒（全天事件除外） |

> 首次开启系统通知时操作系统会询问通知权限，**请务必选择允许**。  
> 已勾选完成（`[x]`）或已取消（`[-]`）的任务不会触发提醒。

### 📱 视图/显示 (View/Display)

| 设置项 | 说明 | 推荐设定值 |
| --- | --- | --- |
| **隐藏行内元数据字段** | 在规划器、阅读视图以及实时预览中隐藏任务标题末尾形如 `[gcalId:: …]` 的方括号字段（笔记正文依然完整保留） | 开启 |
| **在标题栏显示快捷键按钮** | 是否在时间线顶部保留快捷键 (?) 按钮。隐藏后按 `?` 或 `h` 键依然可以唤出帮助 | 根据喜好 |
| **滑动切换日期** | 在手机上左右滑动可翻页切换日期。关闭后会在标题栏提供 `< >` 上一个/下一个按钮 | 开启 |
| **触感反馈** | 在支持振动的移动设备上，勾选完成、切换标签或拖放调整时间块时触发短促震动反馈 | 开启 |

## 4. 侧边抽屉与时间块工作流

**时间块管理（Timeboxing）**的核心在于为任务预留专属的时段，清晰决定*“在何时做这件事”*。  
Dayloom 的侧边抽屉收集了所有尚未安排的具体任务，帮助你聚焦于今日最重要的工作，并能直接将其拖曳到时间线上。

### 打开与关闭抽屉

- **仅在桌面端 Dayloom 主标签页**中生效（在日、N 天、周、月、看板、列表视图均可唤出）。Dayloom Compact 侧边栏和手机端受限于屏幕尺寸不显示。
- 打开/关闭方式：按快捷键 `s`，点击顶部工具栏末尾的**面板图标 (▣)**，或运行命令 `Toggle Side Drawer`。
- 也可以点击抽屉内部右上角的关闭按钮（⨯）。

### 抽屉结构布局

```text
┌ October 2026 ▾        ‹ Today ›    ⨯ ┐  ← 迷你日历（看板视图中自动收起）
│ Su  Mo  Tu  We  Th  Fr  Sa            │
│ ...  6 周日历网格，带色彩状态点 ...       │
│ [ ☑ 任务 8 │ ◔ 统计 62% ]             │  ← 抽屉模式切换栏
├───────────────────────────────────────┤
│ [+ 添加无日期任务 (🔺 ⏫ 设置...)]      │  ← 快速记录
│ ▾ 🎯 今日焦点           (1)            │
│ ▾ 🚨 逾期任务           (3) [移到今天]   │
│ ▾ 📂 无日期任务         (5)            │
└───────────────────────────────────────┘
```

### 迷你日历

- **点击日期**：主规划器立即跳转至该天。当前显示的日期范围呈现柔和的光带，今天以实心圆点标明。
- **Ctrl/Cmd+点击**：直接在后台标签页打开该日期的日记 Markdown 文件。
- **日期下方的彩色小圆点 (Dot)**：
  - 橙色：有未完成的待办任务
  - 红色发光点：包含 🔺 最高 (Highest) 优先级的关键任务
  - 绿色：当天任务已全部搞定
  - 蓝色：包含日历日程
- **‹ › 按钮** 或 **滚轮滑动**：按月翻页（点击 **Today** 返回今天）。
- **点击月份标题**：将日历折叠为仅一行的周视图条带。插件会记住你的收起偏好。
- **拖放至日期上**：将任务直接拖到迷你日历的某一天，该任务就会移至对应日期（时间保持不变）。
- 在**看板视图**中，迷你日历会自动隐藏，让任务列表获得完整的纵向视窗。

### 任务 (Tasks) 模式

- **🎯 今日焦点 (Today's Focus)**：标记为今天且未完成的 **🔺 最高 (Highest)** 任务。**将任意任务拖到该区域**，即会自动加上今天的日期并升格为 🔺 最高优先级（无日期任务会自动获得今日日期）。
- **🚨 逾期任务 (Overdue Tasks)**：早于今天但尚未完成的逾期任务（按优先级 $\rightarrow$ 历史日期 $\rightarrow$ 标题排序，逾期天数以醒目红字标注）。
- **📂 无日期任务 (Undated Tasks)**：尚未分配日期的所有任务资源池（与看板视图的*无日期*列一致）。
- 空分类会**自动折叠**，一旦有任务进入会自动展开。你也可以点击标题手动收起展开。
- **🔺 最高**卡片带有呼吸感红晕边框，**⏫ 高**卡片带有醒目的琥珀橙色边框。

### 统计 (Stats) 模式

展示规划器当前呈现的**当日生产力数据图表**（可在迷你日历点击任意一天查看历史数据）：

- **环形进度条**：已完成时长占计划总时长的比例。如果没有安排具体时长，则显示已完成件数/总件数的比例。
- **计划 (Planned) / 已完成 (Completed) / 剩余 (Remaining)** 时间明细统计。
- **任务完成总数**、**焦点任务完成数**、**日历日程总时长**、**按优先级分布直方图**。
- 根据完成进度呈现的一句简短鼓励寄语。

即使处于搜索过滤状态，统计模块依然保持统计当天的全部任务。

---

### ① 快速记录 (Quick capture)

1. 在抽屉顶部的单行输入框中输入任务并按 `Enter`。
2. 任务会作为无日期任务自动追加至你设定的**默认任务文件路径**中，并弹出完成提示。
3. 输入时可以直接输入优先级 Emoji，插件会自动识别（如：`⏫ 整理项目框架`）。
4. 对中文拼音输入法（IME）有良好适配，打字回车不会误触发提交。

### ② 调整优先级

点击卡片上的优先级徽章（无优先级时鼠标悬浮会出现淡色旗标），或键盘选中卡片后按 `p`。  
在弹出的菜单中选择 🔺 最高、⏫ 高、🔼 中、○ 普通、🔽 低、⏬ 最低，对应 Emoji 会自动写入笔记正文。

### ③ 将任务拖拽排入时间表

| 拖放目标区域 | 产生效果 |
| --- | --- |
| **时间线时段插槽**（日 / N 天 / 周） | 安排到该日期对应时间点（15分钟步长）。时长遵循**默认任务时长** |
| **月历日期格或迷你日历** | 仅更改日期（保留时间；无时间任务依然保持全天状态） |
| **周视图 / N 天视图的日期标题** | **放入第一个空闲时段 (Fit It In)**：自动查找该日最早的空闲间隙填入 |
| **看板视图的各列** | 标准看板：设定为对应列的日期（或标记完成）；优先级看板：赋予对应优先级 |
| **🎯 今日焦点** | 赋予今天日期 ＋ 标记为 🔺 最高优先级 |
| **抽屉内其余空白区域** | 取消排程（还原到无日期状态，参见下文 ⑤） |

- 拖拽过程中，虚线预览框会实时显示将要落入的时间（如 `14:30`）。
- 拖拽时不松开鼠标按 `j` / `k` 键，可以直接翻阅上下一天/周。
- 拖拽中途按 `Esc` 键可立即撤回本次拖动。
- 每次拖放完成后，右上角通知都会提供 **撤销 (Undo)** 按钮。

### ④ 批量连续自动安排时间块

1. 按住 **Ctrl/Cmd 点击**或在抽屉空白处**拉框框选**，选中多张任务卡片。
2. 拖动其中任意一张选中的卡片到时间线的某个起始时段。
3. 所有选中的任务会**依照抽屉中的排序，首尾相接连续排入时间表**！（保留各任务原本的时长，原本无时长的任务则依次按默认任务时长排布。）
4. 排程若超过半夜 24:00，超出部分会保留在原位。点击一次撤销即可还原整组操作。

按 `Esc` 键可清空抽屉内的选中项。

### ⑤ 取消排程 (Unschedule)

把时间线上的色块、全天任务、月历中的任务或看板上的卡片**拖拽回侧边抽屉中**，任务的时间与日期标识就会被抹除，回到纯粹的无日期任务状态。

- 笔记正文中的时间区间、`⏳` 计划日期、`📅` 截止日期都会被安全移除。
- **记录在日记笔记内的任务**由于文件名本身就是日期，因此日期属性不会被擦除（会弹出提示说明）。
- Google 日历的日程拖进抽屉并不会导致日历日程被删除。
- 为防误操作，“已逾期”和“今日焦点”中的任务**只有精准拖到【无日期任务】栏目上时**才会清除日期。

### ⑥ 清理与顺延逾期任务

- 悬停在逾期任务卡片上，会浮现便捷操作按钮：  
  `移到今天` · `明天(Tmrw)` · `+1 周` · `取消日期(Undate)`。在保留任务时间的同时仅修改日期。
- 点击分类标题旁的 **移到今天**，所有积压的逾期任务将一键顺延至今日（支持单次撤销）。

### ⑦ 抽屉卡片键盘导航

按 `Tab` 键将焦点移到抽屉卡片上后：

| 按键 | 触发操作 |
| --- | --- |
| `Enter` | 编辑任务详细内容 |
| `f` | **放入第一个空闲时段**：智能寻找未来 14 天内最早能塞进的空隙并落位 |
| `p` | 设置优先级 |

*Fit It In* 会严格避开已占用的任务和 Google 会议日程，且只在工作时间范围内寻找空闲时段。

### 建议的日常晨间流程 ☀️

1. 早上打开 Obsidian，按 `s` 唤出侧边抽屉。
2. 查看 **逾期任务**，使用 `移到今天` 快速归拢需要补做的事情。
3. 挑选今天最重要的 1–2 项攻坚任务，拖入 **🎯 今日焦点**。
4. 将脑海中临时想到的事情随手填入顶部 **快速记录**。
5. 多选今日打算处理的 **无日期任务**，直接拽入时间线，自动首尾相连排布出全天的时间块。
6. 拖动任务边缘把预估时长对齐，在一天结束时打开 **统计** 面板，体验圆环闭合的充实感！

## 5. 视图、搜索、选择与快捷键

### 6 种视图 (Views)

| 视图 (标签) | 快捷键 | 核心亮点 |
| --- | --- | --- |
| **日时间线 (Daily Timeline)** | `d` | 适合深度规划的一日视图。带有当前时间红线、正在执行任务的动态进度条、顶部固定全天栏 |
| **N 天视图 (N-day View)** | `x` | 2–14 天横向并排概览（可在标签栏直接切换天数）。在手机上默认为 2 天视图 |
| **周视图 (Weekly View)** | `w` | 一周 7 天全局视图。**点击顶部星期日期**可直接进入那一天的日时间线 |
| **月历 (Monthly Calendar)** | `m` | 经典整月大日历。**点击日期格子**直达对应日时间线，**点击周数**直达对应周视图 |
| **看板 (Board)** | `b` | 敏捷看板。支持*标准看板*（无日期 · 已逾期 · 今天 · 明天 · 以后 · 已完成）与*优先级聚焦*（最高 🔺 … 最低 ⏬）双模式 |
| **列表视图 (List View)** | `l` | 按议程流展示一个月内的任务。搜索时自动担任呈现全库所有匹配项的全景视图 |

- 点击标题栏左侧的**日期胶囊**（如：📅 2026-10-07 (Wk 41)）会打开对应的日记或周记笔记。
- 在**看板视图**中拖动卡片到不同列，会自动更新笔记中的任务日期或优先级属性。支持多选批量跨列拖动。

### 桌面端标题栏布局

```text
[📅 日期胶囊]                [‹ Today ›]  [🔍 ↻ 🔍+ ? ▣]  [+]
```

| 控件 | 功能 |
| --- | --- |
| 📅 日期胶囊 | 打开对应日记 / 周记 Markdown 笔记 |
| ‹ Today › | 上一个 / 今天 / 下一个 日期导航 |
| 🔍 搜索 | 展开顶栏搜索框 (`/`) |
| ↻ 同步 | 与 Google 日历同步（右键点击打开手动同步弹窗） |
| 🔍+ 缩放 | 调整时间线每小时像素高度（日 / N 天 / 周视图） |
| ? 快捷键 | 查看键盘快捷键列表（可在设置中隐藏此按钮） |
| ▣ 面板 | 打开 / 关闭侧边抽屉 |
| **+ 添加** | 添加本地任务或添加 Google 日程 (*添加本地任务* / *添加日程*) |

处于看板视图时，顶栏还会增加 **标准看板 / 优先级聚焦** 模式切换开关。

### 🔍 展开式搜索 (Search)

1. 按 `/` 键或点击顶部的搜索放大镜图标。
2. 标题栏按钮全部平滑隐退，展开为一个**横跨整栏的半透明磨砂搜索条**并自动聚焦输入框。
3. 输入内容即时过滤当前视图：
   - 全面匹配任务内容、`#标签`、笔记所属文件路径、Google 日程标题、地点以及日历名称。
   - 使用空格分隔多组词汇可执行 AND 组合查询。
4. **按 Enter 键会自动跳转至 [列表视图 (List View)]**，打破单日限制，**汇总列出整个仓库中匹配到的全部任务与日程**！
5. 按 `Esc` 或点击输入框右侧的 **×** 按钮即可退出搜索并恢复原本的标题栏。

### ✅ 选择与批量删除

| 操作目标 | 触发方式 |
| --- | --- |
| 单个添加/取消选择 | 按住 **Ctrl/Cmd 点击**项目（不会误触打开编辑窗口） |
| 鼠标拉框范围选择 | 在空白区域**按住鼠标拖拽框选**（时间线网格、全天栏、看板列、抽屉卡片均支持） |
| 向现有选择追加选区 | 按住 `Ctrl` / `Cmd` / `Shift` 的同时按住鼠标拉框 |

| 批量拖动位移 | 拖拽任意一个被选中的项目即可整体位移（时间线保持间隔，抽屉卡片连续排布） |
| 批量删除 | 按键盘 `Delete` / `Backspace` 键，或点击底部工具条的 **删除** |

- 执行删除操作时，必定会弹窗询问确认（`Enter` 确认删除，`Esc` 取消）。  
  笔记内的任务行会被干净抹除，随后弹出的右上角提示中带有 **撤销 (Undo)** 按钮，可一键恢复。
- 伴随选中的 Google 日历日程也会同步在云端被删除。
- ⚠️ **提示**：由于 Google API 的限制，Google 日历云端本身的删除操作无法通过 Dayloom 的撤销按钮找回。
- 单个任务的编辑窗口内也配有独立的 **Delete** 按钮。

- 日视图顶端带有星期切换胶囊条，轻轻一触便能切换星期。
- 左右**轻扫（Swipe）**手势翻阅上一天/下一天。
- **长按色块约 0.35 秒**，伴随触感微振动，上下调整手柄随即浮现，可轻松调节开始/结束时间或拖拽移动。
- 点击屏幕任意空白处即可退出调整模式。

### 状态栏信息

Obsidian 底部的状态栏会实时滚动显示当前正在进行的任务（附带进度条与剩余时间），或展示距下一项任务开始的倒计时。

## 6. 任务语法与行内代码块

### 标准语法构成

```markdown
- [ ] 任务标题 ⏰09:00-10:30 ⏫ 🔁 every week ⏳ 2026-10-07 📅 2026-10-10
```

| 元素分类 | 语法写法 | 对应含义 |
| --- | --- | --- |
| 状态框 | `[ ]` `[/]` `[x]` `[-]` | 待办 / 进行中 / 完成 / 已取消 |
| 时间区间 | `⏰09:00-10:30` | 开始–结束时间。若省略结束时间（`⏰09:00`）按 30 分钟处理 |
| 优先级 | 🔺 ⏫ 🔼 🔽 ⏬ | 最高 / 高 / 中 / 低 / 最低（缺省为普通） |
| 计划日期 | `⏳ YYYY-MM-DD` | Dayloom 排期到时间线上时自动附上的时间标签 |
| 截止日期 | `📅 YYYY-MM-DD` | 当不存在计划日期时作为依据 |
| 开始日期 | `🛫 YYYY-MM-DD` | Tasks 插件标准的启动日兼容字段 |
| 完成/取消日 | `✅ YYYY-MM-DD` / `❌ YYYY-MM-DD` | 勾选完成或取消时自动打印的归档日期 |
| 周期循环 | `🔁 every day` 等 | 勾选完成后自动在下方生成下一个周期的全新任务行 |
| 日历同步标识 | `[gcalId:: …]` | 云端绑定的唯一定位符（无需手动编写，切勿删除） |

#### 多样化时间写法识别
Dayloom 同样支持以下常见的时间书写习惯：

```markdown
- [ ] 09:00 - 10:00 团队早会       ← 时间写在标题最前方
- [ ] 团队早会 [09:00-10:00]       ← 用常规方括号括起
- [ ] 团队早会 [startTime:: 09:00 - 10:00] ← Dataview 属性语法
```

#### 循环规则支持
`every day` (`daily`), `every week` (`weekly`), `every month` (`monthly`), `every year` (`yearly`), `every weekday`, 以及 `every N day/week/month/year`（例如 `every 3 days`）。

你可以将 Dayloom 日程视图作为组件嵌入任何普通 Markdown 笔记中。在命令面板中运行 **Insert Inline View (dayloom block)** 即可快速插入代码块模板。

### 🔍 行内代码块的高级筛选面板

点击代码块右上角的 **🔍 筛选** 按钮即可呼出单行过滤设计栏。

4. 点击 **+ 筛选 $\rightarrow$ 组** 可创建更高级的嵌套括号条件组合。

## 7. 常见问题 (FAQ) 与故障排除

### Q1. 笔记里写的任务没有出现在时间线上？
- 检查该行开头是否严格是 `- [ ] `（不支持 `*` 圆点或数字列表序号）。
- 时间线仅展示**带有明确日期的任务**。没有日期的任务请在侧边抽屉的**无日期任务**或看板的**无日期**列中查找。
- 检查设置 $\rightarrow$ 常规 $\rightarrow$ **排除的文件和文件夹** 中是否误包含了该笔记。
- 带有同步冲突标记的文件（文件名含有 `.sync-conflict-`）会被插件自动忽略。
- 检查是否开启了搜索过滤？按 `Esc` 键清空搜索试一下。
- 按 `F5` 键重新扫描全库任务。

### Q2. 刷新 Google 令牌时弹出 "invalid_grant" 报错？
说明刷新令牌已失效或已被授权服务器注销。
- 检查你的 OAuth 同意屏幕是否仍为**测试中 (Testing)**状态（测试状态下令牌**7 天必定过期**）。请将其切换至**正式发布 (In production)**，并按照 [第 5 步](#第-5-步获取刷新令牌-oauth-20-playground) 的流程重新取得新令牌填入。
- 如果你修改了 Google 账户的密码，所有签发的长效令牌也会被强制作废。

### Q3. 提示 "unauthorized_client" 或 "invalid_client" 错误？
- 确认填写的客户端 ID 与客户端密钥首尾没有混入多余的空格或换行。
- 刷新令牌**必须是由当前这套客户端 ID/密钥对所派生的**。如果在 Playground 中未勾选自定义凭据获取到的公用令牌，无法在此通过验证。

### Q4. Google 日历日程不显示或仅部分显示？
- 检查设置 $\rightarrow$ ☁️ Google 日历 $\rightarrow$ **Google 日历 📅** 列表中对应日历**是否已被勾选开启**。
- **任务同步的 Google 日历**中指定的日历为了避免色块叠加，其云端事件不会直接渲染。切勿将主力日程日历选为同步日历。
- 点击工具栏同步按钮（↻）或按 `F5` 刷新。

### Q5. 直接在笔记文本改了时间，Google 日历没有变动？
在笔记编辑器直接打字改动的内容不会实时推送。请点击顶栏**同步按钮 (↻)**或按 `F5` 发起一次提交。  
（在 Dayloom 界面直接拖拽或弹窗修改会立即发起云端更新。）

### Q6. 任务后方的 `[gcalId:: …]` 影响美观，可以删掉吗？
绝对不能删除，删掉将导致失去与云端日程的唯一对应关联。  
前往设置 $\rightarrow$ 📱 视图/显示 $\rightarrow$ 开启 **隐藏行内元数据字段** 即可在界面中干净地隐藏它。

### Q7. 没收到到期提醒？
- 检查设置 $\rightarrow$ 🔔 通知 $\rightarrow$ **提醒方式** 是否被误设为了 `关闭`。
- 任务必须同时具备**今天的日期**以及具体的**开始时间（`⏰HH:mm`）**。
- 若选用系统通知，需要确保操作系统已允许 Obsidian 发送通知提醒。
- 如果听不到声音，请在设置中点击 🔊 试听测试。

### Q8. 快捷键按了没有反应？
- 请先鼠标点击一下 Dayloom 视图内的任意区域，使其成为**当前活动窗口 (Active View)**。
- 当光标位于打字输入框内时，快捷键会自动停用以保证文本输入正常。

### Q9. 某个任务色块拖不动？
- 已标记完成（`[x]`）或已取消（`[-]`）的任务会自动上锁，防止计划被误动。取消勾选后即可自由拖拽。
- 在手机端，需要**长按色块约 0.35 秒**后才会浮现调节手柄并开始拖曳。

### Q10. 找不到侧边抽屉？
侧边抽屉仅在**桌面端的 Dayloom 主标签页**中提供。按快捷键 `s` 或点击顶栏右侧的面板图标（▣）即可展开。（移动端及侧栏的小窗口不包含此抽屉。）

### Q11. 快速记录的任务没有出现在“无日期任务”里？
如果你的**默认任务文件路径**所设定的笔记名称中自带日期（如 `2026-10-07.md`），由于日记继承机制，该任务会自动带上该天日期。请改用不含日期的普通笔记（如 `Inbox.md`）。

### Q12. 不小心误移或误删了任务，如何挽回？
无需惊慌。任何移动或删除操作发生后，右上角弹出的通知中都会保留数秒的 **撤销 (Undo)** 按钮，哪怕是批量操作也能一键复原。  
（注：Google 日历端原本的日程一旦删除无法通过本地 Undo 恢复。）

### Q13. 我的凭据存放在何处？安全吗？
客户端密钥和刷新令牌保存在你本地仓库的 `.obsidian/plugins/obsidian-day-planner-pro/data.json` 文件中，绝不经由任何第三方或开发者中转。  
如果你会将 Vault 上传至 GitHub 等公共仓库，请确保将该数据文件列入 `.gitignore`。

### Q14. 界面语言不是我想要的？
前往设置 $\rightarrow$ 常规 $\rightarrow$ **Language / 语言** 中修改。`Auto` 会自动读取并跟随 Obsidian 本身的语言设置，也可以手动固定为你所需的特定语言。
