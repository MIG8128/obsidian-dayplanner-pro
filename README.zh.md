## 1. 什么是 Dayloom？核心概念

### 它是做什么的？

Dayloom 会自动收集你 Obsidian 笔记中的**复选框任务（`- [ ]`）**，并将它们排布成直观的时间线日程表。
为任务添加日期和时间后，它就会在时间线上以色块呈现；拖动色块时，**你笔记中的文本内容也会随之实时同步修改。**
无需任何外部数据库：所有数据完全保存在你自己的本地 Markdown 文件中。

### 功能概览

| 功能 | 说明 |
| --- | --- |
| 6 种视图 | 日时间线、N 天视图（2–14 天）、周视图、月历、看板（标准看板 / 优先级聚焦）、列表 |
| 时间块管理 | 拖动任务到指定时段；通过上/下边缘手柄拖拽调整持续时长 |
| 随处拖动 | 抓住任务不放即可跨天、跨周，甚至跨视图（日 → 月或看板）随意移动 |
| 侧边抽屉 | 迷你日历、🎯 今日焦点、逾期任务、无日期任务、每日统计（桌面端与平板端均支持） |
| 搜索 | 按 `/` 或 `Ctrl/Cmd+F` 键标题栏直接化身为搜索框；回车后自动在列表中列出所有匹配项 |
| 多选与删除 | 全视图支持 Ctrl/Cmd+点击以及鼠标框选；Delete 键可批量删除任务和日程（支持 1 次撤销） |
| Google 日历 | 浏览、编辑、创建和删除日程；可将带时间的任务同步到指定日历 |
| 通知 | 在开始时（或提前 5–30 分钟）通过应用内提示或系统通知进行提醒，伴有提示音 |
| 触控操作 | 手机、平板与触屏笔记本支持长按拖动；手机端支持滑动切换日期 |
| 行内代码块嵌入 | 使用 ```` ```dayloom ```` 代码块在任意笔记正文中嵌入带筛选器的规划器组件 |
| Tasks 插件兼容 | 完美支持 Obsidian Tasks 插件的标准 Emoji 语法（📅 ⏳ 🛫 ✅ ❌ 🔁 🔺⏫🔼🔽⏬） |
| 主题与多语言 | 自动跟随 Obsidian 主题；支持 English、한국어、日本語、简体中文 |

### 两个窗口：Dayloom 与 Dayloom Compact

| 名称 | 如何打开 | 说明 |
| --- | --- | --- |
| **Dayloom** | 点击功能区日历图标 *Open Dayloom*，或运行命令 `Open Dayloom` | 主规划器标签页。包含所有视图以及（桌面端和平板端）侧边抽屉。 |
| **Dayloom Compact** | 点击功能区时钟日历图标 *Open Dayloom Compact*，或运行命令 `Open Dayloom Compact` | 停靠在右侧边栏的紧凑型规划器。采用手机端布局，底部带有 **日 · 列表 · 月 · 看板** 与 **更多**。 |

> 💡 按 `Ctrl+P`（Mac 为 `Cmd+P`）打开**命令面板**并输入 "Dayloom"，即可查看所有相关命令：
> `Open Dayloom`, `Open Dayloom Compact`, `Go to Today`, `Toggle Side Drawer`, `Insert Inline View (dayloom block)`, `Show Keyboard Shortcuts`, `What's New (Release Notes)`。

### 基本概念

- **一条任务即一行复选框。** 在笔记中写入 `- [ ] 撰写报告`，Dayloom 就会自动识别。
- **日期判断顺序**：优先识别 `⏳ 2026-10-07`（计划日期），其次识别 `📅 2026-10-07`（截止日期），最后识别**日记文件的名称**。
  例如在 `2026-10-07.md` 日记中书写的任务，即便行内没有日期标识，也会自动属于当天。
- **时间格式**：格式为 `⏰09:00-10:30`。带时间的任务会排布在时间线上；未安排时间的任务则置于顶部的“全天”栏。
- **任务状态**：由复选框内的字符决定：`[ ]` 待办，`[/]` 进行中，`[x]` 完成，`[-]` 已取消。

### 发行说明（What's New）

更新后，**新功能**窗口会展示本次更新的变化。你随时可以通过命令 `What's New (Release Notes)` 或在“设置 → 常规”中点击**查看发行说明**再次打开它。

## 2. Google 日历 OAuth 2.0 配置指南

Google 日历集成是**完全可选的**。即使不配置，Dayloom 的所有任务管理功能也均可正常使用。

### Dayloom 的登录机制

Dayloom **没有“使用 Google 登录”按钮**。你需要将三个凭据值输入到插件设置中：

| 设置项 | 说明 | 示例外观 |
| --- | --- | --- |
| `Google 客户端 ID` | 你创建的 OAuth 应用的客户端 ID | `xxxx.apps.googleusercontent.com` |
| `Google 客户端密钥` | 该应用的客户端密钥 | `GOCSPX-xxxx` |
| `Google 刷新令牌` | 用于获取新访问令牌的长期离线刷新令牌 | `1//0xxxx` |

有了这些，Dayloom 会自行向 Google（`https://oauth2.googleapis.com/token`）请求短期的访问令牌，并且只将其保存在内存中。
因此你的任务是：**① 在 Google Cloud 中创建一个 OAuth 应用，② 获取一次刷新令牌并填入设置。**
按部就班操作，大约需要 20–30 分钟。

> ⚠️ Google Cloud 控制台经常调整界面布局。如果某些菜单名称略有不同，寻找含义相同或相近的选项即可。

### 步骤 1：创建 Google Cloud 项目

1. 前往 [Google Cloud Console](https://console.cloud.google.com/) 并使用你的 Google 账号登录。
2. 点击顶部的**项目选择框** → **新建项目**。
3. 输入一个容易识别的名称（例如 `Dayloom`），然后点击**创建**。
4. 确保顶部选择框中已选中刚刚创建的新项目。

### 步骤 2：启用 Google Calendar API

1. 在左侧菜单中，打开 **API 和服务 → 库**。
2. 搜索 `Google Calendar API` 并打开它。
3. 点击**启用**。

### 步骤 3：配置 OAuth 同意屏幕

（新版控制台将其称为 **Google Auth Platform**。）

1. 打开 **API 和服务 → OAuth 同意屏幕**（或 *Google Auth Platform → 品牌*），点击**开始使用**。
2. 应用信息：
   - **应用名称**：`Dayloom`（任意名称均可）
   - **用户支持电子邮件**：选择你的邮箱
3. **目标受众 / 用户类型（Audience）**：个人 Google 账号选择**外部（External）**。
4. 输入开发者联系邮箱，同意条款并点击**保存并继续**。
5. 在**测试用户（Test users）**一栏，添加**你自己的 Google 账号邮箱**。

> ⚠️ **重要：关于 7 天有效期的说明**
> 当应用处于**测试（Testing）**状态时，Google 限制日历刷新令牌**在 7 天后自动失效**。
> 为避免每周都要重新获取令牌，请在获取令牌*之前*，在同意屏幕（受众页面）上将应用切换为**发布应用（Publish app） → 正式发布（In production）**。
> 对于仅供你自己个人使用的应用，无需经过 Google 审核即可直接发布。登录时会出现“Google 尚未验证此应用”的警告，只需点击**高级 → 前往（应用名称）**即可继续。

### 步骤 4：创建 OAuth 客户端 ID 与密钥

Dayloom 设置将其定义为 *OAuth 网页客户端*，因此我们需要创建一个**网页应用（Web application）**客户端。

1. 打开 **API 和服务 → 凭据 → 创建凭据 → OAuth 客户端 ID**
   （或 *Google Auth Platform → 客户端 → 创建客户端*）。
2. **应用类型**：`网页应用（Web application）`
3. **名称**：任意，例如 `Dayloom Web Client`
4. 在**已获授权的重定向 URI**中，准确添加以下地址（Google 官方的令牌测试工具，下一步会用到）：
   ```
   https://developers.google.com/oauthplayground
   ```
5. 点击**创建**。随后会显示**客户端 ID** 和 **客户端密钥**：请妥善复制并保存。

### 步骤 5：获取刷新令牌（OAuth 2.0 Playground）

1. 打开 [OAuth 2.0 Playground](https://developers.google.com/oauthplayground)。
2. 点击右上角的**齿轮图标（⚙️，OAuth 2.0 configuration）**。
   - 勾选 **Use your own OAuth credentials**。
   - 粘贴步骤 4 中复制的 **OAuth Client ID** 和 **OAuth Client secret**。
   - 检查 **Access type** 是否为 `Offline`（获取刷新令牌所必须）。
3. 在左侧 **Step 1** 下方的输入框（*Input your own scopes*）中，输入此权限范围：
   ```
   https://www.googleapis.com/auth/calendar.events
   ```
   > Dayloom 仅需**读取、创建、编辑和删除日程**，因此该权限范围已完全足够。
4. 点击 **Authorize APIs**，使用你在步骤 3 中添加为测试用户的 Google 账号登录并授予权限。
   （如果出现未验证应用警告，点击 *高级 → 前往…*。）
5. 进入 **Step 2** 界面后，点击 **Exchange authorization code for tokens**。
6. 复制右侧面板中的 **Refresh token**（以 `1//0` 开头）。这就是最后的钥匙！ 🎉

> 🔒 请像保护密码一样**妥善保管客户端密钥和刷新令牌**。切勿泄露给他人。

### 步骤 6：将凭据填入 Dayloom 设置

1. 打开 Obsidian **设置（⚙️） → 第三方插件 → Dayloom**。
2. 点击顶部的 **☁️ Google 日历** 标签页。
3. 开启**启用 Google 日历集成**。
4. 在 **Google 日历 OAuth 2.0（同步与编辑）** 下方，粘贴：
   - `Google 客户端 ID`
   - `Google 客户端密钥`
   - `Google 刷新令牌`

   复制时产生的多余首尾空格或换行会自动清除。

### 步骤 7：添加你想显示的日历

1. 在同一标签页中，点击 **Google 日历 📅** 旁边的 **+ 添加日历**。
2. 填写新增的行：
   - **复选框**：勾选 = 显示，未勾选 = 隐藏
   - **名称**：在 Dayloom 中显示的名称（例如：工作、个人）
   - **ID**：主日历填写 `primary`，其他日历填写日历 ID
   - **颜色**：该日历日程在时间线上显示的颜色
3. 查找其他日历 ID 的方法：
   在网页端 Google 日历中 → 点击该日历的 **⋮ → 设置和共享 → 集成日历 → 日历 ID**
   （通常形如 `xxxx@group.calendar.google.com`；主日历 ID 即为你的 Gmail 地址）。
4. 不需要显示的日历可通过**删除**按钮移除。

### 步骤 8：选择任务同步日历（可选）

在**任务同步的 Google 日历**中指定一个日历后，所有带有日期和时间的任务都会自动同步为该日历中的日程。

> 💡 **推荐做法**：在 Google 日历中创建一个**专用日历**（例如 `Obsidian Tasks`），在步骤 7 中添加它，并在此处选择它。
> 为了防止日程重复显示，Dayloom **不会在时间线上将该同步日历中的日程显示为普通日程**（因为任务本身已经显示在上面了）。
> 如果你选择了主日历，那么你原有的会议日程也会在时间线上被隐藏，因此请务必注意。

### 步骤 9：测试连接

1. 打开 Dayloom 视图。
2. 点击标题栏中的**同步**按钮（↻），或按下 `F5`（手机端：**更多 → 同步**）。
3. 弹出“✅ 任务同步完成！…”通知，且时间线上出现了日历日程，即表示连接成功。
4. 若失败，会弹出 OAuth 错误通知 → 请参阅[常见问题 (FAQ)](#8-常见问题-faq-与故障排除)。

### 同步机制详解

| 操作 | 结果 |
| --- | --- |
| **同步按钮 / `F5` / `Ctrl+R` (`Cmd+R`)** | 重新扫描仓库任务，重新拉取视图内的日程，并将带时间的任务推送到同步日历（从过去 60 天到未来 365 天）。 |
| **右键点击（或长按）同步按钮** | 打开*将任务与 Google 日历同步 📤* 对话框：选择目标日历并点击**立即同步**。 |
| **在 Dayloom 内修改任务**（拖拽、编辑弹窗、勾选复选框等） | 该任务的修改会立即同步更新到 Google 日历。 |
| **直接在笔记正文中修改文本** | **不会**自动即时发送；下次手动同步时才会推送到 Google 日历。 |
| 清除任务的日期/时间 | 若该日程由 Dayloom 创建，则会从 Google 日历中删除该日程。 |
| 在 Dayloom 中删除已同步任务 | Google 日历中的对应日程也会被同步删除。 |

- 已同步的任务行末尾会带有 `[gcalId:: …]`。这是关联日程的关键标识，请勿手动删除。
- 同步只会删除**由 Dayloom 自己创建的日程**。你的日常会议、他人邀请等原有日程绝不会被同步误删。
- 在时间线上拖拽、调整大小或编辑 Google 日程时，修改会立即保存到 Google 日历，并提供**撤销**通知。
- 已加载过的日程会被本地缓存，因此下次打开规划器时能瞬间显示，并在后台静默拉取更新。

## 3. 设置选项逐项详解

设置分为五个标签页：

`⚙️ 常规` · `⏱️ 时间线` · `☁️ Google 日历` · `🔔 通知` · `📱 视图/显示`

> 设置项名称跟随你选择的界面语言显示。本指南采用简体中文名称进行介绍。

### ⚙️ 常规

| 设置项 | 说明 | 推荐值 |
| --- | --- | --- |
| **语言 / Language** | Dayloom 的界面语言：`自动检测 (Obsidian 默认)`、`English`、`한국어`、`日本語`、`简体中文`。修改后立即生效 | `自动检测` |
| **发行说明** | 点击**查看发行说明**打开当前安装版本的更新内容窗口 | — |
| **默认任务文件路径** | 快速创建任务时保存到的 Markdown 笔记（快速记录、时间线双击）。不存在则自动创建 | `Day Planner.md`（默认）或 `Inbox/Tasks.md` |
| **排除的文件和文件夹** | 不扫描任务的文件夹或笔记（详见下文） | Templates, Archive |
| **日记文件夹路径** | 存放日记的文件夹路径 | 例如 `Daily` |
| **日记文件名格式** | 日记的文件名格式 | `YYYY-MM-DD` |
| **日记模板** | 新建日记时使用的模板文件 | 例如 `Templates/Daily.md` |
| **周记文件夹路径** | 存放周记的文件夹路径 | 例如 `Weekly` |
| **周记文件名格式** | 周记的文件名格式 | `gggg-[W]ww`（例如 `2026-W41`） |
| **周记模板** | 新建周记时使用的模板文件 | 例如 `Templates/Weekly.md` |

模板文件中支持使用 `{{date}}`、`{{title}}` 和 `{{time}}` 占位符。

#### 🔎 路径输入建议

在路径输入框中打字时，会自动模糊搜索仓库内的文件与文件夹并给出建议（例如输入 `dly` 即可匹配出 `Daily` 文件夹）。
文件输入框仅列出 Markdown 笔记；文件夹输入框仅列出文件夹。

#### 🚫 排除的文件和文件夹

规则采用类似 Obsidian 搜索过滤器的**标签胶囊（Chips）**形式进行管理：

1. 在输入框左侧选择**排除**或**保留**。
2. 输入文件夹或笔记名称，从下拉建议中选择，或按 `Enter`。
3. 规则将添加为一个标签胶囊：
   - **点击**胶囊可在排除与保留之间切换。
   - 点击胶囊上的 **×** 可移除该规则。
   - 仓库中不存在的路径会显示为灰色并带有删除线。
4. 下方会实时显示“已排除 N 篇笔记中的 M 篇”，直观展示排除效果。

| 输入示例 | 含义 |
| --- | --- |
| `Archive` | Archive 文件夹及其内部的所有笔记 |
| `Templates/Daily.md`（或 `Templates/Daily`） | 仅该单篇笔记 |
| `**/Templates` | 任意层级下名为 `Templates` 的所有文件夹 |
| `Daily/*.md` | `Daily` 文件夹直属的笔记（不包括其子文件夹） |
| 排除 `Archive` ＋ **保留** `Archive/2026` | 排除整个归档，但保留其中的 2026 文件夹 |

> `*` 匹配单层文件夹内，`**` 可跨层级匹配。匹配不区分大小写。

### ⏱️ 时间线

| 设置项 | 说明 | 推荐值 |
| --- | --- | --- |
| **N 天视图天数** | N 天视图中连续显示的天数（2–14 天）。也可直接在视图标签页内修改 | `4` |
| **分别设置 Dayloom 与 Dayloom Compact 的高度** | 分别调整主视图与侧边栏 Compact 视图的缩放（每小时高度） | 关闭 |
| **时间线每小时高度 (…)** | 时间线上 1 小时的垂直高度（像素，30–180px） | `60`（默认）；日程密集时建议 `90` 以上 |
| **时间线开始时间 / 结束时间** | 时间线上展示的起止整点。也是**“见缝插针（Fit It In）”所依据的工作时间** | 例如 `7` 时 至 `23` 时 |
| **默认任务时长（分钟）** | 将没有时间的任务拖到时间线上时分配的时长（1–1440分钟）。连续安排多个任务时同样适用 | `60`（默认）；番茄钟可设为 `25` |

> 💡 你还可以通过标题栏上的**缩放**控件（🔍）直接调整每小时高度（手机端：**更多 → 时间线缩放**）。

### ☁️ Google 日历

| 设置项 | 说明 |
| --- | --- |
| **启用 Google 日历集成** | 开启或关闭日历集成功能 |
| **任务同步的 Google 日历** | 带时间的任务同步到的目标日历（[步骤 8](#步骤-8选择任务同步日历可选)） |

## 4. 侧边抽屉与时间块工作流

**时间块管理（Timeboxing）**的核心思想是给每一项任务分配一个固定的时间段：明确决定你*何时*去完成它。
Dayloom 的侧边抽屉负责收纳尚未安排时间的任务，展示今日的核心焦点与完成进度，并支持直接拖放进日程表中。

### 展开与收起抽屉

- 支持在**桌面端与平板端**的 **Dayloom** 主视图全标签页（日、N 天、周、月、看板、列表）中使用。
- 打开/关闭：按 `s` 键，点击标题栏右侧的**面板图标（▣）**，或运行命令 `Toggle Side Drawer`。抽屉自身的右上角也有关闭（⨯）按钮。
- **窄窗口环境**（900px 以下，如分屏模式或竖屏平板）：抽屉会以卡片形式浮动在规划器上方，避免挤压视图。点击外部即可关闭，浮动状态下同样支持向内拖拽任务。
- **手机端与 Dayloom Compact** 没有侧边抽屉：相同的任务和统计功能收纳在底部栏的**更多**抽屉面板中（详见[第 6 节](#6-触控操作手机平板与触屏笔记本)）。

### 抽屉布局结构

```
┌ 2026年10月 ▾          ‹ 今天 ›     ⨯ ┐  ← 迷你日历（在看板视图中显示今日日期）
│ 日  一  二  三  四  五  六            │
│ ... 6周日历视图，繁忙日子下方有圆点 ...  │
│ [ ☑ 任务 8 │ ◔ 统计 62% ]             │  ← 模式切换
├───────────────────────────────────────┤
│ [+ 添加无日期任务 (🔺 ⏫ ...)]          │  ← 快速记录
│ ▾ 📅 今日任务           (4)           │  ← 🎯 今日焦点卡片置顶
│ ▾ 🚨 逾期任务           (3) [移到今天] │
│ ▾ 📂 无日期任务         (5)           │
└───────────────────────────────────────┘
```

### 迷你日历

- **点击日期**：主视图立即跳转到该日。当前屏幕正在显示的日期段会高亮呈带状；今天由实心圆点标出。
- **Ctrl/Cmd+点击**：直接打开那一天的日记文件。
- **日期下方的彩色圆点**：橙色 = 有待办任务，发光红色 = 包含 🔺 最高 优先级任务，绿色 = 所有任务已完成，蓝色 = 有日历日程。
- **‹ ›** 按钮或**鼠标滚轮**：按月翻页；点击**今天**跳回当月。
- **点击月份名称**：可将日历折叠为仅显示 1 周（‹ › 随之变为按周翻页）。Dayloom 会记住这一折叠状态。
- **将任务拖放到某一天**：将任务移至该日期（保留既有时间）。
- 在**看板**视图中，迷你日历会被替换为今天的日期，使任务列表获得完整的纵向展示空间。

### 任务模式

- **📅 今日任务**：安排在今天的所有任务（无论是否带具体时间）。未完成的任务优先排在前面并按时间升序排列。已完成任务保留（灰色），方便直接取消勾选；点击 `↗` 可在原笔记中打开该任务。**将任务拖到此处**即可将其日期改为今天。
- **🎯 今日焦点**（位于“今日任务”最上方）：展示今天任务中标记为 **🔺 最高** 的任务，以显眼的 FOCUS 卡片置顶呈现。**将任意任务拖入焦点插槽**，即可将其设为焦点任务：自动移到今天并升为 🔺 最高 优先级（无日期任务会自动加上 `📅` 今天截止）。即使当前没有焦点任务，拖动时该插槽也会自动浮现。
- **🚨 逾期任务**：早于今天的未完成任务，按优先级 → 最早日期 → 标题排序，过期的日期以醒目的红色显示。
- **📂 无日期任务**：未设置日期的任务（与看板视图中的*无日期*列完全一致），按优先级 → 标题排序。
- 空的分组会自动**折叠**，有任务进入时自动展开；你也可以点击分组标题手动折叠。
- **🔺 最高** 卡片带有发光的红色边框，**⏫ 高** 卡片带有琥珀色边框；完成的卡片变为灰色。

### 统计模式

呈现**规划器当前所显示日期**的综合统计（可在迷你日历中点击其他日期进行查看）：

- **完成度进度环**：已完成时间占计划总时间的百分比（基于带时间任务，排除取消任务）。若当天没有带时间的任务，则根据任务数量计算。
- **计划 / 完成 / 剩余** 时间总计。
- **已完成任务数**、**已完成焦点任务数**、**日历日程总时长**，以及**按优先级分类**的详细明细。
- 贴心的激励小语。

搜索状态下不会影响统计数据：统计始终覆盖一整天的完整日程。

### ① 快速记录

1. 在抽屉顶部的输入框中输入任务，按下 `Enter`。
2. 任务会作为无日期任务直接追加到**默认任务文件路径**指定的笔记中，并弹出保存通知。
3. 输入时可以直接输入优先级 Emoji，例如 `⏫ 撰写项目方案`。
4. 完美兼容中文、日文、韩文等 IME 输入法：输入完成后单次回车直接保存。

### ② 设置优先级

点击卡片上的优先级徽章（未设置时鼠标悬停会显示浅色旗帜），或选中卡片后按 `p` 键。
可选：🔺 最高、⏫ 高、🔼 中、○ 普通、🔽 低 与 ⏬ 最低（支持方向键和 `Esc`）。Emoji 会自动写入笔记正文。

### ③ 拖动任务排入日程

| 拖放目标位置 | 结果 |
| --- | --- |
| **时间槽**（日 / N 天 / 周） | 安排到该日期与时间（15分钟步进）。时长：**默认任务时长** |
| **月历或迷你日历上的某一天** | 仅更改日期（保留时间；无时间任务依旧为全天） |
| **周视图 / N 天视图的星期表头** | **见缝插针（Fit It In）**：自动排入该天第一个空闲时段 |
| **看板列** | 看板模式：对应列的日期（或完成）；优先级模式：赋予对应优先级 |
| **📅 今日任务** | 日期变更为今天（保留时间） |
| **🎯 今日焦点** | 日期变更为今天 ＋ 优先级设为 🔺 最高 |
| **抽屉其余区域** | 取消排期（清除日期与时间，详见 ⑤） |

- 拖拽过程中，在时间线上会出现虚线框预览及对应时间（如 `14:30`）；在其他区域时，光标旁会跟随显示任务名称的小标签，下方悬停的日期、列或抽屉分组会自动高亮。
- 拖拽时不松开鼠标，按 `j` / `k` 键可直接切换到下一天 / 上一天（或下周/上周）。
- 拖拽时不松开鼠标，按视图快捷键（`d`, `x`, `w`, `m`, `b`, `l`）可直接跨视图搬运任务：例如在日视图中抓起色块，按 `m` 切换到月历，然后丢在目标日期上。
- 拖拽过程中按 `Esc` 即可取消操作。
- 每次排期变动都会在下方弹出带有**撤销（Undo）**按钮的通知。

### ④ 连续安排多个任务

1. **Ctrl/Cmd+点击**多张抽屉卡片，或者在任务列表空白处**鼠标拖动框选**，选中多个任务。
2. 抓住其中任意一张选中的卡片，拖到时间线上。
3. 所有选中的任务会从放置的时间点开始，按照抽屉内的顺序**紧凑连续地（back-to-back）**依次排列。每个任务保持自身时长或采用默认任务时长。
4. 会排到午夜之后的任务会保留在原处。单击撤销即可一次性还原所有排列。

按 `Esc` 可清除抽屉中的多选状态。

### ⑤ 取消排期（清除日期与时间）

将时间线色块、全天任务、月历任务或看板卡片**拖入抽屉中**，即可清除其日期与时间：任务将回到“无日期”列表中。

- 时间、`⏳` 计划日期与 `📅` 截止日期都会从笔记中移除。
- **日记笔记内的任务**因其日期源自文件名，因此日期会保留（系统会弹出通知提示）。
- 将 Google 日历日程拖入抽屉中不会将其从 Google 日历中删除。
- 为避免误操作，“逾期任务”和“今日焦点”卡片只有在**精确拖放到无日期任务分组上**时才会取消排期。

### ⑥ 逾期任务梳理

- 悬停在逾期任务卡片上会浮现快捷操作按钮（触控屏上常驻显示）：
  `移到今天` · `明天` · `+1 周` · `取消日期`。仅修改日期，原有设置的时间保持不变。
- 点击分组表头的**移到今天**按钮，可一次性将所有逾期任务顺延到今天（支持单次撤销）。

### ⑦ 抽屉卡片的键盘操作

按 `Tab` 键聚焦到卡片上后：

| 按键 | 操作 |
| --- | --- |
| `Enter` | 编辑任务内容 |
| `f` | **见缝插针（Fit It In）**：自动排入未来 14 天内的第一个空闲时间槽 |
| `p` | 打开优先级设置菜单 |

“见缝插针”会将**时间线开始/结束时间**作为工作时间范围，对于今天只寻找当前时刻之后的空槽，并自动避开现有的任务和 Google 日历日程。如果没有合适空位，会弹出“无可用空闲时段”通知。

### 推荐的一日工作流 ☀️

1. 清晨打开 Dayloom，按 `s` 展开侧边抽屉。
2. 查看**逾期任务**，使用 `移到今天`、`明天` 或 `取消日期` 快速清理。
3. 挑选今天最重要的 1–2 件事，拖入 **🎯 今日焦点**。
4. 将脑海中闪现的新琐事随手写入抽屉顶部的**快速记录**。
5. 在**无日期任务**中多选今天要做的项，直接拖放到时间线上连缀排开。
6. 拖动色块下边缘微调预估时长；傍晚工作结束时，查看**统计**复盘成就。

## 5. 视图、搜索、选择与快捷键

### 6 种视图

| 视图（标签页） | 快捷键 | 亮点特性 |
| --- | --- | --- |
| **日** | `d` | 单日时间线。当前时刻红线、正在进行任务的状态条、顶部固定的“全天”栏 |
| **N 天** | `x` | 多天并列展示（2–14 天；可在标签页中直接切换天数） |
| **周** | `w` | 单周时间线。**点击星期表头**直接进入对应日期的日视图 |
| **月** | `m` | 月历网格。**点击日期**进入日视图；**点击周数**进入周视图 |
| **看板** | `b` | *标准看板*模式（无日期 · 已逾期 · 今天 · 明天 · 以后 · 已完成）与*优先级聚焦*模式（最高 🔺 … 最低 ⏬ 未完成任务）。`j` / `k` 可在两模式间切换 |
| **列表** | `l` | 当月议程式列表。在搜索时，直接展示所有日期的匹配项 |

- 在**看板**中，将卡片拖到其他列会改变其日期（今天 → 今天，明天 → 明天，以后 → 3天后，逾期 → 昨天，无日期 → 清除日期，已完成 → 标记完成；从已完成移出则重新激活）。在*优先级聚焦*模式下拖动则会更改任务的优先级。支持多选卡片批量移动，点击列标题旁的箭头可折叠该列。
- 视图切换毫无延迟：每个视图常驻内存，仅在数据变动时重绘。

### 标题栏布局（桌面端与平板端）

```
[📅 日期]     [ 日 | 4天 | 周 | 月 | 看板 | 列表 ]     [‹ 今天 ›] [🔍 🔎 ↻ ? ▣] [+]
```

| 控件 | 说明 |
| --- | --- |
| 📅 日期胶囊 | 打开对应的日记/周记（在日视图中，周数点击可打开周记） |
| 视图标签 | 切换视图。切换时保持当前浏览日期不变，窗口变窄时自动折行 |
| ‹ 今天 › | 上一个 / 今天 / 下一个（看板视图始终以今天为准，故无此按钮） |
| 🔍 缩放 | 日/N 天/周视图的时间线高度（每小时像素）：悬停或点击弹出滑块 |
| 🔎 搜索 | 搜索任务与日程（`/`） |
| ↻ 同步 | 与 Google 日历同步（右键点击：打开任务同步对话框）。启用日历时显示 |
| ? | 键盘快捷键帮助（可在设置中隐藏） |
| ▣ 面板 | 打开 / 关闭侧边抽屉 |
| **+** 添加 | 新建本地任务或新建 Google 日历日程（*添加本地任务* / *添加日程*） |

在看板视图中，标题栏还会加入**标准看板 / 优先级聚焦**的切换开关。
标题栏、菜单与弹窗完全适配你的 Obsidian 主题配色。

### 🔍 展开式搜索

1. 按 `/` 键或 `Ctrl/Cmd+F`，亦可点击搜索图标。标题栏的所有按钮会自动收起，展开为通栏搜索输入框。
2. 输入关键字：当前视图会实时过滤显示。搜索范围涵盖任务文本（含 `#标签`）、笔记路径、日程标题、地点、描述以及所属日历名称。支持多词空格分隔匹配。右侧会显示匹配结果计数。
3. 按 **Enter** 键可直接切换到**列表**视图，一次性**列出跨越所有历史与未来的全部匹配项**。
4. 按 **Esc** 键或点击 **×** 可退出搜索并恢复全部日程显示。

无日期任务不属于时间维度的列表视图；在搜索时，匹配到的无日期任务会呈现在抽屉的“无日期任务”分组中。

### ✅ 多选与批量删除

| 操作 | 方式 |
| --- | --- |
| 增选 / 减选单项 | **Ctrl/Cmd+点击** 对应项目（不会打开编辑弹窗） |
| 框选多项 | 在空白区域**鼠标拖动出选框（Marquee）**：时间线、全天栏、看板、抽屉任务列表均支持 |
| 追加框选 | 按住 `Ctrl`、`Cmd` 或 `Shift` 拖动选框 |
| 清除选择 | 点击空白处，按 `Esc`，或点击底部选择栏上的 × |
| 批量移动 | 抓住任意选中的一项拖动：其他选中项随行（时间线色块保持间距，抽屉卡片连续排布） |
| 批量删除 | 按 `Delete` 或 `Backspace` 键，或点击底部操作栏的**删除所选项目** |

- 选择属于**单一区域**：时间线/看板/月历网格、全天栏、或侧边抽屉之一。在其他区域点选会开启新的选择。
- **删除**操作会有安全确认提示（`Enter` 确认，`Esc` 取消）。任务行会从笔记文件中彻底移除，选中的 Google 日程也会从云端同步删除。在操作后弹出的通知中**点击一次撤销（Undo）**即可将整批项目完整还原，包括日历日程。
- 任务和日程的编辑弹窗内同样提供**删除**按钮（在编辑弹窗内按 `Delete`/`Backspace` 同样会有确认提示，打字时光标内绝不会误触发删除）。

### ⌨️ 键盘快捷键

> 快捷键在 Dayloom 视图获得焦点（点击一次）后生效。当光标处于输入框（快速记录、搜索栏、编辑器等）中时，按键用于文字输入。除 `Ctrl/Cmd+R` 和 `Ctrl/Cmd+F` 外，常规修饰键组合均保留给 Obsidian 原生功能。

| 按键 | 功能 |
| --- | --- |
| `j` / `k` | 上一个 / 下一个日期周期（桌面看板：切换看板/优先级；紧凑看板：切换列） |
| `t` | 跳到今天 |
| `d` / `x` / `w` / `m` / `b` / `l` | 切换至 日 / N 天 / 周 / 月 / 看板 / 列表 视图 |

### 🖱️ 鼠标交互

## 6. 触控操作：手机、平板与触屏笔记本

### 长按拖动（所有触控设备）

在触控屏上轻扫默认用于页面滚动，因此抓取任务需要**长按约 0.3 秒**：

1. **按住**色块或卡片直到其轻微浮起（支持设备会伴随短促的触感振动）。
2. 用同一根手指**拖动**：鼠标拖拽能做的一切操作（抽屉、月历格子、看板列等）完全一致支持。
3. 抬起手指即可放置。若没有移动直接抬手，则放回原位。

在时间线色块上，长按还会呼出色块的**尺寸调整手柄**：拖动顶部或底部边缘即可改变时长。手柄显示期间，按住色块主体可直接拖动。轻触其他空白区域即可退出调整模式。

当一只手指按住任务时，你可以**用另一只手指轻触视图标签、日期箭头或日期胶囊**，直接将任务带往另一个视图或日期。

### 触屏笔记本

Dayloom 能够智能识别手指触控与鼠标/触控板操作：

- **手指触控**：采用上述长按拖动逻辑；轻触滑动用于滚动页面。
- **鼠标 / 触控板 / 手写笔**：与传统桌面端完全一致，点下即拖。鼠标悬停在色块上即显示尺寸调整手柄。

### 手机端（与 Dayloom Compact）

- **底部导航栏**：**日 · 列表 · 月 · 看板** 4 个视图标签，外加**更多**按钮（周视图与 N 天视图可在主 Dayloom 中使用）。
- **标题栏**：包含日期展示、**‹ 今天 ›** 跳转按钮与 **+** 快速添加按钮。
- **日期滑块**：在日视图和列表视图的标题栏下方，有一整周的日期胶囊，轻按即可切换至对应日期。
- **滑动切换日期**：在规划器内左右滑动即可翻页（在看板中切换列）。从屏幕边缘发起的滑动依旧能正常呼出 Obsidian 侧边栏。此滑动翻页功能可在“设置 → 视图/显示”中关闭。
- **列表**：以单日议程视图直观展示（左侧时间标尺、颜色指示条、事项时长、所在笔记名称与完成进度统计）。
- **月**：每个日期格子内尽可能多地展示事项，超出部分折叠为 `+N`。轻点日期格子直接在日视图中打开该天。
- **看板**：每次全屏展示单列；可通过上方指示条或左右滑动快速切换列。
- **更多**：点击呼出底部抽屉面板，内含**搜索**、**同步**（长按可进入高级同步选项）、**时间线缩放**滑块，以及原侧边抽屉中的**任务**与**统计**面板（今日任务、今日焦点、逾期任务、无日期任务）。轻按外部、向下拉动或按 `Esc` 即可关闭。
- **双击**：双击空白时间槽快速添加新任务。

### 平板端

平板端直接提供完整的桌面端布局体验，内建完整的侧边抽屉，并支持长按触控拖拽。搭配妙控键盘触控板、鼠标或 Apple Pencil 时，操作体验与桌面端完全一致，即点即拖。

## 7. 任务语法与行内代码块

### 基础语法格式

```markdown
- [ ] 任务标题 ⏰09:00-10:30 ⏫ 🔁 every week ⏳ 2026-10-07 📅 2026-10-10
```

| 部分 | 语法写法 | 含义 |
| --- | --- | --- |
| 状态 | `[ ]` `[/]` `[x]` `[-]` | 待办 / 进行中 / 完成 / 已取消 |
| 时间 | `⏰09:00-10:30` | 开始–结束时间。若没有结束时间（`⏰09:00`）则默认显示为 30 分钟 |
| 优先级 | 🔺 ⏫ 🔼 🔽 ⏬ | 最高 / 高 / 中 / 低 / 最低（缺省为普通） |
| 计划日期 | `⏳ YYYY-MM-DD` | Dayloom 在安排任务日程时写入的标准日期 |
| 截止日期 | `📅 YYYY-MM-DD` | 当没有计划日期时备选采用的基准日期 |
| 开始日期 | `🛫 YYYY-MM-DD` | 兼容 Obsidian Tasks 插件语法 |
| 完成 / 取消日期 | `✅ YYYY-MM-DD` / `❌ YYYY-MM-DD` | 在完成或取消任务时自动记录的日期 |
| 重复规则 | `🔁 every day` 等 | 勾选完成后自动在下一行生成下一次的新任务 |
| Google 关联 | `[gcalId:: …]` | 日历同步时自动写入的标识（请勿手动修改） |

#### 其他时间写法支持

Dayloom 同样兼容以下常见的时间书写习惯：

```markdown
- [ ] 09:00 - 10:00 晨会          ← 时间在前
- [ ] 晨会 [09:00-10:00]          ← 方括号包裹
- [ ] 晨会 [startTime:: 09:00 - 10:00]
```

#### 日期生效的优先顺序

`⏳ 计划日期` → `📅 截止日期` → **笔记文件名中的日期**（日记笔记）。
例如在 `Daily/2026-10-07.md` 笔记中写入 `- [ ] 晨练 ⏰07:00-08:00`，即便没有写任何日期 Emoji，也会自动成为 10 月 7 日 07:00 的色块。

#### 重复规则写法

`every day`（`daily`）、`every week`（`weekly`）、`every month`（`monthly`）、`every year`（`yearly`）、`every weekday`（每个工作日），以及 `every N day/week/month/year`（例如 `every 3 days`）。

### 行内代码块：```` ```dayloom ````

你可以将 Dayloom 规划器直接嵌入到任何普通笔记正文中。在命令面板中运行 **Insert Inline View (dayloom block)** 即可快速插入。

````markdown
```dayloom
type: daily
height: 500px
```
````

> 早期版本的代码块标识 ```dayplanner` 和 ```dayplanner-pro` 依然完全兼容。

| 选项 | 可选值 | 说明 |
| --- | --- | --- |
| `type` | `daily` · `multiDay` · `weekly` · `monthly` · `board` · `list` | 呈现的视图类型。在块内点击标签页切换会自动更新此处 |
| `date` | `YYYY-MM-DD` 或 `today` | 显示的目标日期 |
| `height` | `500px`、`80vh` 等（纯数字默认代表 px） | 规划器高度。拖动块的下边缘可调整并自动保存 |
| `hourHeight` | 数字 | 仅为此嵌入块单独设置每小时像素高度 |
| `showFilters` | `true` | 打开时默认展开筛选器栏 |
| `collapsedColumns` | `[undated, completed]` | 默认折叠的看板列 |
| `filters` | （由筛选器面板自动生成） | 见下方的筛选器说明 |

- 在**日记**中放置未指定 `type` / `date` 的代码块时，会自动聚焦展示当天；在**周记**中则展示当周。且此时该代码块仅列出属于该天/该周的事项。
- 在嵌入块中，点击星期表头、日期和周数会直接打开对应的日记/周记**笔记**（因为代码块本身不提供视图切换顶栏），列表视图自带专属的日程搜索框。
- 嵌入块与主视图一样支持完整的鼠标拖放操作，且仅在滚动到视口内时才进行渲染，极致节省系统资源。

### 🔍 行内代码块筛选器

点击代码块顶部的 **🔍 筛选** 按钮即可呼出单行筛选条。按钮上会显示当前生效的筛选规则数量，例如 `🔍 筛选 · 2`。

```
[全部匹配 ▾] [📁 文件夹 包含 Work ×] [# 标签 包含 #urgent ×] [+ 筛选]
```

1. **+ 筛选** → 选择筛选维度：`文件夹` · `文件` · `标签` · `状态` · `优先级` · `日期` · `文本` · `项目类型`
2. 在展开的条件编辑行中配置运算符和取值，点击**完成**（或按 `Enter`）。
3. 点击生成的标签胶囊可再次编辑，点击 `×` 可删除该规则。
4. 最左侧的**全部匹配 / 任意匹配 / 全部不匹配**可设置多条规则间的逻辑关系。
5. 如需更复杂的嵌套逻辑，可通过 **+ 筛选 → 规则组（匹配其中任意一项…）** 添加带括号的组合条件。

| 筛选维度 | 可用条件 |
| --- | --- |
| 文件夹 | `属于` / `不属于` ＋ 目标文件夹（带自动补全） |
| 文件 | `匹配` / `不匹配` ＋ 笔记名称 |
| 标签 | `包含` / `等于` 等 ＋ `urgent`（`#` 号可选，包含子标签） |
| 状态 | `是` / `不是` ＋ 待办 · 进行中 · 完成 · 已取消 |
| 优先级 | `等于` / `高于` / `低于` ＋ 优先级级别 |
| 日期 | `是` / `早于` / `晚于` ＋ 今天 · 明天 · 本周 · 本月 · 某一特定日期，或 `为空` / `已设置` |
| 文本 | `包含` / `开头是` 等 ＋ 文本内容 |
| 项目类型 | 任务 / Google 日历日程 |

筛选规则在编辑时实时生效。关闭面板后，规则会以标准的 YAML 结构保存在代码块中（亦支持手动编辑）：

```yaml
filters:
  kind: group
  mode: all
  children:
    - kind: rule
      type: folder
      operator: contains
      value: "Work"
    - kind: rule
      type: status
      operator: notEquals
      value: "completed"
```

> 💡 技巧：在一篇项目笔记中嵌入一个带有 `Folder in Projects/Alpha` 过滤规则的看板代码块，就能直接生成一个专属该项目的 Kanban 看板！

## 8. 常见问题 (FAQ) 与故障排除

### Q1. 任务没有显示在规划器中。

- 检查该行是否以 `- [ ] ` 开头（`*` 符号列表或数字编号列表无法被识别为任务）。
- 时间线**仅展示带有日期的任务**。无日期的任务请在侧边抽屉的**无日期任务**或看板的**无日期**列中查找。
- 检查该笔记是否被包含在“设置 → 常规 → **排除的文件和文件夹**”规则中。
- 同步工具（如 Syncthing）产生的冲突副本文件（文件名中含有 `.sync-conflict-`）会被有意忽略。
- 检查当前是否开启了搜索筛选，按 `Esc` 键清空搜索试试。
- 按下 `F5` 键重新扫描整个仓库。

### Q2. 在笔记中打字时，规划器没有立即刷新。

这是为了确保打字流畅所做的专门优化：Dayloom 会在你**停止敲击键盘约 2 秒后**，才重新读取笔记并静默重绘规划器。

### Q3. 刷新 Google 令牌时弹出 "invalid_grant" 错误。

这说明你的刷新令牌已经过期或已被撤销。

- 当同意屏幕处于**测试中（Testing）**状态时，令牌**在 7 天后会自动失效**。请将同意屏幕发布到**正式环境（In production）**，然后按照[步骤 5](#步骤-5获取刷新令牌oauth-20-playground) 重新生成一个长期刷新令牌。
- 修改 Google 账号密码，或在 Google 账号安全设置中撤销了该应用的访问权限，也会导致原有令牌作废。

### Q4. 遇到 "unauthorized_client" 或 "invalid_client" 错误。

- 仔细核对客户端 ID 和客户端密钥是否完整复制，没有遗漏字符。
- 刷新令牌**必须与当前的客户端 ID 和密钥配对生成**。在 Playground 中若未勾选 *Use your own OAuth credentials* 而直接获取的令牌是无法在此使用的。

### Q5. Google 日历日程丢失，或者只显示了部分日程。

- 检查“设置 → ☁️ Google 日历 → **Google 日历 📅**”列表中，该日历是否已被添加且**已勾选启用**。
- 设置为**任务同步的 Google 日历**中的日程默认不会在规划器中作为日程重复显示。请不要将存有普通会议的主日历设为同步日历。
- 点击标题栏同步按钮或按 `F5` 刷新试试。

### Q6. 我在笔记中修改了时间，但 Google 日历没有同步更新。

直接在笔记文本中手动编辑的变动不会即时自动推送到云端。请点击标题栏的**同步**按钮（或按 `F5`）推送一次。
在 Dayloom 规划器内通过拖拽或弹窗修改的任务，则会立即同步到 Google 日历。

### Q7. 任务末尾的 `[gcalId:: …]` 显得杂乱，能删掉吗？

千万不要删除，它是关联云端日程所必需的唯一 ID。建议在“设置 → 📱 视图/显示”中开启**隐藏行内元数据字段**，即可在不破坏笔记原始内容的前提下在界面上将其隐藏。

### Q8. 收不到开始提醒。

- 确认“设置 → 🔔 通知 → **提醒方式**”没有设为`关闭`。
- 确认该任务具备**今天的日期**以及具体的**开始时间（`⏰HH:mm`）**。
- 系统通知需要操作系统的权限授权。如果曾经拒绝过，请在操作系统设置中允许 Obsidian 发送通知（无权限时 Dayloom 会回退为应用内通知）。
- 如果听不到提示音，可点击 🔊 按钮测试。在部分手机系统上，受浏览器安全策略限制，需要先轻触一次屏幕才允许播放声音。

### Q9. 快捷键不起作用。

- 请在 Dayloom 规划器区域内单击一次，确保其成为**当前焦点视图**。
- 当光标位于文本输入框（如快速记录栏、搜索框、笔记编辑器）内时，键盘按键用于输入文本，快捷键不会触发（属于正常行为）。
- 再次按下 `?` 键可关闭打开的快捷键帮助弹窗。

### Q10. 时间线色块无法拖动。

- 已完成（`[x]`）和已取消（`[-]`）的任务会自动锁定。取消勾选后即可恢复拖拽。
- 在触控屏上，直接滑动会被识别为翻页滚动，因此需要**长按色块约 0.3 秒**后再开始拖动。

### Q11. 看不到侧边抽屉。

侧边抽屉仅在**桌面端和平板端的 Dayloom 主视图**中提供。按下 `s` 键，或点击标题栏右上角的面板图标（▣）即可展开。
在手机端或右侧边栏的 Dayloom Compact 中，相同的功能都整合在底部栏的**更多**抽屉内。

### Q12. 抽屉遮挡住了时间线的一部分。

当规划器宽度小于 900px 时，为防止时间线被压缩过窄，抽屉会自动转为悬浮卡片式展开。点击外部或按 `s` 键即可关闭；拉宽 Obsidian 窗口即可恢复侧边并列停靠。

### Q13. 快速记录添加的任务没有出现在“无日期任务”里。

如果设置中的**默认任务文件路径**指定的笔记文件名本身包含日期（例如 `2026-10-07.md`），那么新加入的任务会自动继承该日期。建议指定一个不含日期的文件名（例如 `Inbox.md` 或 `Day Planner.md`）。

### Q14. 误挪动或误删除了日程，能够撤销吗？

完全可以。每次挪动或删除操作后，屏幕下方都会弹出带有**撤销（Undo）**按钮的通知提示。即使是一次性批量操作也能一步完整复原，误删的 Google 日历日程也会被无缝恢复。

### Q15. 我的 Google 凭据存放在哪里？安全吗？

你的客户端密钥和刷新令牌保存在仓库本机的 `.obsidian/plugins/obsidian-day-planner-pro/data.json` 文件中。短期的访问令牌仅保存在内存中，绝不写入硬盘。抓取的日程缓存保存在同目录下的 `gcal-cache.json` 中。
如果你将整个仓库公开分享（例如托管在公开的 GitHub 仓库），请务必在 `.gitignore` 中排除上述配置文件。
若要彻底撤销访问权限，可在 Google 账号设置 → 安全性 → **第三方应用与服务**中解除 Dayloom 的授权。

### Q16. 我通过 Syncthing 等工具同步仓库，有什么注意事项吗？

Dayloom 仅在设置发生实质修改时才写入 `data.json`，能自动感应并采纳从其他设备同步过来的新配置，并且会主动忽略带有 `.sync-conflict-` 的冲突副本笔记。在同步途中即使文件瞬间处于锁定状态，Dayloom 也绝不会破坏文件，而是安全地以默认配置维持运行。

### Q17. Dayloom 显示的语言或配色不正常。

- 语言：前往“设置 → 常规 → **语言 / Language**”进行调整。`自动检测`会跟随 Obsidian 自身的语言设置，也可以手动固定为你所需的语言。
- 配色自动适配你的 Obsidian 主题。任务色块使用**本地任务颜色**，各 Google 日历则遵循在“设置 → ☁️ Google 日历”中为每个日历自定义的独立颜色。
